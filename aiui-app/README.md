# 電脳秘書ロキ AIUI版 0.1.0

これはロキのAIUI向け移植です。公式サンプルの名前を変えただけのものではなく、既存ロキの日本語秘書としての応答方針とアイコンを引き継ぐ独立したAIUIプロジェクトです。Android APKの全機能移植ではありません。

## 取り込み
ZIPを展開し、このREADMEと`app.json`があるフォルダーをAIUI Studioの **Import from local folder** で選びます。親フォルダーやZIP自体を選ばないでください。

GitHub取り込みに失敗する場合もローカルフォルダーから取り込めます。GitHubから取り込む場合はAIUI専用のルート配置ブランチを使います。Android版リポジトリ全体は不要です。

1. AIUI Studioのプレビューで会話画面を開きます。
2. AIUIホスト側の言語モデル設定を確認します。このプロジェクトにAPIキー入力欄や固定キーはありません。
3. 文字を入力して送信します。音声入力は認識結果を入力欄へ戻すだけで、自動送信しません。
4. 生成中の文字は暫定です。完了すると「確定」になります。停止・失敗時の途中文章は確定扱いにしません。
5. 「回答を読む」は明示的な音声合成要求です。「読み上げ停止」で本エージェントの再生を停止できます。

## 実装範囲
- 同じ話題の直近最大6往復・10000文字以内を引き継ぐ日本語会話。回答12000文字、入力2400文字、90秒待機上限。
- 依頼IDに対応した途中表示、中止後の遅延応答の除外、空きポーリング時80ms待機。自動再送なし。
- 音声入力の明示開始・停止（最大60秒）、確認後の送信、回答の明示読み上げ（最大1200文字）と停止。
- メモ30件・各1000文字、質問テンプレートの下書き呼び出し、話題切替、一時履歴40件。
- 履歴保存は初期OFF。ONにした場合だけ確定した最大20件を保存。復元した履歴は自動でモデルの文脈へ渡しません。
- 音声はAIUIホストの能力に依存し、日本語の認識・読み上げ品質は未保証です。

## 保存と外部送信
メモと設定、任意の履歴はAIUIエージェントごとのlocalStorageに保存します。アプリ独自の暗号化はありません。機密情報を保存しないでください。Android版の暗号化保存・データ形式との互換性はありません。

送信ボタンを押した質問と、同じ話題の現在の一時会話をAIUIホストが設定するモデルへ送信します。メモは自動送信せず、相談の下書きに戻して送信した場合だけ含まれます。音声入力・読み上げはAIUIの音声サービスを利用します。プロバイダー、データ保持、料金はホスト設定・利用条件を確認してください。

画面を離れると本エージェントの回答待ち・音声入力・読み上げを停止します。既送信データ、受付済みの処理や料金は取り消せません。再表示やネットワーク復帰で自動再送しません。会話は成功時の完了テキストだけ保存対象にします。保存競合時は上書きを拒否し、保存失敗時は画面の入力を保持します。

## 検証
`node --test tests/*.test.js`で合成モデル・音声・保存アダプターを使う回帰テストを実行します。実AI要求やマイク・音声再生を行わないテストです。公式`@yodaos-pkg/aix-cli`のpack/list/showはパッケージの構造を確認するもので、実機動作の保証ではありません。AIUI Studioへの実取り込みと実機のモデル・日本語音声は別途確認が必要です。

対応しないAndroid版の機能と今後の接続方針は[PORTING.md](PORTING.md)を参照してください。
