# 配布用グラス画像の容量削減

`Optimize-GlassArtwork.py --apk <署名済APK> --report-dir <新しい検証用フォルダ>` をビルド後に実行する。Python / Pillow / NumPy と既存Android SDK・デバッグ署名環境を利用する。

元の署名済みAPKはreport-dirのunoptimized.apkに保持する。同じフォルダを別版に再利用しない。リポジトリの元PNGを変更しない。画像はquality95 WebPで配布し、黒背景・表示幅480でのMAE<1.8、RMSE<3.8を満たさなければ画素完全一致の可逆WebPへ切り替える。寸法・アルファの一致を検証する。論理アセット名は互換性のため維持する。

現在ソースに参照のない旧transition flowだけをAPKから除外する。DEXとその他リソースはバイト一致を検証する。同じ開発署名で再署名する。ストア配布用署名にはこのスクリプトをそのまま使用しない。

最終APKの全画像について対象AndroidのBitmapRegionDecoderで読み込み検査し、実行コードと描画・復帰の検証を行ってから適用する。元PNGが必要な処理やopenFd経由の利用を追加した場合は拡張子とコーデックの扱いを再検証する。圧縮のみでは端末全体の容量消費原因が解決したとは判断しない。
