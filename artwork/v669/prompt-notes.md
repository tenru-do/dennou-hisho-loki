# 生成指定の記録
方式：imagegenスキル、組み込みimage_gen、通常背景（透明化なし）。すべてユーザー指定の2026-10-27基準画像を第一参照として入力した。

- 手差し立位：旧loki_body_affection_v667を第二参照。4列2段、上段立位・下段座位、自然な小さい頭・手、細身の長い脚、成熟したリアルな顔、同一スケール、黒背景の余白を指定。
- 手差し座位：旧loki_body_affection_seated_v667を第二参照。上段3列から4列へそろえる指定。下段4列は着席・手差し・少し伸ばす・手を戻す。座位をセルいっぱいへ拡大しない。
- 接触：旧loki_contact_states_v667を第二参照。上段立位・下段座位、開いた手・握る手・両腕を開く・戻る。頭・顔・手の拡大を避ける。
- 脚：基準画像と旧座位シートを参照し、4列2段の専用動作を生成。初回生成は反対側への組み替えが不足したため修正。最終原画では下段0→1→2が左右の組み替えになり、下段3は元向きへ戻るため不使用。採用原本はselection.json。

原本をプログラムで変形加工したものではない。Pythonの画像処理は検査用一覧・プレビューのみに使用。
