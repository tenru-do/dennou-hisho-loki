# 寝姿の仕草・表情の試作

2026-10-27、ユーザーが提案された日常の寝返り・背伸び・照れた身じろぎと、寝姿の表情の制作を依頼。built-in image_genで基準画像と既存の寝姿を参照して作成した。新しい試作であり、アプリへの登録・APK更新・実際の動画化はまだ行っていない。

- rest-motion-12frames.png: 4列×3段。上段は仰向けから横向きへの寝返り、中段は腕を伸ばす背伸び、下段は照れた身じろぎと頬に手を添える仕草。
- rest-expressions-8frames.png: 4列×2段。左から軽いキス顔、困り顔、せつない顔、気持ちをこらえる落ち着いた顔。上下で弱い表情と少し明瞭な表情。
- prompts.txt: 実際に使用したプロンプト全文。

成人キャラクターの顔立ち、黒いシャツ・スカート・ヒール、通常の休息姿勢を維持する方針。原画を目視し、全身が枠内に収まることと動作・表情の差を確認。今後組み込む場合は全コマの体格の目印・境界・肩幅・脚長を比較し、実表示での表情の判別と切り替えを検証してから登録する。生成画像はピクセル単位で同じ体格や衣装形状が保証されるものではない。
