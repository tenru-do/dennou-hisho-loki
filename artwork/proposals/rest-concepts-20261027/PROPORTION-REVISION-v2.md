# 頭身・体格の修正 v2

旧 rest-motion-12frames.png と rest-expressions-8frames.png は、基準より頭が大きく寸胴に見えるとのユーザー指摘により不採用。旧ファイルは履歴として保持するが、差分制作の参照に使わない。

基準画像だけから rest-master-proportions-v2.png を作り直し、それを元に rest-expressions-4frames-v2.png（2列×2段）、rest-motion-9frames-v2.png（3列×3段）を制作。1コマの縦横比を基準に近づけ、頭を大きくしてコマを埋めない方針。成熟した顔・細い腰・長い脚・黒い衣装を目視比較した。ピクセル単位で骨格が一致することや、すべての角度の比率の一致は保証しない。

表情は左上キス顔、右上困り顔、左下せつない顔、右下こらえる顔。動作は上段寝返り、中段背伸び、下段照れた身じろぎ。静止画の動作素材であり動画化・アプリへの登録・APK更新は未実施。

実際のbuilt-in image_genプロンプトは prompts-v2.txt。原本の基準画像は変更していない。
