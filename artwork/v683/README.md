# v683 寝姿画像の最終仕様

ユーザー最終指定：縦長画面、頭が上・足が下、真上から見る寝姿。靴を脱ぎ、髪と服に自然なくつろぎ感。基準の成熟した顔と細身の長い脚を維持。

最終採用は pillow / arms / chin（仰向けで頬に手）/ dream の4枚。各1024x1536の2x2シート、セル512x768。落ち着き・微笑み・考え顔または心配顔・眠そうな寝顔を同じ中立の体へ重ねる。

横長と斜め配置の試作は不採用。未適用の試作のためv683のまま最終構成へ更新した。膝の間の抱き枕と横向き追加分は生成ツールの出力安全判定で停止したため採用せず、操作で未対応と明示する。医学的な意味や実際に眠っている状態は推定しない。

新しい画像の原本はimagegenのgenerated_imagesに保持。各画像は基準との全体像・顔・手足・服の丈を確認し、artwork/character-artwork-review.jsonでSHA256を固定。ランドマークは最終の縦長図で再記録。自動評価だけで全画像の身体比率を保証するものではない。
