画像制作はimagegenスキルのbuilt-inモード。2026-10-27のユーザー指定基準を優先。原本を保持し、採用PNGと生成記録をselection.jsonと各prompt.txtへ記録。

座位・襟元に手を添えた座位・ソファで横になる・襟元に手を添えた寝姿の4種類。座位は元のスカート丈とスリットを維持し、布を付け足さず、両手を膝元へ重ねる。

表情は通常・微笑み・照れ笑い・ウインク・焦り・泣き顔・運動後の息切れの7種類。ポーズと表情を別に管理する。涙は初回が眠った表情に見えたため再編集。感情シートは2段目の足先が下のコマへ入っていたため、全体を小さく配置し直した。素材の行は厳密な等間隔ではないため、PoisedAtlasLayoutの目視確認済み余白を使う。原画は切り貼り加工せず、Java描画時に領域を選ぶ。

髪を耳にかける・視線を向ける・肩越しに振り向く通常の仕草は、立位と座位の各4キー。露出を増やす演出や自動衣装変更は行わない。先の別指定で拒否された画像の再試行ではなく、ユーザーがその後選んだ通常の仕草と表情を制作。

4姿勢×7表情は既存全身443枠とは別の動作用素材。443枚を再生成したものではない。アプリへは必要な素材のみ遅延読み込みし、画像生成時の外部APIキーは使用しない。

## 最終描画方式
原画の表情違いに体格・脚の差があったため、全身画像の切り替えは採用しない。loki_relaxed_poses_v670.pngの4つの元姿勢を固定して描き、表情アトラスから頭部だけを元画像の頭部領域へ重ねる。頭部は元の枠内へ縦横比を保って収め、頭や手を大きくしない。襟・スカート丈・脚・椅子は元画像のまま。息切れの動きは頭部から特定した胸元付近だけに加える。
頭部領域の解析は遅延デコードのバックグラウンド処理で一度だけ行い、既存の仕草には追加解析を行わない。描画時はキャッシュを再利用する。実アプリのCanvasで28通りを確認し、脚の画素が表情変更で変わらないことも検査する。

呼び出し：全身モードのSET→全身の仕草を確認→新しい姿勢→表情を選ぶ。通常の視線・耳に髪をかける・肩越しの振り向きは同じ仕草一覧から選べる。ユーザーからの明示的な指示でのみ衣装関連の元画像へ切り替わり、自動で衣服を変更する機能は加えない。
