# v667 全身画像のリアル寄りの統一

初期の全身ID4と大人の顔の参照から `loki-realism-reference.png` を作り、最近追加した11系列の基準とした。細身の体格、頭・手の自然な大きさ、切れ長の目、鼻・頬・顎の陰影をそろえ、マンガ的な大きな目や幼い顔つきを抑える。ポーズ、黒い衣装、椅子、寝姿の視点を保つ。

制作は組み込みimage_genの編集機能。プロンプトと選択履歴をこのフォルダに保存した。最終原画は `glass-app/assets/*v667.png`。旧原画は保持する。登録済みの初期443枠すべてを描き直したという意味ではなく、初期の標準画像を残して最近の動作11系列を補正した。

全身の仕草レンダラーはv667の原画を参照する。姿勢の縦横比を保ち、脚や頭だけを拡縮しない。手差し座位は上段3列・下段4列で、段の間の余白不足を再編集で修正した。描画に使用する列境界と段境界に明るい人物画素がないことを検査する。

11系列：立ち姿の手振り、座位の手振り、耳、立位の手差し、座位の手差し、手招き、触れ合い、手帳、よろめき・立位のキス動作、上からの休息姿勢、座位のキス動作。顔モードの肖像画像は今回の全身11系列の変更対象に含めない。
