# ロキの画像統一・動作補正 v666

元の `loki_face_cool_v559.png` の大人の顔立ちを基準に、耳に触れる・手を差し出す・手招き・接触・手帳・立ち姿の7系列を補正した。座位専用画像、よろめき、寝姿、顔モードのv665補正版も引き続き使用する。衣装・ポーズ・体格を保ち、元ファイルは削除しない。

制作は組み込み image_gen の編集モード。各プロンプトをこのフォルダに保存した。アプリが参照する最終PNGは `glass-app/assets/*v666.png` に配置する。プロフィール生成時にはソース参照用の画像もスマホ側へコピーするが、スマホAPKの更新・適用を意味しない。

登録済み全身443枠を一覧で目視確認し、最近追加した系列を重点補正した。一覧検査だけで全画像の細部の完全性を保証しない。原画の単なる拡大縮小で頭身を変えず、描き直しで補正する。切り出しに使う枠の境界には黒い余白を確保する。招きは3列、その他は原則4列。座位の手差しは上段3列・下段4列で、上段は寸法参照にのみ使う。

`GestureMicroMotion` は再利用するメッシュの胸元だけに小さい呼吸を加える。頭・脚・足元・外周を固定し、動作の強さ設定を尊重する。新しいキスポーズの接近は縦横同じ倍率で足元を支点にし、頭や胴を部分的に引き伸ばさない。既存の長め・強め・通常へ戻す指定も保持する。新規通信や常駐タイマーは追加しない。

ビルド・純粋Java検査・画像枠検査と、Android上での描画検査・実機適用を区別して記録する。v666の実機検証が未完了なら、適用済みとは扱わない。
