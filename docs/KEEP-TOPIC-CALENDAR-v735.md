# KEEP・TOPIC・予定参照・送信待ちの修正（2026-11-11）

グラスv735、スマホv319を適用済み。最終グラスAPKは端末内base.apkのSHA-256と一致。グラス397ファイル、スマホ10,601ファイルと設定の保持を確認しました。送信待ち12件と再送保留の集合は更新前後で一致し、取消し・自動再送は行っていません。通常のロキの起動も両端末で確認済みです。

## 変更と使い方

- **KEEPの露出補正**：KEEP長押し →「撮影の明るさ」。日向は−1EV、自動は0EV、夜道は＋1EV。次のKEEP撮影から適用し、READ・TOPICの露出や保存済み写真は変更しません。グラス実機の対応範囲は約1/6EV刻み・−4〜＋4EV。白飛びした部分の復元はできず、暗所ではブレやノイズが増える場合があります。説明は「調整の注意点」へ分け、3択が実際に表示されることもAndroid上で検証しました。現地の日向・夜道での撮影は実施していません。
- **復帰時の選択**：CAMよりREADを優先。フォーカス移動だけで撮影を始めないことを確認しました。
- **グラスのTOPICメニュー**：「従来のTOPIC」「音＋カメラで連続トーク」「AMB：環境音＋カメラ」「AMB：Bluetooth再生音」の4種類を前面へ。停止と状態確認は残し、判定・認識内容などは詳細へ整理しました。
- **送信待ち**：再接続時に直近2分の新しい質問まで保留する不具合を修正。古い質問は消さず個別承認で再開。90件の回答済み履歴があっても古い未完了分を先に表示します。接続状態欄の「送信待ちを確認・個別に再送」から開けます。画像3件も個別に表示し、残っている添付だけを選んで再送できます。送信待ちに紐づく期限切れ画像は自動削除しません。既に添付が無い場合は再選択が必要と表示します。
- **予定の参照**：「カレンダーを見れば分かる」「予定が見えない」でも読取に進み、会話中の日付を引き継ぎます。取得したデータにカレンダー名を残して、本人と家族などの予定を区別します。単純な予定一覧はモデルの言い換えを通さず所属付きの実データを返し、会話の続きには今回取得した予定を渡します。予定の作成・変更の確認経路は分離しています。

**PC・タブレットの操作ページは一度再読み込みしてください。再ペアリングや保存トークンの削除は不要です。**

前回のナビの移動行の小型1行化、READ原本保存・再転送、立位基準の人物倍率と頭頂保護もこのグラス版に含まれます。
