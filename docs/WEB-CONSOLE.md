# PC・タブレットで写真・会話を共有する

スマホBridge v163に、同じWi-Fiから開くWeb画面を追加しました。スマホ内の記録写真と、スマホ・グラスの共通会話履歴を参照します。

## 接続（スマホv164以降）

1. スマホで「PC・タブレットで写真・会話を共有」を押します。
2. タブレットは表示されたQRをカメラで読み取ります。PCは共有した接続リンク、または通常のWeb接続リンクをクリックします。URL・コードを手で入力する必要はありません。
3. 初回はこのスマホの自己署名証明書を使います。証明書のSHA256をスマホの表示と照合して接続します。この初回の証明書確認は省略しません。
4. Web画面が自動で接続を要求します。スマホ上の「このWeb端末を許可しますか？」で端末名・接続元を確認し、「接続を許可」を押します。
5. 「この端末を登録する」は初期状態でオンです。登録後は同じ接続先をブックマークして開くだけで、ブラウザを再起動した後も30日間再接続できます。

招待リンクは2分間・1回限りです。招待情報はURLのフラグメントに入れ、Web画面が読み取った直後にアドレスから消します。招待リンクだけで写真・履歴が取得できるわけではなく、スマホでの許可が必要です。

スマホの共有画面が閉じた状態で期限切れのリンクや未登録の通常リンクを開くと、「スマホの共有画面を開いてから接続してください」と表示します。スマホで共有画面を開き直し、Web側の接続ボタンを押してください。

共有PCでは「この端末を登録する」をオフにします。その場合の認証は最大24時間で、このタブだけに保持します。「接続を解除」は端末登録も取り消します。スマホから全Web端末の認証を解除することもできます。端末登録は最大8件です。

スマホとPC・タブレットは同じWi-Fiで使います。スマホのIPが変わった場合は、QR・共有リンクから接続先を更新してください。Wi-Fiの端末間通信禁止設定では接続できません。インターネットへの公開やポート転送は対象外です。

「接続リンクを共有」はAndroidの共有画面を開きます。送り先はユーザーが選択します。アプリがメール等を勝手に送信する機能ではありません。「接続リンクをコピー」も使用できます。

## 写真

- 一覧は60枚ずつ。画面幅に応じて列数が変わります。
- 「このページをすべて選択」は表示中の写真だけを対象にします。ページを変えると選択は解除されます。
- 写真を開くと、拡大・縮小・前後移動・JPEG保存・削除ができます。削除後は残った次の写真を同じ拡大画面に表示します。
- 選択した複数の写真をJPEG保存／削除できます。複数ダウンロードはブラウザでの許可が必要になる場合があります。
- 「保存分をすべて削除」は全ページが対象です。確認後に一覧が変わっていた場合は削除を中断し、再確認します。
- 削除はスマホ内のロキ保存分を削除し、再取り込みによる復活を防ぐ記録も残します。スマホのギャラリーに保存済みのJPEGは削除しません。
- JPEGには撮影日時と、保存時に利用できた撮影場所のEXIF情報を付けます。位置情報がない古い写真へ場所を推測して付けることはしません。
- 「グラスから一括取り込み」は、確認後に既存の撮影停止・転送処理を要求します。実際の転送にはグラスとスマホの接続が必要です。一覧の更新で転送結果を確認します。

PC・タブレットで保存したJPEGは、そのブラウザのダウンロード先に入ります。スマホのギャラリーへ自動保存する操作ではありません。

## 会話

Webの入力も既存のグラスへの指示キューへ送ります。グラスがGeminiで回答し、そのログがスマホへ届くと共通履歴に表示します。Web画面では最新200件まで表示し、5秒ごとに更新します。

グラスが未接続の場合は送信待ちです。この版は、グラスなしでスマホだけがGeminiに直接回答させる機能を追加していません。既存のプロフィール・ツール・会話処理をそのまま使うためです。

Web端末からの送信記録は最新100件、共通履歴とは別に保持します。送信元の端末名と受付状況を表示します。リクエストIDで再送を識別し、同じWeb送信を二重にキューへ追加しません。スマホの操作と同様、実際の発話として記録された段階で共通会話履歴に反映されます。

## 認証と負荷

- Web専用のランダム認証情報を使い、スマホにはハッシュだけを保存します。グラス接続用トークン、GeminiのAPIキーはWebへ渡しません。
- Web認証では既存BridgeのAPIを操作できません。
- 認証情報はURLへ入れず、登録端末ではlocalStorage、登録しない端末ではタブのsessionStorageに保持し、専用リクエストヘッダーで送ります。CORSは許可せず、異なるOriginからの操作も拒否します。
- HTML・JS・CSSは署名済みAPK内の固定3ファイルから読み込みます。CDNや外部スクリプトへ接続しません。
- 写真・履歴レスポンスはno-storeです。写真をブラウザへダウンロードした後の保管は、その端末で管理してください。
- 一覧に元写真をすべて読み込みません。ブラウザのサムネイル取得は同時2件、スマホの画像生成は直列にしてメモリ負荷を抑えます。
- アプリ本体の端末バックアップは、認証情報や会話履歴を含み得る非公開データです。GitHubに入れないでください。
