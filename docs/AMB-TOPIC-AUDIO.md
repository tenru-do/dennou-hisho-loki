# AMB・TOPICの音声取得改善（グラス556／スマホ206）

VOICEで改善した発話途中の間の扱いを周囲音の取得にも適用。AMBの従来マイク・再生音経路は無音1秒から2.2秒へ、録音上限8秒から12秒へ変更。入力データが一時的に届かない場合も、すでに発話を取得していれば4秒で強制終了しない。

AMB環境音・音＋カメラとTOPICの専用マイク取得は、固定4秒から最短4秒・最長12秒へ変更。1.5〜1.8秒の言いよどみで切らず、信号後2.2秒の静けさを待つ。周囲音は言葉以外も大切なので、無音・判断不能時も4秒の観察サンプルを渡し、従来の「新しい反応なし」の判定を保持する。VOICE用STTに置換せず、環境音・画像を解釈する既存のGemini経路を使用。

TOPIC読み上げ中は既存マイクの分岐にも同じ時間判定を適用。会議録音中は別のAudioRecordを開かず、既存リングから最新12秒をコピーする。リングの増分256KB。単一のPCMは最大384000B（16kHz/16bit/mono）。WAV・Base64・HTTP文字列・キューのコピー分は別途必要。通常VOICEの60秒録音・認識中の追加発話処理には変更を加えていない。AMB/TOPICがすべての時間を欠落なく保存する機能ではない。会議の全量保存はMTGが担う。

スマホの観察音声受信上限を512060文字へ変更し、radio_observationだけPOST本文3MiBを許可。他の通常リクエストの上限は従来通り。観察要求の期限・世代検証・重複拒否と停止時の破棄は維持。通常会話・TOPICの保護されたプロンプトは変更しない。

検証：合成入力の1.8秒の間、後続フレーズ、連続音12秒、無音4秒、PCM上限、会議リングの順序・独立コピー、スマホの12秒WAV受理・大容量拒否・重複・旧世代・停止をPC上で確認。ビルドと実機の確認は作業出力に記録する。合成試験は実環境の聞き取り精度や連続稼働の保証ではない。

更新順序の互換性：スマホ206の取得要求だけがmaxAudioMs=12000を通知する。旧スマホからの要求は従来の4秒上限を維持し、共有音声も最新4秒に絞る。スマホ未更新の間に受信上限超過でTOPICが停止することを防ぐ。AMB単独の環境音取得は12秒。
