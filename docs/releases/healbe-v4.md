# 電脳秘書ロキ v651からの累積更新（グラスv697・スマホv303・HEALBE補助v4）

## v651/v290からの主な更新

- 歩数・HEALBE収支を同じ欄に表示し、関連会話と運動の声かけに反映。HEALBE収支を約5分ごとにGoBeへ再接続して同期します。
- 保存済みの会話履歴や文脈を応答に反映する処理を改善。
- 顔・全身の表情、仕草、操作への反応、体格と表示バランスを調整。
- TOPICの話題生成・ニュース読み上げ、通知の受信・復帰を改善。
- 写真を添えた会話とカレンダー登録の導線を改善。
- PC・タブレットの再接続と入力、保存領域制限への対応、未完了の確認による中断を改善。

予定ナビとBT30は既存機能です。今回追加した機能としては扱いません。

## HEALBE補助v4での修正

v3ではGoBeが接続済みの場合の再接続省略と、一部の同期完了通知だけを根拠に集計を読む処理により、取得時刻が進んでも収支が固定される場合がありました。

v4は毎回のGoBe再接続後、SDK全体のTasksState.SYNC→OPERATIVEを待ってから日次集計を取得します。同期成功時刻と実際の収支変化時刻を別に記録。手動再取得で実値が変化し、続いて手動操作なしの定期取得でも実値変化時刻が更新されたことを確認しました。取得時刻だけの更新を、実値更新の証拠とはしません。

グラスの「同期N分前」は最後の同期完了後の取得時刻を示します。数値が毎回変わることや公式アプリとの同時刻一致を保証する表示ではありません。詳細エネルギーデータ時刻とは区別します。

## ダウンロードと導入

- グラス: `loki-glass-v697-release.apk`（前回公開と同一）
- スマホ本体: `loki-phone-v303-release.apk`（前回公開と同一）
- HEALBE利用者のスマホ: **`loki-healbe-v4-release.apk`へ更新**

HEALBEを持たない方は補助APK不要。許可済みHealth Connect等の歩数を利用し、HEALBE収支は未取得表示です。公式HEALBEのアカウント・既存GoBe PINはスマホ内だけで入力します。

通常利用にUSBは不要です。ロキとスマホ、GoBeの無線接続は必要です。約5分周期はAndroidの省電力・権限制御で遅れる場合があります。常駐起動が制限された場合の代替は15分ジョブです。Geminiの自発生成上限は最大1時間に1回のままです。

既存配布APKと同じ署名を使用。開発版とは署名が異なる場合があるため、既存データを削除して入れ替えないでください。
