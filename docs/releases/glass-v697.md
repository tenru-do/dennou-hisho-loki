# グラスv697・HEALBE補助v3（アルファ版）

前回のグラスv695・HEALBE補助v2からの更新です。スマホ本体はv303のままで、前回と同一のAPKを同梱しています。

## v651/v290からの累積アップデート

- 歩数・HEALBE収支をグラスの同じ欄に表示し、関連会話と運動の声かけへ反映。HEALBE補助アプリを追加。最新版では約5分同期と「同期N分前」表示に改善。
- 会話履歴・文脈・姿勢指示への対応、顔と全身の表情・仕草・操作反応、体格や表示範囲を調整。
- TOPICの話題生成・ニュース読み上げ、通知の受信・復帰を改善。
- 写真を添えた会話とカレンダー指示の導線を改善。
- PC/タブレットの再接続、ブラウザー保存領域の制約、入力と未完了表示を改善。

予定ナビとBT30は既存機能です。v651以降の前段の検証と制約は [v695の記録](glass-v695.md) に記載しています。

## v695以降の変更

- HEALBE収支の取得を、通常の15分JobSchedulerから約5分周期のBluetooth connectedDevice型常駐サービスへ変更。スマホ側の通知から連携画面を開けます。
- インターネット接続なしでは取得を開始せず、同期処理の重複は防止。連携停止操作でサービスも停止します。
- 常駐サービスを開始できない場合は15分ジョブを代替として登録。Androidの省電力制御・権限制限等で5分ちょうどを保証しません。常時CPUを起こすWakeLockは使いません。
- グラスのSDK収支には、詳細エネルギーデータの時刻ではなく、GoBeの接続・同期完了後の取得時刻を「同期N分前」と明示。詳細データの時刻と日次収支の同期時刻の混同を修正。
- Geminiの自発的な声かけ上限は従来の1時間に1回のまま。取得周期の短縮でGeminiの呼び出しは増やしません。

## 更新するAPK

- グラス: loki-glass-v697-release.apk
- HEALBE利用者のスマホ: loki-healbe-v3-release.apk
- スマホ本体: loki-phone-v303-release.apk（変更なし）

通常利用時のUSB接続は不要です。ロキとスマホ、およびGoBeとの無線接続は必要です。開発版と配布署名版は署名が異なり、開発版へそのまま上書きできない場合があります。データを削除して入れ替えないでください。

## 検証

隔離Android実機で448項目。詳細データ53分前/同期6分前と、同期20分前の表示を区別し、最大値を含む情報欄の描画を確認。公開グラスAPKは検証済み開発版とコード・画像が一致し、従来の配布署名を継続しています。

HEALBE補助v3は実機で常駐起動と初回取得に成功。手動操作なしの次回取得を約5.04分後に確認。これは長時間Doze、スマホ全体再起動、すべての端末で正確5分周期を保証する検証ではありません。当日の収支は更新に伴って変わる推定値です。

HEALBEを持たない方は補助APK不要。許可済みHealth Connect等の歩数は利用でき、HEALBE収支は未取得表示になります。
