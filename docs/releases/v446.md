# v446 implementation checkpoint (2026-10-10)

This checkpoint adds an optional full-body presentation while retaining the face presentation. It includes pose assets, posture-aware transitions and idle activities, planner/tablet/coffee actions, blink and speech animation, conversation reaction metadata and bounded reaction audits. Face mode now consumes the same semantic cues through its own expression registry.

Additional features include PLAY controls, system brightness integration, AMB audio/camera options, continuous JPEG recording with a 5 GB quota, and a dedicated KEEP button protecting the previous two minutes and next minute. Phone changes include keyboard insets and TOPIC history retention.

## Validation and limits

The glass v446 build completed with zero compilation errors. Host portrait and full-body semantic reaction tests passed. Device tests verified a real Gemini SURPRISE cue, refusal expression retention across speech segments, expression release after speech, mouth-animation enablement, blink scheduling, and audit persistence. Original display selection was restored after verification. The phone was not redeployed during v446 verification.

Earlier recorder checks verified capture, protection and stop behavior on v443, and dedicated KEEP behavior on v444. Brightness settings read/write were verified; physical LED brightness was not measured. Worn-device visual quality, long-duration recording, thermal behavior and battery duration remain unverified. Capture intervals depend on camera availability and latency. The quota uses actual JPEG bytes, not an assumed 1 MB per image.

Some older visual test fixtures require maintenance; this checkpoint does not claim every historical test passes. Private conversation logs, device backups, credentials and APK build outputs are excluded from this source checkpoint.
