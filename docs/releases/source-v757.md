# グラスv757・スマホv321までのソース更新

2026-11-15。前回のソースv742/v319からの変更です。これはソース公開であり、公開配布APKを更新したという意味ではありません。最新の公開APKはREADMEの配布リンクを参照してください。

## 変更

- 人物を同じ距離から見ていることを基準に、立位・座位・寝姿の縮尺、顔中心、頭頂を残す切り抜きを調整。あいさつ・脚組み・姿勢移行・座位/寝姿の自然動作と、全身モードの情報表示を改善。
- 起動/復帰時のREAD選択、前回の表示サイズ、AMB優先とモード表示を整理。
- KEEPの夜間/自動露出補正、保存前確認と撮影状態、スマホ取り込み状況を改善。
- READ要求は進行中のKEEP撮影を中断してカメラを譲る。他アプリのカメラ使用・競合・アクセス優先順位変更時もKEEPを待機。待機を撮影失敗として数えず、解放後の定期枠で再開する。撮り逃しのまとめ撮りはしない。他アプリのカメラを強制停止しない。
- 選択した未送信依頼を元ID・順序で再開する処理、Web画面のまとめ操作、取り込み状態表示を改善。過去の依頼を自動で一括実行する変更ではない。
- PC接続時のADB復旧・エラー詳細・子プロセスの標準エラー継承を修正。PC起動時、対象グラスを一意に確認できる場合だけ、稼働中のメーカーWi-Fi診断ログサービスを標準操作で停止するガードを追加。

## 検証と限界

- グラスv757の統合ビルド・既存描画/動作/露出の回帰検査、署名検証成功。カメラ優先制御22項目は、取消・複数要求・二重解放・外部競合想定・スレッド間所有権移譲を確認する。今後の統合ビルドにも同検査を追加。
- スマホv321も296ソースのコンパイル（エラー・警告0）、ニュース重複回帰12項目、APK署名検証成功。
- PC側の診断ガード5項目、ADB復旧1274項目、Windows PowerShell 5.1の多重起動・標準エラー処理を確認。新規ネイティブ実行ファイルの検査1件はWindows Application Controlで拒否されたため未実施。既存PowerShellランチャー経路の検証と区別する。
- 実機へのv757更新前後でアプリ内394ファイルのハッシュ一致を確認した。個人データや端末のバックアップはこのリポジトリへ含めない。
- KEEPの1枚撮影・暗号化保存・スマホ転送・JPEGハッシュ一致・テスト原本の両端末削除を実機確認。ただし、この1枚検査はv756時点の保存/取り込み経路を確認したもの。v757でのREAD/公式カメラとの実撮影競合試験、長時間KEEPの正常動作を保証するものではない。
- メーカー診断ログの停止時に大量書込みが止まることは確認したが、グラス単独再起動後の恒久停止は保証しない。PCガードはPCランチャー実行時のみで、蓄積済みの保護ログを削除しない。
- テザリング再設定後の端末間同期は確認したが、報告された移動中の現在地マーク停止の原因特定・実移動での追従再検証は未完了。ナビ修復済みとは扱わない。

撮影・録音・外部AI/APIを使う新しい検証は今回のGitHub公開作業では行わない。
