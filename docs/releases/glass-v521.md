# グラスv521・スマホv175

会話の文脈保持・検索と予定登録、顔の描画・笑顔の口の動作、最大2時間の会議録音、PC／タブレットからのMTG操作と録画・録音ファイルの後処理を統合したアルファ版です。

## 会議録音とWeb操作
グラスの **TOPIC → MTG**、または認証済みロキWeb画面の **会議・録音** から、録音のみ／TOPICの音＋カメラ＋録音／TOPICの音＋カメラ＋写真＋録音／TOPICの音＋録音を選びます。
録音は最大2時間。MTG終了で、そのモードのTOPICと連続写真も停止します。終了済み音声は利用者の操作でスマホへコピーし、グラス側にも残します。VOICE音声入力は録音中に休止し、TOPICは同じマイクの直近4秒を利用します。撮影は30秒以上の間隔に制限し、保存待ちやメモリ不足では見送ります。
Webからの要求は2分で期限切れになり、送信待ちとグラスからの実行結果を分けて表示します。状態受信が15秒以上途絶えると未接続と表示します。

## 録画・録音の文字起こしとAI要約
Webの「録画・録音ファイルから会議記録を作る」で音声付きMP4／M4A／MP3／WAV等を選びます。最大2時間・2GB、対応形式はスマホのデコーダーによります。スマホで音声のみを取り出し、10秒単位の会議記録へ保存します。映像の内容をAI解析する機能ではありません。
録音中や読み込みだけでは文字起こしを実行しません。保存した会議記録から「文字起こし・AI要約（Geminiへ音声を送信）」を明示的に選ぶと、既存のGemini APIキーを用いて後処理します。結果の表示・再生・テキスト保存ができ、途中失敗時には文字起こしの保存済み区間から再開できます。
PCは既存のUSB接続用Web画面を更新、タブレットはスマホの共有QR／リンクから接続して使います。詳細は [Web画面](../WEB-CONSOLE.md) を参照してください。

## その他の更新
- 顔37種類の目・口を通常／軽量描画で検証。笑顔の開閉と待機時の口元を強化。会議録音やナビ中は軽量描画を使用。
- 前の会話を参照する質問、雑談と検索・予定検索の区別、検索出典URLの読み上げ除外を改善。
- 書込み可能なGoogleカレンダー名を指定して予定を登録。書込み権限、日程・登録先、重複と保存後の再取得を確認する。端末上の保存はGoogleへの同期完了とは区別する。
- 登録したCodex会話のID・タイトルを確認して指示を中継。自動で現在表示中の会話を取得する方式ではなく、PCで送信先を登録し直す方式。
- KEEPは連続写真の開始／停止、SETのRECは間隔・共有・移動の設定。写真保存時の小さな音と端の白い点を追加。

## 検証範囲
接続済み端末での録音と撮影の同時動作、暗号化音声転送、認証付き実HTTPS Web APIからの録音開始・終了・転送、合成MP4／WAVの音声抽出、合成音声だけを使ったGemini後処理、認証解除を確認しました。2時間分の合成PCM保存と720区間の復号照合も合格しています。
2時間連続の実録音・電池持ち、2GB実ファイル、実会議の認識精度、タブレット実機の画面、配布署名APKの新規導入は未検証です。PCのWindows画面操作ツールはURL判定で停止したため、クリック操作の目視確認は未実施です。Webコードの動作と実HTTPS APIの往復は確認しています。

## 配布
配布APKは前回グラスv485と同じ専用配布鍵で署名します。署名以外のエントリは実機検証済み開発用APKと同一です。既存の開発用署名版には上書きできません。署名を変えるためにアンインストールすると復号鍵・設定・会話を失う可能性があります。既存端末は維持してください。
