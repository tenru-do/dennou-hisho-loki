# KEEP写真ギャラリー・撮影情報（glass v451 / phone v157）

スマホのKEEP写真から一括取り込み、2列の大きなサムネイル、30枚ずつページ送り、全体プレビューとJPEG保存を追加。グラスSET→RECからの転送も可能。KEEP保護済みだけを送信し、元写真と保護を残す。
撮影時刻を表示し、今後の撮影では取得できた新しいスマホ位置・精度を保存。過去写真の位置は復元せず「位置情報なし」。書き出すJPEGには日時・取得済みGPSのEXIFを記録。位置取得は別スレッド、転送は撮影停止後に1枚ずつ128KiBの断片で実行。TLS認証、SHA-256照合、スマホ内AES-GCM、再実行時の重複拒否を追加。

## 実機検証（2026-10-10）
- 元APK・アプリデータ・外部写真をバックアップ、ZIPと端末のハッシュを照合して更新。グラスv451、スマホv157のインストール済みAPKを候補のハッシュと照合。
- グラスの暗号化写真690枚、KEEP80枚を保持。全690枚の保存ファイルが更新前バックアップとハッシュ一致。
- スマホの取り込みボタンで保護80枚を転送し、実際の一覧と写真プレビューを確認。今日のKEEP62枚を含む。
- スマホのネイティブ試験で複数断片、Keystore暗号化、元JPEG一致、再送、衝突・古い位置拒否、縮小デコード、JPEG日時/GPS書き出し、改ざん拒否PASS。GPS試験は合成座標を使った専用一時領域で行い、実際の外出時位置取得は未確認。
- 写真一覧の大型化後にも試験を再実行し、80枚が保持されていることと実画面の配置を確認。補助アプリは削除。

## 動作停止
取得した直近ログでは停止原因を特定できなかった。過去のメモリ不足を避ける撮影時描画停止は維持し、撮影・保存時間の診断を追加。転送・画像表示・位置取得の負荷を分離した。5秒/10秒撮影中の体感停止時間の比較は今後の実機確認事項。停止が解消したとは主張しない。

手順: docs/OPERATIONS.md。位置・書き出しの保存方針: docs/PRIVACY.md。


## スマホv157：拡大・削除
写真プレビューをピンチ拡大縮小（全体表示から最大8倍）、ドラッグ移動、ダブルタップで拡大/全体表示に対応。描画行列だけを変えて同じBitmapを使い、拡大のたびにデコードしない。
プレビューの「スマホから削除」→確認画面「削除」で、選んだスマホ内コピーと位置メタデータだけを削除。グラスの元写真とKEEP保護、別の保存先に書き出したJPEGは残る。一括取り込みを再実行すれば再取得する。
実機試験は専用一時画像で対象限定削除・範囲外拒否・拡大上限/下限を確認。実写真は削除せず、実際のダブルタップ拡大・確認ダイアログ・キャンセル後80枚保持を確認。phone v154のAPK・アプリデータ・全80枚をバックアップしてからv155へ更新し、インストール済みAPKハッシュを照合。


### スマホv157：削除後の閲覧を継続
削除確認画面は写真プレビューの上に表示し、キャンセルは元の写真へ戻る。削除成功後は同じプレビュー画面の画像と撮影情報を差し替え、新しい順の次の写真へ移動する。次がなければ前の写真、最後の1枚だけは一覧へ戻る。写真を閉じた時に一覧を更新する。保存先選択でもプレビューを維持する。
利用者の作業の継続を設計の前提にする：整理作業を不要な一覧への遷移で途切れさせず、同じ作業を続けるための画面・選択位置・タップ数を検討する。
実機ネイティブ試験で先頭/途中/末尾/空の選択、テスト画像削除後の同一ダイアログでの次画像表示と既存写真への移動を確認。現在の実写真77枚をバックアップして更新し、試験で実写真を削除せず全77枚を保持した。
「JPEGを保存」はACTION_CREATE_DOCUMENTで保存先を選ぶファイル書き出し。ギャラリー（MediaStore）への自動登録はしない。選択した保存先によって端末のギャラリーに表示される場合はあるが、ギャラリーへの確実な登録は未実装。書き出したJPEGはロキ内コピーの削除対象外。


### スマホv157：通常のギャラリーへ保存
写真プレビューの「ギャラリーに保存」はMediaStore.Imagesに通常のJPEGとして登録する。Android 10以降ではPictures/Lokiに保存し、書き込み完了までIS_PENDINGで非公開、完了後に公開する。失敗時は作成途中の登録を削除する。撮影日時と取得済みGPSをEXIFに保持し、DATE_TAKENも撮影日時で登録する。写真表示は維持する。自分で保存したURIが残っている場合は重複を作らない。
保存した写真はギャラリーのLokiアルバムで通常の写真と同様に扱える。ロキ内コピーの削除と、ギャラリーに書き出したコピーの削除は独立。従来の保存先選択方式を通常の保存ボタンから置き換えた。Android 9以前ではストレージ書込み権限を必要時に求める互換処理があり、この互換経路は実機未検証。
実機ネイティブ試験で公開済みMediaStore画像登録、Pictures/Loki、JPEG形式、撮影日時、GPS、重複防止を確認。専用のテストJPEGは試験後に削除し、77枚の実写真は保持。インストール前にスマホv156のAPK・アプリデータ・写真をバックアップし、v157の署名とインストール済みAPKハッシュを確認。


### スマホ v158：KEEP写真の選択操作
- 一覧の各写真の「選択」にチェックを付け、上部の「選択して保存」「選択して削除」で複数枚を処理できます。ページ移動でも選択を保持します。
- 保存先は通常の写真ギャラリーの Pictures/Loki。削除はロキのスマホ内取り込みコピーのみで、グラスの元写真・KEEP保護、書き出し済みJPEGは残ります。
- 操作前に枚数と対象を確認。失敗した写真は選択を保持し、成功数を表示します。
- 1枚表示の保存・削除・閉じるを専用の2段配置へ変更し、削除ボタンが下端で切れる問題を修正しました。削除後に1枚表示を維持する動作、拡大操作は継続します。
- 検証用スマホ 実機：v157 APK・写真77枚を含むデータの検証済みバックアップ後、v158へ更新。署名とインストールAPKハッシュを確認。2枚のテスト画像で一括保存/削除、元77枚の維持、ページ間の選択保持と全ボタンの画面内表示を確認しました。


### スマホv159：すべて選択
一覧の「すべて選択（全ページ）」は取り込み済み写真の全ページを選択します。「選択解除」で全選択を解除できます。選択後は既存の一括保存・一括削除を使います。実機で全41枚の選択、ページ移動後のチェック維持、全解除を確認しました。更新前の41枚をバックアップ・ハッシュ検証済み。テスト中に実写真の保存・削除は行っていません。
