# グラスv651・スマホv290：認証保護、待機負荷、ナビ文字配置

本ページは検証中のソースと開発APKの記録です。公開配布APKはv646/v288のままで、この更新の追加対策は含みません。正式版の全手動確認・版固定12時間試験の完了を示すものではありません。

## 変更

- 認証を確かめてから要求本文を読み込むよう変更。未認証の大きな本文、重複・不正なContent-Length、未対応のTransfer-Encodingを拒否する。
- Android 12L以前を含め、RokidAIのアプリ内部通知を署名権限で保護する。Rokidの装着通知を受ける別の経路は維持する。
- 共有画像の一時ファイルのURIを検証し、読み取り・書き込みの動作を回帰確認する。
- Codex通知はIDを指定したACKに対応し、保留中の会話を削除せずに通知だけを処理する。旧クライアントの先頭ACKの意味は変えない。
- 「TAP: 読み上げ停止」がコメント欄へ重なる表示と、250ms周期の表示更新を廃止。物理タップでの停止・再開は保持する。
- 通知待機ループの所有権を予約待ち時間中も保持し、ループの増殖と短周期の失敗再試行を抑える。
- 変化のない会議状態の送信をまとめ、同じボタン装飾・文字・設定値の再作成や保存を抑える。背面の補助確認と頭部センサー動作を削減する。
- 現在地モードの時計・GPS欄の固定高さを廃止し、日本語フォントの実測高さを確保する。半分表示では地図を残りの高さに収める。
