# 電脳秘書ロキ グラスv757・スマホv321・HEALBE補助v6（アルファ版）

前回公開のグラスv697・スマホv303・HEALBE補助v4から、GitHubへ反映済みの最新ソースを配布APKにしました。

## 主な更新

- 立位・座位・寝姿の人物サイズを同じ距離感にそろえる校正、カラー画像、表情・あいさつ・脚組みの中間動作、全身モードの情報表示を改善。
- KEEPの自動露出と夜間補正、READ画像の保存、写真取り込みと残り枚数・保存状態の表示を改善。
- READ要求や他アプリのカメラ使用・競合時はKEEPがカメラを譲り、解放後の定期枠で再開。撮り逃し分はまとめ撮りしません。
- 復帰時のREAD選択、表示サイズの保持、AMB優先・状態表示、TOPICの選択とニュース重複を整理。
- 送信待ちの依頼を選んで再開する処理、スマホメニュー、PC/タブレット共有画面、PCのADB接続復旧を改善。
- メディア送りはBT90（90秒送り）。再生アプリ・コンテンツの対応状況に依存します。
- HEALBE補助v6は同期停止からの復旧と予備ジョブを改善。利用しない方は補助APK不要です。

## ダウンロード・更新

- グラス：`loki-glass-v757-release.apk`
- Androidスマホ/タブレット：`loki-phone-v321-release.apk`
- HEALBE利用者のスマホ：`loki-healbe-v6-release.apk`

3本とも従来の公開配布版と同じ署名です。開発版とは署名が異なるため、開発版を入れている端末へはそのまま上書きできません。更新のために既存アプリを削除しないでください。通常の配布版利用者は、対応する配布APKを上書き更新します。

R08操作は既存のR08 Access Bridgeを利用します。ロキ内のR08中継実験機能は撤回済みで、QRingとの同時利用を保証するものではありません。

## 確認範囲と制約

両アプリの統合ビルド・回帰検査と署名検証を実施。グラス/スマホの実行コード・画像は検証済み開発APKと一致することを照合し、配布APKのデバッグ無効・バックアップ無効・テストランナー非混入・秘密情報非混入を検査しました。隔離Android検査17,379項目・カメラ優先制御22項目、Web画面20項目に合格しました。SHA-256は添付ファイルを参照してください。

公式アプリとKEEPの実撮影競合、報告された移動中の現在地マーク停止の原因特定/追従再検証、全端末・長時間連続運転・電池比較は未完了です。今回の公開検査では撮影・録音・外部AI/API送信を行っていません。v756時点のKEEP1枚保存・スマホ取り込み・画像一致・テスト原本削除の確認と、v757のカメラ競合の実撮影試験は区別しています。

メーカーWi-Fi診断ログが単独再起動後に再開する問題は、APKだけで恒久対処したとは扱いません。PCランチャーの停止ガードはPC起動時のみです。HEALBEの正確な5分周期、全端末再起動・長時間Dozeも保証していません。
