## 追加経路の確認

新しい検索・読み取り訂正・出発チェックのWeb APIは、既存のトークン認証・Origin検査の後で処理。ブラウザの表示はtextContentなどを用い、記録の文字列をHTMLとして実行しない。検索や訂正、静かな時間、出発チェックに追加の外部AI送信はない。

読み取り履歴と訂正、録音しおりは端末内AES-GCMとAtomicFileを使用。原文を保持し、訂正の版番号・IDと内容の衝突を検査。履歴削除では元写真/予定/会話を削除しない。履歴は100件・90日、1件20訂正、しおりは会議100件を上限とする。録音再生時の一時WAVは専用キャッシュを使い、停止・画面終了時に削除するが、異常終了で残る場合がある。

端末更新用ツールはモデル・対象パッケージ・署名・更新前バックアップのコピー/読み出し・SHA-256一致を確認。既存バックアップの整理は明示適用時だけ、PCコピーとハッシュ検証を通過した更新用重複ファイルに限定する。

## 回帰と限界
