# グラスv695・スマホv303・HEALBE補助v2（アルファ版）

## 主な更新

- 歩数とHEALBEのエネルギー収支を同じ情報欄に表示。HEALBEがない場合、歩数は許可済みHealth Connect等を利用し、収支は未取得表示。
- HEALBE公式SDK連携を追加。スマホ内で既存アカウントとGoBeのPINを入力して利用。定期取得時のGoBe再接続、同期開始・完了待ちを実施し、古い日次集計を再取得成功と誤認する不備を修正。
- 当日収支は推定・暫定値。SDKの日次集計が付ける現在時刻を測定時刻として使わず、エネルギーデータの最終時刻で鮮度を判定。
- 歩数・収支を関連会話へ反映し、設定に応じて運動の声かけを生成。自発生成のGemini呼び出しは最大1時間に1回。休息の意向と静穏時間を尊重。
- 会話履歴・姿勢指示・操作に対する反応、顔と全身の表情や動き、体格と画面内表示の調整を追加。
- TOPICの話題生成・ニュース読み上げ、通知の復帰、写真添付とカレンダー指示、PC/タブレットの再接続・保存領域制限・未送信表示を改善。

## HEALBEの導入

通常のグラスAPK・スマホAPKに加えて、必要な方だけ `loki-healbe-v2-release.apk` を同じスマホへ追加する。ロキの「歩数・HEALBEと運動の声かけ」から直接連携を開く。HEALBEのアカウント・PINはスマホだけに入力する。公開APKには認証情報・個人の健康データを含めない。

公開版3APKは同じ配布署名を使用。開発版とは署名が異なるため、開発版へ公開APKを直接上書きできない場合がある。既存データを削除して入れ替えないこと。HEALBEを使わない方に補助アプリは不要。

## 検証と限界

- グラス・スマホの公開署名版を隔離したAndroid実機環境で446項目確認。コード・画像は対応する検証済み開発版と一致。
- Web回帰24スイート。画像質問テストの古いwindowストレージ模擬と、未完了時の確認ダイアログを期待する旧テストを修正し再実行。実アプリコードの変更は不要。
- HEALBEは前日の活動内訳・基礎代謝・燃焼・収支を表示丸め範囲で照合。修正後、当日も公式とSDKで基礎代謝・活動4分類合計・総燃焼が一致。具体的な個人の測定値は公開資料に含めない。
- 再接続修正後のプロセス終了→ジョブ復帰→新規取得を確認。スマホ全体再起動・長時間Doze・あらゆる端末での動作保証ではない。
- グラスへの配信源は確認済み。最終回の実表示テキストをPCから取得できず、最新画面の完全な目視照合は未完了。
- 公式HEALBEとの同時接続・更新時点によって差が出る可能性がある。15分周期はAndroidの電池制御で遅延する。

今回もアルファ版として公開する。新しい医療上の判断を行う機能ではない。
