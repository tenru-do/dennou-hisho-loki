# グラスv742・スマホv319までのソース更新

2026-11-11。前回公開ソースのv697/v303以降の累積変更。今回のGitHub更新はソース・アプリで使う画像・検査コードの反映であり、新しい配布署名APKの公開ではありません。既存のReleaseは従来の公開版を指します。

## 主な変更

- キャラクター画像のカラー化、立位を基準にした座位・寝姿の倍率と頭頂保護、座位の手振りで体がぶれる問題を改善。
- 通常座位と脚組み中の衣装が変わっていた問題を修正。同じブラウス・スカート・側面の布を持つ7姿勢を8段階でつなぐ。新しい中間原画は3枚で、方向が違った生成候補は採用していない。
- 脚をほどく、両足をそろえる、右／左脚を指定する操作と完了姿勢の保持を追加。足首・つま先の小さな動きを3種類追加。
- 自然な動きがオンなら、連続した待機120秒後に脚を組み替える。静止・省電力・読み上げ・表示保持中の抑制と、再開時に時間を飛ばさない処理を維持。
- KEEP撮影の自動明るさ補正、写真一覧と取り込み進捗、READ原本保存・転送、TOPICの選択整理とニュース重複の抑制を更新。
- スマホのメニュー整理、送信待ちの個別確認・再送、会話でのメモと予定参照、ナビ表示と乗車操作、BT90、PCのUSB接続復旧などの未反映分を含む。
- HEALBE補助の同期復旧処理を含む。取得時刻の更新と健康値の更新を同一視しない。QRingとの併用を目指したロキ内R08実験機能は撤回済みで、実験用ソースは今回の公開対象に含めない。

## 検証範囲

グラスv742の開発署名APKそのものを使った隔離Android Canvas検査189項目に合格。7原画、8段階と7補間中点、順逆再生、ほどいた姿勢の保持、自動開始と静かなモードでの一時停止を確認した。局所動作30751項目、メッシュの向き1241088項目と、既存のビルド必須検査にも合格。実機に適用したAPKは検査APKとSHA-256が一致し、既存アプリデータを保持した。

スマホv319も今回の公開準備でビルドと必須検査を再実行し合格。キャラクター画像・カラー・会話入力ベースラインの検査を実行している。衣装レビューと元画像のハッシュを検査し、未レビューの衣装差し替えを通さない。

以上は全機能の今回の手動再検証や、自然な動きの主観的評価、長時間連続稼働、電池比較、HEALBEの全環境での同期成功を保証しない。今回の公開準備では実会話・写真のAI送信、録音撮影、経路検索・案内開始を行っていない。個人設定・認証情報・端末ログ・ローカルの画像バックアップは公開対象から除外した。
