# グラスv521・スマホv175 公開前セキュリティ・プライバシー検査

2026-10-14。現行の公開候補ソース・画像・テスト、配布用のグラスv521／スマホv175 APKを検査しました。現在の公開候補と両APKについて、主要な秘密情報形式、既知の端末シリアル、個人PC固定パス、個人メール、PNGのテキスト・EXIFメタデータの混入は検出しませんでした。完全な無脆弱性・任意形式の個人情報不存在を保証する第三者監査ではありません。

## 検査と修正
- 実APIキー、GitHub／OpenAIトークン、AWSアクセスキー、秘密鍵の高信頼形式を検査。APKは全エントリを分割読取りし、ZIP整合性と署名を確認。
- Codex通知スクリプトの個人PC固定パスを、Git対象外のローカル設定へ移動。通知対象のプロジェクトを維持したまま、公開コードから取り除いた。
- ローカル認証・送信先／受領記録、Pythonキャッシュ、生成検証結果、録音・録画・暗号化データ、端末バックアップをGit対象外に追加。
- 録音全量、録画入力、会話ログ、予定・メール、認証トークン、署名秘密鍵、端末バックアップを配布物・Gitに含めない。公開する文字列の回帰試験は固定の合成入力のみ。
- Manifestのdebuggable=false / allowBackup=false、録音・後処理Serviceの非公開を確認。

## 通信・保存の確認
- TLSの正誤証明書、認証証明の改ざん拒否、AES-GCMの改ざん・別鍵・nonce、写真の移行／容量／保護、期限と24並行要求のペアリング、PC TLS相互運用を確認。
- 実HTTPS Web APIで未認証401・異なるOrigin403・不正モード／サイズ超過／転送SHA不一致の拒否、認証解除後の資格情報拒否を確認。
- Webの開始・終了・転送と実グラスの受領、合成MP4／WAVの暗号化分割転送と音声抽出、明示操作による合成音声だけのGemini後処理を確認。実会議や個人音声はこの検証で送信しない。
- Web APIからGeminiキー・Bridge用トークンを返さない。公開アセットは固定ファイルで、外部スクリプト／CDNは使わない。認証解除後の文字起こし再表示を防ぐ競合試験も合格。
- 音声・文字起こし・要約はKeystore暗号化。現在区間の一時PCMと日時・題名・TOPICコメント等のJSONは非公開領域で暗号化されない。録音だけでは全文をAIへ送らず、TOPICの送信と明示後処理を区別する。詳細は [プライバシー](../PRIVACY.md)。
