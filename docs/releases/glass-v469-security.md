# グラスv469 公開前セキュリティ・プライバシー検査

2026-10-12。今回公開するソース・画像・テストおよび配布用APKについて、下記範囲で公開を妨げる認証情報・個人データの混入は検出されませんでした。完全な無脆弱性を保証する第三者監査ではありません。

## 検査対象と結果

- 現在の追跡ファイル559点とAPKの128エントリを検査。実APIキー、GitHubトークン、OAuth秘密情報、秘密鍵、既知の端末シリアルを検出せず。
- 現在追跡される旧APKについても内部エントリをパターン検査。機能上の安全性・一般配布の適合性を認定したものではありません。
- ローカルに取得済みの全Git参照のテキスト差分124,797行について、削除行も含めて主要な秘密情報形式を検査し、該当なし。履歴中の全バイナリは対象外。
- 会話再生テストは外部入力ファイルを読むコードのみ。実際の会話入力、端末バックアップ、写真、署名鍵は公開ファイルに含めていません。
- PNGのテキスト・EXIFメタデータなし。全身キャラクター画像はアプリ用の画像素材です。
- APKのZIP整合性、署名、`debuggable=false`、`allowBackup=false` を確認。
- 写真共有Provider・撮影Serviceは非公開。アクセシビリティServiceはAndroidのBIND_ACCESSIBILITY_SERVICE権限で保護。MainActivityの公開はランチャー用途。
- Bridgeの機能通信は証明書を固定したTLSへ変換。HTTPは公開証明書の発見用で、トークンを送らず、証明検証失敗時に平文へ戻りません。
- Geminiへの送信はHTTPS。通常会話・必要なコンテキスト、カメラAMBを有効にした場合の画像などは外部送信されます。詳細は [プライバシー](../PRIVACY.md) を参照。
- TLSの正誤証明書、認証証明の改ざん拒否、AES-GCMの改ざん・別鍵拒否、写真の旧形式移行、容量・保護、ペアリングの期限・並行要求について回帰試験合格。

## 検査に伴う修正

- セキュリティ回帰スクリプトに必要なAndroid JSONクラスの参照を追加。Android SDKの場所をパラメータで指定できます。
- 全身画像検査スクリプトから個人用PCの固定パスを除去。
- 開発用署名APKをそのまま公開せず、専用RSA 3072-bit配布鍵で署名。秘密鍵・パスワードはローカルに保管し、Git・Releaseへ含めていません。
- 署名に関係しない全APKエントリの名前とSHA256が、グラスに導入済みのv469ビルドと一致。

## 配布用APK

- ファイル: `DennouHishoLoki-glass-v469-release.apk`
- SHA256: `e2700e41f7eb47fa8da744020ba1d786643101adb149aa5a2d8a169d999302e2`
- 証明書SHA256: `4022edbcdf7973743f1fda819afd281f6fd4abd12e9886896206ac1e57a791d7`
- 証明書名: `CN=Loki Distribution`

配布用はグラスに導入済みの開発用署名APKと署名が異なり、既存の開発用版へ上書きできません。この配布用APKを装着端末へ新たにインストールした検証は行っていません。既存端末はそのまま維持しています。署名を変える目的で既存アプリをアンインストールしないでください。Keystoreの写真鍵は引き継げず、保存データを失うおそれがあります。

## 残るリスク・範囲

利用者が入力するAPIキー、会話・撮影・位置情報の扱い、強い権限の許可、認証済み共有端末の管理は引き続き必要です。Androidの自動バックアップ無効は独自バックアップや共有先のコピーまで禁止するものではありません。`usesCleartextTraffic=true` は証明書発見用HTTPのために残っています。通信先の全組合せ、侵入試験、機器固有の脆弱性、全Git履歴の任意形式の個人情報、旧Releaseの全バイナリまでは検証していません。

以前のAPKは今回の対策を含まない履歴用成果物です。新規導入に推奨しません。公開パターン検査は未知の形式の秘密情報まで検出する保証ではありません。

参考: [Androidの署名](https://developer.android.com/studio/publish/app-signing)、[テスト・デバッグ機能のリスク](https://developer.android.com/privacy-and-security/risks/test-debug)。
