# グラスv485：動作・縮尺と会話反応の改善

グラス0.9.306-troubled-reaction。スマホv165・Audio Relay v20は変更していません。

- 待機・会話中の呼吸、重心、衣服、グラスの付け外しと姿勢間の補間を強化。サイバー障害等20場面を会話の条件へ接続。
- 立位・低姿勢の顔基準と描画時の縮尺を調整。手足の重複を画像監査し、修正素材を採用。
- 「しゃがんで」「しゃがめ」「かがんで」「腰を落として」を直接の姿勢指示として処理。「立ち上がって」で特殊場面を解除。
- 困る・戸惑う返答は困惑画像を選び、誤った笑顔タグに引きずられないよう調整。明確な制止の表情は区別。
- 読み上げ用の短い発声と読点の連発を整形し、通常語の促音を保持。返答は通常200文字前後を目安。
- SET先頭に明るさ、全身／顔は押すたびに切り替え。

## 検証範囲

109ソースのビルド、25組のホスト回帰試験、署名と93対象素材のAPK内ハッシュ照合が成功。v483では実機230枚・20場面と既存姿勢を検証。最終v485では直接しゃがむ4種・立ち上がり・困惑優先・発声整形を実機表示経路で確認し、24枚・6組すべてに画像変化があり、重ね描画は1層でした。検証後の設定復元、通常起動、対象プロセスのAndroidRuntimeエラーなしを確認。

会話文を表示経路へ入力した検証であり、音声認識→クラウド→発話の全経路や、聞こえ方・装着時の光学像を確認した記録ではありません。生成指示による言い回しは全回答を保証しません。
