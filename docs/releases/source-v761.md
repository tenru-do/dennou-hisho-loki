# ソース更新：グラスv761・スマホv322

v757/v321以降の変更です。公開配布APKの更新ではありません。公開署名APKは引き続きglass-v757のリリースを参照してください。

## KEEP・READ
- 自動露出モードで17時〜翌6時台の暗い場面を従来より明るく補正。v759の追加2ステップから、v761では追加4ステップへ変更（v759比でさらに2ステップ）。1ステップは端末の露出補正単位。+2EV・機器の補正範囲・白飛び・遅いシャッター・高ISO等の制限が優先され、条件によって増分は制限されます。
- READのカメラ優先要求を描画休止より前へ移動。READ等の取得待ちを最大12秒とし、非同期解放が旧3秒を超える場合も待機。KEEPの取得待ちは従来どおり3秒。
- JPEGの到着が撮影完了通知より先になる場合でも、露出補正用の次の撮影要求を重ねないよう順序制御。
- 写真取り込みで固定された旧スマホIPを使わず、既存の認証付き接続先復旧経路を利用。
- 接続未確認の待ちと保存状況を区別し、ブラウザーは保存完了後に一覧を一度更新。選択中・閲覧中の操作を優先。

## キャラクター画像・動作
- 通常待機を読取り状態と区別し、立位の手振り・手招き等の待機動作を追加。
- 通常座位で手動指定を維持していても、脚動作の時計を毎フレーム初期化しないよう修正。自発的な脚動作の間隔を45秒から30秒へ短縮。
- グラス用の白黒・ラインアート220ファイル（113,699,474bytes）と、スマホ側の不要コピー23ファイルを削除。旧ラインアートの読取り処理と自己紹介用の旧登録も整理。
- 現在のカラー画像の顔・体格・縮尺は変更していません。

## 検証
- グラスv761の開発ビルド、昼夜・露出保護98,308項目、既存露出8,312項目、READ/AMB97項目、カメラ優先33項目、待機動作52項目を通過。
- Webの写真一覧・再接続・完了時更新は33項目の隔離ブラウザー試験を通過。実サービスへの送信なし。
- v761の端末適用、既存アプリデータの更新前後ハッシュ一致を確認。新しい撮影・録音・外部AI呼出しは今回の適用では実行していません。

## 継続中の制約
メーカーの診断ログが再起動後に再開する問題は恒久解決していません。写真削除後の容量減少を、KEEP原本だけの問題またはすべて診断ログの問題と断定していません。本ソース更新で再発しないとの保証はありません。
