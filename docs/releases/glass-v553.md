# グラスv553・スマホv203：複数画像・動画の添付

2026-10-18。グラスv551・スマホv199からの更新です。

- 画像・動画を会話のそばへ添付。PCではファイルのドラッグ、複数選択、画像の貼り付けに対応。後から加えた画像が先の画像を置き換える問題を修正しました。
- 合計6件まで、動画は最大3本。動画は1本2分・50MBまでで、端末内で各8場面の抜粋へ変換します。全場面・音声の解析ではありません。
- 添付番号・枚数を解析側へ渡し、無関係な画像もそれぞれ分けて説明します。動画内の場面と、別の添付を混同しない指示を追加しています。
- Googleフォトで開いた画像のドラッグから、実画像URLを取り込めます。サムネイルやページリンクのみで画像情報が渡らない場合は対応しません。受信状況・取得失敗を添付欄に表示します。
- スマホの写真選択・共有、動画との混在、暗号化下書きからの復元にも対応しました。

詳細は [添付の使い方・制限](../MEDIA-ATTACHMENTS.md)、[公開前検査](glass-v553-security.md)、[プライバシー](../PRIVACY.md) を参照してください。

Edgeでの複数添付・送信、スマホ実機でのMP4場面抽出と順次追加・復元を確認しました。合成したバス画像と予約票によるGemini検証では、順序を入れ替えても両方を分けて認識しました。実機の更新前バックアップ・SHA256/ZIP整合性・署名・インストール済みAPK一致・起動も確認済みです。全形式・全動画・全画像の認識精度や装着時の確認を保証するものではありません。

公開APKと接続済み開発端末のAPKは署名が異なります。配布署名へ切り替えるために既存アプリをアンインストールしないでください。設定・会話や復号鍵を失う場合があります。

配布APK・チェックサム・検査記録は [GitHub Release glass-v553](https://github.com/tenru-do/dennou-hisho-loki/releases/tag/glass-v553) に掲載します。
