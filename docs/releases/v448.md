# v448 AMBコメントと画像の連動改善

環境音・カメラ・両方のAMBのコメントを通常2〜4文、90〜180文字目安、最大220文字にした。短い観察は1〜2文でよく、情報がない場合は従来どおりNONEとする。何に反応したか、ロキの感想、必要なら一つの気づきを述べる。入力にない音・映像・人物の感情は推測しない。リクエスト間隔と同意・送信範囲は変更しない。旧BT音声の文言・検証表示形式は維持する。

AMBの受信成功ステータスの緑色が笑顔へ自動変換されていた。AMBでは状態表示による表情変更を止めた。観察結果の感情と強さを内部メタデータへ登録し、顔・全身の発話途中でも保持する。通常会話の古い入力をAMBの顔判定へ流用しない。全身の観察反応に対して単語分類から照れ等を上書きしない。

喜びと笑いを区別し、笑う動作はコメントに笑いの表現がある場合にする。座位待機から拒否の腕組みを外し、静かな思案と正面待機へ変更した。立位の待機候補も穏やかなものにした。立位・座位の定期切替周期は変更せず、AMBのコメント後の休止姿勢も現在の姿勢を引き継ぐ。瞬き・呼吸・繋ぎ画像は維持する。

## 検証

6件のホスト試験に合格。コメントと感情・強さの保持、発話分割、10分相当の待機選択、立位・座位の不変性、既存の顔・全身の意味反応を確認した。全身の姿勢不変性試験は781920ケース。ビルドは84ソース、errors=0 / warnings=0。

実機では実際のMainActivityとFullBodyMascotViewを使い、緑色の受信状態と黄色の待機状態が笑顔を注入しないこと、発話分割後も観察した思案が照れに変わらないことを確認した。検証用データを使用した試験であり、実際のお笑いライブやGeminiの音声・映像理解品質、装着時の見え方まで確認したという意味ではない。

更新前のAPK・アプリ設定・写真をバックアップしハッシュ照合後、同じ署名でグラス448へ上書きした。搭載APKのSHA256一致も確認した。写真暗号鍵は書き出せないため、暗号化写真だけのコピーでは他端末に復元できない。アプリの初期化やアンインストールは行っていない。スマホ152は今回変更していない。端末上の一時バックアップと検証用アプリを削除し、ロキを再起動する。
