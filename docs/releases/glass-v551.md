# グラスv551・スマホv199：会話・VOICE・画像活用の更新

2026-10-17のソース・APK更新です。機能は段階的に実装・限定検証したアルファ版です。端末や通信環境に依存し、すべての組合せ・長時間動作・装着時の見え方を保証しません。専用配布署名のグラスv551／スマホv199 APKをアルファ版として配布します。

## 主な追加・改善（前回v521/v175以降）
- グラスのREAD撮影、スマホの撮影／画像選択、PC・タブレットの添付画像から質問。解析結果を会話の続きで参照し、カレンダー登録は内容確認と実行を区別する。READ写真の暗号化保存・スマホギャラリーへのコピー、取得済み日時・位置の印字にも対応。
- 会話から画像／短い動画の生成・継続編集を振り分ける。採用済みのロキ画像を本人参照へ利用。安全停止・不明な受付結果からの自動再生成はせず、動画は同じ受付IDの結果確認を再開できる。生成には対応API・権限・課金条件が必要。
- VOICEは最長60秒の区間、2.2秒の無音待ち、認識した内容の確認・修正に対応。前区間の認識中も次の録音を受け、上限付きキューで順序を保つ。スマホの分割認識で冒頭・中盤・末尾を保持する。
- 通常会話の継続窓を12分から2時間へ変更し、過去の対象・条件を引き継ぐ。訂正後に聞き返すだけの回答を一度だけ補正。安全停止の入力・失敗応答は共有会話履歴へ保存しない。
- グラスとスマホで共有する経路候補、公共交通の開始地点・乗車判定、経路表示・目的地情報を改善。現実の全路線・全移動場面を検証したものではない。
- KEEPとTOPIC画像処理の競合を抑制。撮影付随情報が壊れても元データを退避し、写真本体の認証・ハッシュ照合を維持して個別に取り込む。過去削除の応答ではグラス原本を消さず、再取り込みを除外。
- スマホの会話・ログ・画像質問を近くへ配置し、ナビ等を折り畳み。入力欄とキーボードの調整、写真一覧200枚とページ下部の選択・保存・削除操作、対応再生アプリでのBluetooth30秒移動、座り姿勢の首と胴体の補正。
- Windowsタスクバー向けUSBランチャーの公開用ソース。個人設定・端末証明書を含めず、BOM付きUTF-8、PowerShell 5.1の構文、実行ファイル起動の検査を用意。

## 検証と資料
会話・音声・生成意図等の12テスト群、TLS・暗号化保存・ペアリング・写真保持、未認証Web API拒否、スマホビルドを確認。グラスv551の文脈継続は隔離した実機設定で確認済み。公開用ランチャーは構文・異常文字コード拒否を確認し、個人設定済みの実ランチャーは実起動とWeb応答も確認。
