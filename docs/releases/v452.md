# KEEP写真の暗さ：v452露出安定待ち

確認済み：RECはカメラを毎回開いて最初のJPEGを直ちに保存していた。スマホのデコードは向き補正のみ。転送受信はSHA256で照合し、RECはハードウェアJPEGを再圧縮せず保存する。暗さの原因は未確定で、露出収束前の撮影が候補。

修正：RECだけAE_MODE_ONを明示し、最低2枚のウォームアップ画像を保存せず閉じる。収束状態に応じ、最大6枚または1.5秒の追加フレーム範囲で最終JPEGを採用。全体の8秒待機上限とカメラ所有権・close処理を維持。TOPICの撮影経路は従来どおり。ウォームアップ画像はJPEGバッファをコピー・Bitmap化しない。追加診断LokiRecorderExposureはAE状態、露出時間、ISO、ウォームアップ枚数を記録。

未確認：実機で明るさが改善するか、暗所・逆光での撮影、連続撮影間隔への影響。元写真には補正を適用していない。既存の暗い写真も書き換えていない。

実機手順：グラス接続後、端末・アプリ名・バージョン451を確認し、APKと写真を含むアプリデータをバックアップしてハッシュ照合。それからv452を更新。明所/暗所それぞれでRECを撮影し、LokiRecorderExposureとLokiRecorderTimingを確認。KEEP→一括転送→スマホJPEG保存を比較する。本人が装着して撮った写真の品質は別途確認する。
