# グラスv646・スマホv288：操作導線とキャラクター反応

v640/v288のリリース候補に対するグラス側の追加更新です。スマホ・タブレットの版はv288のままです。

## 変更

- TOPのPLAY／PAUSEの隣へBT30を復帰。押すと接続端末で優先される操作可能な再生セッションへ30秒送りを実行します。途中のアプリ選択は表示しません。アプリ選択・30秒戻し等の詳細操作はSETに残しています。
- 既存のTOP配置を保ち、一度だけBT30を追加します。追加後に利用者がSETへ移した場合は、その選択を維持します。
- ナビの「予定から目的地」を「目的地を指定」の直下へ移動。NAVの画面モード最下段に「ナビを閉じる」を追加し、明示的な停止を要求します。
- TOP・設定・選択ダイアログのボタン確定時に、顔・全身の短いリアクションを追加。PLAY／PAUSEも同じ仕組みを使用します。フォーカス移動や無効ボタンでは実行しません。
- 通常はうなずくような動きと待機顔への微笑み、直近の発言に接触の文脈がある場面では元の表情を保った小さな身引きの動きにします。非接触・中止・話題変更の表現は除外します。カメラによる接触検出ではありません。
- 反応は約0.9秒で終了。会話の表情・全身姿勢・読み上げの状態を変更せず、連打では最新の反応へ置き換えます。メニュー終了後や表示モード切替後にも見えるよう、操作処理後に反応し、表示保持を更新します。

既存の顔37種・全身443フレームを使用し、新規画像は追加していません。

## 検証と限界

- v646の開発ビルド：256ソース、エラー・警告0。
- v646 APKに対するAndroid隔離検証28項目が成功。リアクションの期限・重複・会話表情保持・無効ボタン・PLAY継承・ナビの配置等を確認。
- 接触文脈の判定19ケースが成功。実際の身体接触や新規AI会話による確認は行っていません。
- BT30の直接30秒送りはv642で実機確認。ナビ配置はv644、顔の反応・復帰はv645、全身の反応・復帰はv646で実画面確認しました。以前の結果をv646で全機能再実行した記録とは扱いません。
- v646をグラスへ適用し、APKハッシュ・署名一致を確認。既存データ415ファイルと外部写真1913ファイルの内容保持を初回起動前に確認しました。
- 最初のv646更新は更新前APKのUSBバックアップ段階で停止し、アプリ置換前でした。新しいバックアップ先で再試行して成功しました。
