# グラス v606 / スマホ v253

Androidメガネ・スマホ版の使い勝手を更新し、配布APKも現在の機能へ揃えました。

- スマホに質問が入った時、既存の認証済みTLS接続でメガネの確認を促します。従来の3秒間隔の確認も残し、依頼の受理・重複防止・中止の扱いを維持します。
- 内容を保存しない処理時間を追加しました。スマホの「ロキの状態・回答診断・メモ・会話の続き」で、グラス受理後のモデル開始・最初の表示・音声送信までを確認できます。音が実際に鳴る時刻は取得していません。
- メガネのSET →「トップのボタンを編集・SET内の操作」で、ボタンを先頭へ移動・トップから外す・戻すことができます。外した操作も同じ設定内から開け、SETは常に残ります。標準配置にも戻せます。
- メガネのSET →「読み上げ辞書」で、1行に `単語=よみ` を保存できます。50件まで。このメガネ内で暗号化し、音声へ渡す時だけ適用します。表示・元の回答・履歴は変えません。
- スマホの「添付・その他」→「写真・記憶・共有」→「仕事・相談ごとの参照セット」で、選んだメモ・会議要約・画像の読み取り文などを相談ごとに保存できます。最大20セット、各6件、見出しと本文は合計1800文字。保存時点のコピーで、自動更新・自動送信はしません。元データを削除してもセットのコピーは残ります。不要なセットは明示的に削除してください。写真の画素は含まないため、画像そのものが必要な場合は従来の添付を使ってください。
- 写真添付時に端末内で暗さ・細部の少なさを確認します。スマホでは送信前に確認、Webでは添付欄に案内を表示します。無地の絵でも案内が出る目安で、認識精度の保証や自動送信拒否ではありません。撮り直すか、そのまま送るか選べます。
- 配布用APKを既存の配布証明書で署名しました。開発署名版とは互換性がありません。署名変更のためにアンインストールしないでください。

## 待ち時間の実測

同じ約200字の合成質問を変更前後で各3回送信しました。USB経由HTTPS、Edge 1024×1366、短い回答・途中表示ON、完了後15秒空ける条件です。

| 指標 | v605 / v252 | v606 / v253 |
| --- | ---: | ---: |
| 最初の文字のブラウザ描画・中央値 | 7.1秒 | 6.5秒 |
| スマホ受付からメガネ受理・中央値 | 2.3秒 | 1.6秒 |

描画時刻はDOM追加後2フレームです。一部の暫定表示は画面外にあり、物理タブレットで実際に文字が見えた時刻ではありません。各3回の少数試験で会話文脈とモデル処理の揺れがあるため、短縮幅を保証しません。プロバイダー内部の最初のトークン生成時刻も未計測です。

## 更新手順

1. ロキ内の録音・連続撮影を止め、ロキのバックアップ機能で必要な記録を保存してください。
2. [GitHub Release glass-v606](https://github.com/tenru-do/dennou-hisho-loki/releases/tag/glass-v606) の対応APKとSHA256を確認します。スマホ用とメガネ用を入れ違えないでください。
3. 既存の配布署名版には上書き更新します。開発署名版の端末には配布APKを上書きできません。同じ署名の版を使い、アンインストールで切り替えないでください。
4. 更新後に起動し、会話・記録・接続・設定を確認してください。旧版への戻しと保存形式の互換性は保証しません。

実機上の隔離検証576項目、Web回帰289項目、合成画像のブラウザ検証5項目を通過しました。接続端末には開発署名版を上書きし、更新前バックアップ・署名一致・APKハッシュ・起動前の既存ファイル保持を確認しました。公開APKはその検証版とコード・資産が一致し、Manifestはデバッグ無効化の差分です。旧配布版からの実更新、全機能の長期運用、装着時の見え方と音声辞書の聞こえ方は未検証です。
