# グラス v607 / スマホ v254

回答の冒頭が見えにくい、送信待ちをスマホで直しにくい、待っている理由が分からない場面を改善しました。

## 変更と使い方

1. **回答の冒頭を入力欄のすぐ下へ。** Webの暫定・確定回答を設定パネルより上に表示します。送った質問に対応する回答だけを目立たせ、次の質問を送った後に前の回答が届いても混ぜません。過去ログを読み進めている時や次の文章を入力中は表示位置を奪わず、「この質問の回答を見る」で冒頭へ戻れます。長い回答は枠内で読め、全文は履歴にも残ります。
2. **スマホでも送信待ちを編集・取り消し。** 上部の「送信状況」または設定の「送信待ち・待ち時間」で、スマホ・Web共通の会話テキストを選べます。メガネが受理する前だけ本文を差し替え・取消できます。受理と競合した場合は拒否し、元の処理を続けます。元の送信控えは画面内の「送信控えを開く」から確認できます。画像添付・画像や動画の生成はこの編集の対象外です。
3. **待っている理由を表示。** Webの送信した質問のそばと、スマホの送信状況に、接続確認中・前の質問の完了待ち・送信間隔の待機・受理済み・AI処理中を表示します。古い接続情報は現在の処理と断定せず、送信間隔の秒数を回答完了予測として表示しません。
4. **参照セットを元の記録と比較。** 「仕事・相談ごとの参照セット」から保存したセットを開き、「比較・管理」→「元の記録の変更を確認」で保存時点と現在を比較できます。選んだ項目だけ更新し、未選択のコピーは残します。比較後に元の記録やセットが変わった場合は上書きを拒否します。削除・対象外・読み取り失敗は区別できない場合があり、自動更新・自動送信はしません。
5. **スマホでメガネの辞書を編集・試聴。** 設定の「メガネの読み上げ辞書・試聴」で、保存済み辞書を読み込み、メガネへ保存要求できます。反映結果を確認して開き直し、短い試聴文を明示的に送れます。編集中の未保存辞書では試聴せず、メガネ側で変更済みなら上書きを拒否します。1行に `単語=よみ`、50件・8000文字まで。試聴は原文160文字・変換後500文字までです。表示や履歴は変わりません。
6. **トップ配置のプリセット。** メガネのSET →「トップ配置プリセット」から会話中心・撮影中心・移動中を選べます。確認後に配置だけを変更し、録音・撮影・再生・ナビは開始しません。SETは常に残り、従来のボタン編集から標準配置へ戻せます。
7. **更新確認と更新前チェックを一画面へ。** スマホの設定 →「アプリ更新・更新前チェック」で、端末の版と署名、公開版の対応APKとSHA256、空き容量、直近のメガネの録音・撮影状態、バックアップの範囲を確認できます。GitHub確認はボタンを押した時か、利用者がONにした起動時1日1回だけです。自動確認は初期OFFです。自動確認はバックグラウンド常駐ではなく、ロキを起動した時に行います。APKの自動ダウンロード・インストールはしません。

## 保存・更新時の注意

- 辞書はメガネに暗号化保存し、スマホに届く辞書の状態も既存の暗号化保存を使います。反映と試聴の要求には期限があります。聞こえ始めや実際の発音の良否を自動判定する機能ではありません。
- 参照セットは元の記録と独立したコピーです。元データを削除してもセットのコピーは残ります。不要なコピーはセット側でも明示的に削除してください。件数・文字数の上限は従来どおりです。
- 既存の暗号化バックアップ機能はメモ・記憶の参照コピー・保守画面の表示設定が対象です。写真・録音・会話全文・認証情報・参照セット・メガネの辞書は含みません。必要な記録を個別にも保存し、復元内容を確認してください。書き出し記録があっても復元確認済みとは表示しません。
- 公開情報のSHA256表示は、取得後のAPKの署名検証完了を意味しません。配布署名版と開発署名版を区別し、署名を切り替えるためにアンインストールしないでください。

## 検証

- 両アプリのビルド・保護プロンプトの検査（メガネ20区間・スマホ2区間）を通過しました。
- 最終APKの実クラスによる別UID・権限なしの隔離Android検証630項目、既存Web回帰289項目、新しい会話画面のWeb検証23項目が成功しました。これらは合成データのみで、モデル要求や音声再生は行っていません。
- 接続した実端末に上書き更新し、更新前バックアップ、署名とAPKハッシュ、起動前の元ファイル保持（メガネ408件・スマホ151件）を確認しました。
- インストール済みスマホの設定・送信状況・辞書画面を開き、実際のGitHub公開情報の取得、自動確認OFF、開発署名への注意表示を確認しました。APKはダウンロードしていません。
- 合成語の辞書保存・メガネへの反映・試聴要求を実通信で確認し、元の辞書へ復元しました。実際に聞こえた発音の評価はしていません。
- 通常のロキ経路で同じ約200字の合成質問を3回送り、3回とも最初の暫定表示が画面内にあることを確認しました。最初の文字の描画は5.4秒・6.3秒・5.8秒、中央値5.8秒でした。USB経由HTTPS・Edge 1024×1366・短答・途中表示ONです。DOM追加後2フレームの観測で、物理タブレットや装着したグラスの見え方、モデル内部の最初のトークン時刻は測っていません。少数試験で文脈やモデル処理に揺れがあり、短縮幅を保証しません。
- スマホの配信資産8件が最終ソースと一致し、診断情報に辞書を含めないことを確認しました。一時接続と転送ポートは解除しました。
