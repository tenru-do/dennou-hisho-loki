# グラスv596・スマホv240 ソース更新

2026-10-20。公開済みv580/v225以降のソース・テスト・運用文書を更新。新しい配布APKはこの更新に含まない。既存の専用署名配布版はv553/v203、端末上の開発署名版と区別する。

## 主な変更

- VOICE/TOPIC/AMBとBluetooth音声の併用、停止処理の所有者判定、ニュースの導入句、会話の短い追加質問と指示対象の保持を改善。
- スマホのコメント欄・ログ・キーボードの配置、画像入力検査、添付/本文の復元、送信状況、進行表示と復旧案内を改善。
- 安全性・出力上限などの停止理由を区別し、不確かな処理結果を完了や自動再送として扱わない。
- ナビ情報の受信・位置の鮮度、写真や録音の保存量、容量/負荷状態を確認する画面を追加。
- 音量プロファイル（初期OFF）、熱・電池などによる撮影負荷の制御、対応設定の取り消し、会議要約からの保留候補、画像の指定箇所についての質問を追加。
- 会話・会議要約・画像読み取り・受信箱を端末内で横断検索。読み取りの原文と訂正履歴を分けて保持。
- 録音中の「ここ重要」しおりと、しおり位置からの明示再生を追加。
- 静かな時間（初期OFF、通知/TOPIC/AMBを表示のみ）と、端末内の出発前チェックを追加。
- PCの画像アニメーション検品ツールを追加。目・口・縮尺・顔と胴体の相対ずれなどを数値比較し、候補から再生/拡大/目視確認へ進める。通常の描画へ検査負荷を追加しない。

[音量・負荷など](../TUNING-v595.md)、[記録機能の操作と保存](../RECORDS-v596.md)、[自動検品の使い方](../ANIMATION-AUDIT.md)、[運用一覧](../OPERATIONS.md)、[保存と送信](../PRIVACY.md)を参照。

## 確認範囲

公開前に既存のローカル回帰、保護プロンプトのベースライン、TLS・ペアリング・暗号化保存の検査を実行。記録機能の隔離端末試験は51項目成功。新しい検品ツールの合成テスト21項目、画面操作22項目成功。これらの実行中に新しい外部API送信・実撮影・実録音・予定登録・画像動画生成は行っていない。

アニメーションは同じAPKをスマホの隔離Canvasで全480系列・10,855コマ、グラス実機では立位/座位の代表69コマを別々に確認。4系列は登録顔領域不足で未判定。検出なしは自然さの合格を意味しない。グラス実機の全480系列、全会話の回答品質、全Bluetooth機器との互換性、装着しての長時間動作を今回確認したとは扱わない。

以前の許可済み実API確認の範囲は個別の版の文書に記載し、今回のオフライン回帰と区別する。
