# v553/v203公開前のセキュリティ・プライバシー確認

2026-10-18。対象は今回の公開候補ソース・テスト・利用手順と、グラスv553／スマホv203の専用配布署名APKです。独立した侵入試験や無脆弱性の認定ではありません。

## 混入と通信・保存

- 公開候補の現行ツリーを走査し、主要なGoogle/GitHub/OpenAI/AWS資格情報形式・秘密鍵・既知の実端末シリアル・個人PCパスの混入は検出しませんでした。PNGのテキスト・EXIF付加情報も検出しませんでした。最終ステージにも別途検査を行いました。
- APIキー、署名秘密鍵、パスワード、個人写真・動画・録音、会話履歴、バックアップ、端末証明書、ブラウザープロファイル、実機検証の私的データは公開しません。
- Google画像の取得は認証後にだけ実行。実機の未認証要求は401、異なるOriginの要求は403でした。HTTPSの特定Google画像配信ホストだけを許可し、資格情報付きURL・任意ポート・フラグメント・過長URL・ローカルIP等を拒否します。リダイレクトは追跡せず、画像の形式・サイズ・画素数を制限します。Googleの画像取得へGemini APIキーやPCのCookieを渡しません。
- ドラッグHTMLはDOMへ挿入せず、不活性なtemplate内で参照します。リンクを勝手に開かず、画像URLがない場合も受信形式を表示します。
- 複数添付も従来の600KB JPEG、HTTP本文の上限、期限付き暗号化送信待ちを維持します。動画原本・動画音声はこの経路ではアップロードせず、8場面の画像を解析します。元の選択データを同時にすべて展開せず、動画は1本ずつ処理します。
- 端末内の最新ドロップ診断には時刻・形式名・件数・段階だけを保存し、写真URL・HTML・ファイル名・写真内容を保存しません。詳細は [PRIVACY.md](../PRIVACY.md) を参照してください。

## 検証範囲

- URL制限テスト、TLS証明書固定・改ざん拒否・AES-GCM・写真保持・一度だけのペアリング・PC TLS相互運用の回帰試験が成功。
- 会話・生成意図・VOICE等の12テスト群が成功。保護対象の通常会話プロンプトは基準一致を確認。
- Edgeで順次追加した2画像の両方がプレビューに残ることを画素でも確認。動画の順次追加・混在・件数付き送信、破損動画・上限超過時の添付保持も確認。
- スマホ実機で、架空MP4動画2本の8場面抽出・画像追加・件数と種類の保持・暗号化下書き復元を確認。合成画像のGemini解析では、バスと架空予約票の両方を正順・逆順で別々に認識しました。個人写真や保存済み会話・カスタム設定はこの検証で送信していません。
- 接続端末は開発署名版のグラスv553／スマホv203へ反映し、対象・署名・バックアップSHA256/ZIP整合性・インストール済みAPKハッシュ・起動を確認済み。全メディア形式、長時間の全機能同時稼働、装着時の確認は含めません。
