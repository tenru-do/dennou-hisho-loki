# グラスv605・スマホv252：会話・記録・保守操作の改善

2026-10-21。v596/v240以降のソース更新です。配布用署名の公開APKは引き続きv553/v203です。この更新の実機検証には開発署名版を使用しており、配布署名版への上書き用APKとして扱わないでください。

## 会話とタブレット

- 入力欄を上部に置き、添付はログ内の小さいプレビューで確認できます。質問IDと回答の対応、最新の依頼と以前の回答を区別します。
- 送信待ちの編集・取消・選択した未送信質問の統合、追跡対象の回答待ちの中止、受信・処理中・結果未確認の案内を追加しました。処理済みの外部操作やAPI料金を取り消す機能ではありません。
- 通常の追跡対象Web会話を途中表示し、短答／詳説とメガネの表示文字数を選べます。暫定回答は確定本文と区別し、切断したストリームを回答完了とは扱いません。
- v252では表示中の処理待ち・生成中に限り、状態取得の完了後の間隔を1秒から250msへ短縮しました。通信失敗時は最大8秒まで間隔を延ばします。古い状態取得結果が新しい履歴を上書きしないようにします。
- 暫定回答は同じDOM上で更新し、同じ質問IDの確定本文を取得したら同じ場所で切り替えます。完了通知だけでは暫定本文を確定扱いにしません。
- 定型文、任意の暗号化下書き保存、共有ログの検索、2枚の画像比較下書き、お気に入りと選択した会話のテキスト書き出しを追加しました。下書きの復元や比較の準備だけでは送信しません。
- 最新の対応回答の読み上げ停止・区切りからの再開、話題切替、再起動後の依頼照合、ログの段階読み込み、表示設定、本文を含まない診断情報を追加しました。読み上げは秒単位の任意位置からの再開ではありません。
- v605ではBT30をトップのボタン列からSET内へ移しました。30秒送り・戻しの制御処理自体は変更しておらず、接続先の音楽アプリでの動作を保証しません。

## 記録と日常操作

- スマホに「話す・記録・要対応・設定」の入口、設定検索、対応が必要な処理の一覧を追加しました。
- 読み取り訂正の会話下書きへの反映、会議しおりメモ、横断検索の絞り込みと原記録への移動、端末内メモ、会話の続きカードを追加しました。
- 会議タスクの出典保持・本文／担当／期限の編集・更新競合・履歴と取り消し、重複メモ／写真の整理候補、音声区間からの明示的な再生を追加しました。
- 保守画面、対象カテゴリの暗号化バックアップ、復元前の件数・重複・容量・更新検査、保守処理の同時実行制御、容量確認を追加しました。全写真・全音声・全設定・認証情報をまとめて移行するバックアップではありません。
- 転送予約と保存確認結果、任意の音なし結果通知、利用量の部分的な記録・利用者指定単価による見積り、ロキの状態一覧、負荷調整を追加しました。未確認の結果を成功や無料と扱いません。
- 顔座標の未判定だった画像4件を補正し、元画像の隠れた目や閉じた目を維持しました。元画像は変更していません。

詳しい対象と制限は [日常操作](../DAILY-EXPERIENCE-v600.md)、[保守機能](../MAINTENANCE-v599.md)、[履歴・同意・中止](../RELIABILITY-v598.md)、[確認・診断](../REVIEW-v597.md) を参照してください。これらは各実装時点の記録です。現在の版と最終検証は本書を優先してください。
