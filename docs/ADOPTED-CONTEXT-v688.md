# 採用42項目の統合実装（グラスv688・スマホv297）

直近7回の提案各6項目を統合。既存のv687までの実装を再利用し、不足箇所を補完。画像を枠に収めるための縮小案は撤回し、2026-10-29の指定「基準の縮尺を優先し、はみ出しは切り捨て」に置き換えた。新しい画像は生成していない。

## 検証上の範囲

曖昧な表現は、現在の姿勢・直前の操作・対応済みの表現から保守的に解釈する。任意の日本語表現すべてを理解できるという保証ではない。未対応や判断不能では維持・確認を優先する。

通信不能でブラウザー自体がページを開けない場合、古いIPのページ内に案内を出すことはできない。その場合はスマホの共有画面の新しいQR／リンクを使用する。

音声の終了タイミングは既存のアプリの再生状態に従う。Rokidから音声完了コールバックを取得できない経路では、既存の再生時間推定の制限が残る。

実際の移動、予定の読み取り、実会話・写真の外部送信、再生アプリの送り操作は今回の合成試験とは別。検証結果・端末更新は完了後に追記する。

## 最終検証結果

- 最終APK：グラスv688 / スマホv297。会話プロンプト保護と37画像アトラスの回帰ゲートを通過。
- ローカル：文脈・言い換え・指示順・切り取りの57項目を含む、既存の会話・画像・動作検証が成功。ニュース関連12項目成功。
- スマホ上の隔離パッケージで、グラス用APKとスマホ用APKの全回帰6403項目成功。実アプリの個人設定とは分離。
- 同じ最終グラスAPKをグラス上の隔離パッケージで確認：84項目成功。
- スマホでの合成RSS・予定の場所判定・復帰後の保留など8項目成功。Web再接続／自動POST再送をしない検査7項目とJavaScript構文検査も成功。
- 初期の検証失敗は成功に数えていない。旧フィット仕様と全画像キャッシュを前提にした試験を、固定縮尺・画面外描画の禁止・必要時の再読込へ更新。通常の入力が姿勢操作へ誤分類されないこと、寝姿の明示的禁止、隣へ座る従来の膝抱え、非表示中の設定保存、読み上げ開始での動作二重適用も修正して再検証した。
- native画像 `context-v688-native.png` と `comfort-v678-preview.png` を目視。立位・座位・寝姿の表示と、横に広い読書姿勢の切り取りを確認。
- 外部API、実会話／保存写真の送信、実際の録音・撮影、案内開始・メディア送りの実行は0件。
