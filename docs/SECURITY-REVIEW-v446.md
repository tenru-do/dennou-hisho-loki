# 公開前のプライバシー・セキュリティ確認

確認日: 2026-10-10。対象はv446公開予定ソース、画像、資料と関連する既存連携処理。GitHubへのプッシュ、端末へのインストールは行っていない。

## 公開ファイル検査

- 検査時点のGit管理対象449ファイルを走査。Google/GitHub/OpenAI/AWSの代表的な鍵形式、秘密鍵、メールアドレス、既知の端末シリアルを検査した。
- 既存の管理対象APK18本についてDEX・設定テキストも走査。上記の認証情報形式は検出しなかった。バイナリ全体の逆解析や全Git履歴の調査ではない。
- 追加PNG47枚に、テキスト・圧縮テキスト・EXIFチャンクはなかった。画像はキャラクター素材であり、実機の撮影写真を追加していない。
- 会話履歴、アプリ設定、端末バックアップ、録画写真、署名鍵は今回の追加対象に含まれない。回帰テストには拒否・耳への息などの短いシチュエーション例があるが、実会話履歴一式や個人識別情報は含めていない。
- ソース・手順書・テストスクリプトに残っていた端末シリアルを削除し、テスト実行時に接続先を明示するよう変更した。

## 修正

- 発話本文と認識前後の本文をLogcatへ出さない。文字数だけを記録する。
- Googleナビのリクエスト・応答本文・エラー本文をLogcatへ出さない。座標、目的地、経路情報の露出を抑える。
- プライバシー資料にAMB画像のGemini送信、REC写真の保存場所と保護写真の無期限保存、反応監査の限界、開発用デバッグ設定を追記した。

## 残る運用・配布上のリスク

| 項目 | 確認した内容 | 対応方針 |
| --- | --- | --- |
| LAN通信 | 既存連携はHTTPで暗号化されない。APIキー等を含む同期内容や共有トークンを盗聴される可能性がある | 自分のテザリング等の信頼できるネットワーク限定。一般配布前にTLS等を検討 |
| ペアリング | スマホの全インターフェースで待受。利用者が開いた60秒の窓で最初の要求にトークンを返す | 信頼できるLANでだけ開く。一般配布前に接続先確認や追加チャレンジを検討 |
| 開発APK | グラスはdebuggable=true。許可済みADBからアプリデータを取得可能 | 現在のバックアップ・開発手順を保つため今回は変更しない。一般配布APKは別途リリース設定を整える |
| 写真・監査 | 写真は未暗号化、保護写真は無期限。監査の感情・時刻・無塩ハッシュも機微情報になり得る | 不要データ削除、バックアップ管理。ハッシュを完全な匿名化と扱わない |
| AMB | 音声や画像をGeminiへ送る | オンにする場面と映り込みを利用者が確認する |

これらはソース公開による秘密の混入とは別の、アプリ利用・一般配布上の問題である。セキュリティが完全であるとの判断はしていない。

## 追加機能の境界

RECサービスはexported=false。通知のPendingIntentは明示的な宛先とIMMUTABLEを使用。写真削除は記録機能の命名規則に一致するファイルだけを対象とする。反応監査はアプリ内部領域で容量を制限し、本文を記録しない。通常のブリッジ要求には共有トークンを比較し、空トークンで通過しない処理がある。

## 検証の範囲

修正後のグラス78ソース・スマホ63ソースをビルドし、両方errors=0、warnings=0で完了した。今回の修正はソースのみに反映し、端末上の既存ログの削除や再インストールは行わない。既に公開済みの履歴に含まれる端末識別子は現在のファイルを直しても過去コミットには残る。全履歴の削除・書き換えは実施しない。
