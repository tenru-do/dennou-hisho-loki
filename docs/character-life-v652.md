# ロキの動き・操作反応と操作中の点灯維持（v652）

2026-10-25実装、2026-10-26にグラスv652を適用済み。公開APKはv651のままです。最終実機結果と誤操作の記録を末尾に記載しています。

## 変更

- 顔：既存の本人素材を維持し、視線を左右へ動かす、首を傾ける、うなずく、穏やかに微笑む待機変化を追加。聞き取り中・読み上げ中は別のうなずき周期。会話で指定された困惑・拒否などの表情は待機の微笑みで上書きしません。
- 全身：顔と足元を固定する既存メッシュ上で、短い肩・上体の仕草を追加。ボタン反応は3パターンで交代し、連打は最新の反応に置き換えます。
- スワイプ：キャラクター上の直接スワイプに方向別の短い反応を追加。直近3分の明示的な接触文脈では、触れられたように方向に合わせて身をずらす反応へ切り替えます。グラスの方向キーとして届くスワイプも、接触文脈中に視覚反応を重ねます。元の入力処理は消費・再送しません。
- 入力欄、ダイアログ内のスクロール、ナビ表示中の方向操作は接触スワイプから除外。小さな揺れ、2秒を超えるドラッグ、複数指、キャンセルは対象外。接触の中止・話題変更・期限切れを除外します。
- 点灯：目的地設定を含むダイアログの表示・キー・タッチ操作で90秒の点灯期限を更新。ダイアログのWindow.Callbackを透過的に中継し、既存の選択・戻る・閉じる処理を維持します。ダイアログ終了・アプリが背面へ移動・無操作の期限切れで保持を解除し、通常の表示制御に戻します。点灯期限中は既存のHUD消灯・減光処理から保護します。
- 負荷：ナビ／録音中は顔の追加仕草を抑制。短い動きの期間だけ描画間隔を細かくし、既存の非表示・背景時の停止制御は維持。新しい通信・センサー・画像ダウンロードは追加していません。

新規の画像素材は生成していません。既存の顔37種・全身443フレームの本人表現を保って、描画と動作のバリエーションを増やしています。
