## 使い方

- 全身モード：SET → 全身の仕草を確認
- 顔モード：SET → 顔の表情・仕草を確認

全身の一覧では、手を振る／手のひらで案内、耳たぶに触れる、甘えるように手を差し出す、誘うように手招きする、軽く近づく、長めに寄り添う、不意に近づく、めろめろで甘える、を確認できます。立ち姿・座り姿は現在の姿勢を保持します。

## 耳を触る癖・会話の反応

耳たぶを触る仕草は、待機中の2分ごとの短い癖として、手を上げて触れてから同じ手を下ろします。考える文脈でも使います。

「甘えて」「そばにいて」「会いたかった」「一緒にいて」「ロキ大好き」などのやり取りに、ロキ側の肯定的な返答が合った時に甘える動きを選択。「誘って」「誘惑して」等では手招きを選びます。やめて、普通に戻って、嫌だ、話題変更、拒否・強い困惑等では収めます。定義の質問、第三者への文面作成、ナビや仕事の通常の質問は対象外です。会話文脈は90秒で期限切れとなり、動きは短い間だけ表示します。

全身のキス差分画像の生成は、画像生成側の安全判定で停止しました。再試行せず、全身には生成済みの服装付きの仕草を使用し、近づき方・傾き・間の違いを表現します。全身に新しいキス画像を追加できた、という扱いにはしません。顔の4種類の差分は生成・登録済みです。

## 描画と保持

生成画像の段の境界は正確な半分とは限らないため、黒い行間を検出して切り出し、隣の段の足先等が混ざる問題を修正。ごく暗い背景ノイズは描画キャッシュで除去。頭・足元と手を広げる範囲を計測して、表示内へ収めます。PNG原本は変更していません。

素材は背景スレッドで読み込み、同じ素材を使うクリップはキャッシュを共有。非表示・終了で解放し、読み込み失敗時は通常の全身表示を使って60秒間の再試行を抑止。新しいネットワーク・センサー・常時ポーリングは追加しません。ナビや録音中は追加動作を抑えます。

既存の全身443フレーム、顔の従来素材、停止・再開・目的地設定中の点灯維持を保持します。
