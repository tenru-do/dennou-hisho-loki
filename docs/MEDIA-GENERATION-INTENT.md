# 会話からの画像・動画生成

スマホとWebは「生成した画像・動画」に一覧を統合。会話入力で画像・動画の種別を選ぶチェック欄は不要。

明示的な画像・動画指定を優先し、直近2時間の完了または処理中の生成文脈を使って省略された依頼を判断する。動画生成後の「セクシーにおどって」「では水着でダンスして」は動画依頼、「水着姿を描いて」は画像依頼として扱う。衣装・動作の新しい指定は前の指定より優先する。生成文脈のない曖昧な動作、機能の質問、予定操作などから有料生成を開始しない。

グラスにはペアリング先から種別と時刻だけを共有する。選択画像の「この画像から続ける」も同じ自然文判定を使用。プロバイダーのコンテンツ制限と、受理状況不明時・拒否時に自動再生成しない方針を維持する。

検証版: グラス538 / スマホ196。分類・参照画像と生成リクエスト構成・同時処理のロック・統合UI・既存動画再生・キーボードを検証。Webの生成受付はモック、新たな有料生成は実施していない。

グラス540 / スマホ197: 『ロキがおどってみて』『ロキが踊ってみて』『ロキ、ダンスして』など、本人を明示した動作の実行依頼は、過去の制作から2時間以上経過していても新規の動画依頼として扱う。本人の登録画像を参照し、時間切れの制作指示・衣装は継承しない。能力の質問、動作の説明、再生・削除・予定登録・否定の指示は生成しない。名前のない曖昧な動作依頼の2時間制限は維持する。
