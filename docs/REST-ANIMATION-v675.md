# v675: 修正版の寝姿とアニメーション

寸胴・頭が大きいと指摘された旧12/8コマは使用しない。基準だけから作り直した rest-master-proportions-v2.png、動作9コマ、表情4コマを採用。寝たまま手を振る画像4コマをbuilt-in image_genで追加した。原画・生成プロンプトは artwork/proposals/rest-concepts-20261027 と artwork/v675/rest-wave-prompt.txt に保存。

## 表示と操作

- 「ねそべって」で修正した寝姿へ。従来の全身表示と同じく通常時に全身モードへ切り替える。
- 「寝返りを打って」「寝たまま背伸びして」「寝たまま照れた身じろぎをして」「寝たまま手を振って」を端末内で解釈し、有限のキー再生と420msのつなぎ、胸元の小さな呼吸で表示。動作終了後は同じ修正した寝姿に戻る。静かな表示中は姿勢表示で上書きしない。
- 「寝たままキス顔にして」「寝たまま困った顔にして」「寝たまませつない顔にして」「寝たままこらえる顔にして」。表情は顔の部分だけを切り替え、元の胴体と脚を保つ。微笑みも同じ寝姿の追加画像から顔を取得する。まばたき・読み上げ時の小さな口の動きは既存描画周期に載せる。軽いキス顔の口は閉じたままにする。
- SET → 全身の仕草を確認 → 寝姿の表情・動作（修正版）でも選択できる。
- 通常の質問、読み上げ終了、待機時間切れで立ち姿へ戻さない。「動いてない」で直前の動作を再適用し、「戻って」で前の姿勢・表情へ一段戻す。立つ・座るの明示指示で通常表示へ戻る。

## 比率と描画

縦横を同じ倍率で拡縮する。曲げた脚や腕の位置で見かけの高さが変わっても、ポーズごとの外接高さに合わせて頭まで拡大しない。元画像のカメラ基準で合わせる。生成シートの行間は均等ではないため、実際の空白列・行を採寸した境界で切り出す（動作 y=0/483/978/1536、表情 y=0/747/1536、手振り y=0/741/1536）。

デコードは1本の背景処理で一度だけ行い、14の身体キーと6つの顔部分を保持。描画中の画像読み直し・新規Bitmap生成・追加通信・独立した常時タイマーはない。非表示では既存のView描画停止に従い、View終了時はキャッシュを解放する。原画は加工せず保存し、実表示時の切り出しとメッシュにより動かす。

## 検証

組み込み前の新規ソースを含む隔離Android検証1730項目成功。実Viewの要求→応答→音声開始/終了相当を通した保持、予算0のMainActivityによるローカル返答、4動作の時間変化、5表情で下半身ピクセルが一致、キャッシュ解放を確認。基準に対する手入力目印の比較では寝姿マスター・動作・手振りの標本が閾値内。頭・腕が切れないことと顔の位置は実描画プレビューも目視した。これは全コマの解剖学的な完全一致の保証ではなく、装着しての実マイクからの通し試験とも別。

最終APKと適用ハッシュ・データ保持・動画プレビューは作業側 outputs/rest-v675-* に保存する。外部AI API、実会話、保存写真、録音、撮影を使う検証は行っていない。最終成果の対象は上記の日常の寝姿・表情・仕草。
