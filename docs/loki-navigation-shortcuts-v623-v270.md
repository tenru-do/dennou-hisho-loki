# NAVIの呼び出し・表示・通信断対応：メガネv623・スマホv270

## 1. 行き・帰りを先頭から呼び出す

スマホNAVIの先頭とメガネのNAVメニューに「行きのルート」「帰りのルート」を追加しました。メガネでは、ナビ中以外でも「帰りのルート」「行きのルートを開いて」で登録ルートの選択画面を開けます。

事前にスマホの「よく使うルート・区間指定」からルートを編集し、ショートカット欄を「行き」「帰り」に設定して保存してください。初期登録はありません。複数のルートを同じ種類に指定した場合は一覧から選びます。

呼び出しただけでは検索・案内開始はしません。ルート、開始区間、検索の確認、候補、開始の確認という既存の手順を通します。途中から始める場合は、それ以前の区間を省略することを確認します。

## 2. 乗る便の行き先を表示

公共交通の経路に含まれる路線名・便の行き先・降車予定地点を区別して表示します。スマホNAVIでは上部の大きな文字、メガネでは公共交通の案内表示に加えます。候補の一覧にも便の行き先を付けています。

行き先は経路サービスから取得したheadsignだけを使い、降りる駅から終点や方面を推測しません。取得できない候補は「行き先：未確認」です。現在の乗車区間が確認できない場合は取得済みの次の乗車候補を示すもので、乗車済みや実際の運行を保証しません。降車後の区間では乗る便の表示を外します。

## 3. 通信が切れても保存経路を確認

確定した案内経路の最後の1件を、スマホと、受信できたメガネの各端末内へ暗号化保存します。保存対象は取得済みの経路線、区間・乗降地点などの参照情報です。現在位置の点や進捗は保存経路へ引き継がず、自動再開もしません。

- スマホ：NAVI上部「保存経路を確認（通信不要・閲覧専用）」
- メガネ：NAV「保存経路を確認（通信不要）」

経路取得時刻と保存時刻を分けて表示し、取得時刻がない場合は未取得と表示します。保存した線は概略図として見られますが、道路名を備えた地図や現在地表示ではありません。地図タイルのオフライン保存ではありません。

閲覧は通信不要です。保存データから新しい左右案内・乗降判定・運行情報は生成しません。再検索には通信が必要です。メガネがまだ経路を受信していなければ、そのメガネに保存記録はありません。

削除すると、その端末の最後の保存経路を削除し、以後の自動保存も停止します。再び有効にするには保存経路画面で選びます。スマホとメガネの保存・削除設定はそれぞれ独立しています。保存ルートの登録そのものは削除しません。

## 4. 移動手段に合わせた表示と案内

初期状態では移動手段に合わせた表示が有効です。自転車は短い操作案内を大きく、公共交通は乗降・行き先を中心に表示し、補足の読み上げを抑えます。重要な案内や位置・経路の未確認表示は残します。

公共交通へのアクセス・降車後の区間は、登録されている徒歩／自転車に合わせます。乗車中・降車後への移行は、既存の乗車・降車確認状態に従い、端末の動きから勝手に乗車と判定する処理は追加していません。

スマホの「徒歩・自転車の通知タイミングと表示」、またはメガネNAVの「通知タイミング・表示」で自動切り替えをオフにできます。オフにすると従来の「案内の詳しさ」を使います。

## 5. 区間と出口・駐輪メモを関連付ける

スマホで保存ルートの区間を編集し、「出口・駐輪メモを関連付ける」から既存のメモを選んで、区間とルートを保存します。写真のデータをルート内へ複製せず、メモのIDで関連付けます。関連付けの解除もできます。

検索候補の確認画面、自転車区間の開始後約2分以内、または指定した到着地点付近で、利用者メモとして名前と本文を表示します。メガネの案内中にも表示し、写真は従来どおりスマホで確認します。到着地点付近かどうかは鮮度・精度を満たす現在地で確認します。

削除済みなどで参照できないメモを、古い内容のまま表示しません。メモは利用者の記録であり、出口の開閉や駐輪場の空き状況は未確認です。

## 6. 徒歩・自転車の通知タイミング

スマホの「徒歩・自転車の通知タイミングと表示」、メガネNAVの「通知タイミング・表示」で、移動手段ごとに遅め・標準・早めを選びます。

- 徒歩：予告距離の目安は最大約80m／120m／180m。実際は取得した速度に合わせて変動します。
- 自転車：予告距離の目安は約150m／250m／400m。直前の案内は別の段階で判定します。

ナビ中の「もう少し早く教えて」は設定画面を開くだけで、確認するまで変更しません。メガネからの設定変更はスマホ接続が必要です。スマホの設定は既存のナビ受信時にメガネへ反映します。位置が古い・精度が不十分・経路更新中の場合は、設定距離に達しても古い方向を案内しません。

Googleマップ自身の通知距離や音声設定を変更する機能ではなく、ロキ側の案内を調整します。実際の通知タイミングはGPS更新間隔や移動状況でも変わります。

## 個人情報と検証範囲
