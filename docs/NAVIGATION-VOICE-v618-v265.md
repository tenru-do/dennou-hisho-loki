# ナビVOICE改善：メガネv618・スマホv265

2026年10月23日。両端末への最終版の適用完了。更新前データのバックアップ、署名、インストール後APKのハッシュを照合し、起動前にスマホ146ファイル・メガネ410ファイルの内容が変わっていないことを確認した。

## 変更内容

1. 案内中の「あとどれくらい？」「次どっち？」「もう一回」を、現在のナビ状態から短く回答する。Geminiを呼ばず、現在の残り時間・距離・次の案内を使用する。位置や経路が不確かな場合は、その旨を伝えて方向を断定しない。
2. VOICEの開始時、および継続録音で発話を検出した際に、ロキ自身のナビ読み上げを止める。会話・回答読み上げが落ち着いた後、最新の位置・次の案内が確認できる場合に再開する。会話中に通過した曲がり角の古い音声を読み直さない。再開待ちは45秒以内、個々の案内の待機は10秒以内。
3. 「その前にコンビニ」「途中で東京駅に寄って」「やっぱり上尾駅に行きたい」を変更希望として受け付ける。VOICEで確認し、「はい」でスマホの候補確認画面へ進む。候補検索・候補選択・経路確認・開始の操作を経て切り替える。声だけで候補を自動選択する機能ではない。
4. 音声案内を短くし、同じ経路・曲がり角の同一音声は20秒以内に自動で繰り返さない。利用者が明示した聞き直しは抑制しない。経路情報に交差点名や斜め方向が含まれる場合は、その情報を保つ。存在しない目印は作らない。
5. 「そっちじゃない」には、目的地と道順のどちらかを聞き返す。「目的地が違う」には変更したい場所を尋ね、「道順のこと」にはスマホで経路を確認するか尋ねる。聞き返し直後の「道順」「目的地」という短い返答にも対応する。変更確認は1件・60秒以内で、キャンセル、別の話題、経路終了・変更、時刻の巻き戻りでは確定しない。
6. 古い位置情報や精度不足、経路の再取得、次の曲がり角への移行を確認した際に、古い方向案内を停止・破棄する。新しい位置と経路が確認できるまで案内を保留する。

Googleマップ自身が再生している音声は、ロキの読み上げ停止の対象ではない。上記の発話割り込みはVOICEが起動している間に対応する。

## 使い方

案内中にVOICEで「あとどれくらい？」「次どっち？」と尋ねる。

目的地の変更は「やっぱり上尾駅に行きたい」→確認に「はい」→スマホで住所・候補と経路を確認して開始する。立ち寄りは「その前にコンビニ」から同様に確認へ進む。候補が曖昧な場合はスマホで地域や店名を補う。

変更を取り消す場合は確認に「キャンセル」と答える。
