# 通勤ナビの改善：メガネv622・スマホv269

## 個人情報

住所・勤務先・停留所などの個人情報は同梱・初期登録していません。保存ルート、出口・駐輪場所の記録は利用者が入力して明示的に保存します。保存先は端末内の暗号化ファイルです。地点候補や経路を検索すると、必要な地点情報が既存の検索サービスへ送られます。保存場所を地図で開く際も、選択地点が地図アプリへ渡ります。

## 1. 保存ルートを途中から再開

スマホNAVIの「よく使うルート・区間指定」からルートを選び、「途中から再開・区間の候補を確認」を押します。開始区間を選ぶと、それ以前の何区間を省略するか確認できます。メガネNAVの「よく使うルート・区間指定」でも区間を選べます。

現在地が選んだ区間の出発地点から離れている場合や、位置が古い場合は開始しません。現在地だけで区間を自動変更せず、候補の検索・開始は操作で確認します。

## 2. 駐輪・改札・駅構内移動の余裕時間

ルートの区間編集で、駐輪・改札・駅構内移動の余裕を、それぞれ0〜60分で指定できます。乗車する電車・バスの区間に必要な時間を設定してください。設定した合計時間は、経路中の各乗車・乗り換えに適用します。

候補に時刻表と徒歩所要時間が含まれる場合、検索時刻／前便の到着時刻から、徒歩移動と設定した余裕が取れるか計算し、足りない候補に警告します。余裕が不足していても自動除外せず、内容を確認して選択できます。開始前にも確認し、候補表示後に余裕が不足へ変わった場合は検索し直します。

時刻表や徒歩時間がない候補、平均所要時間だけの候補は「未確認」と表示します。遅延・運休や実際の乗車可否を保証しません。保存ルート全体を未来時刻で一括予約する機能ではなく、利用する区間ごとに検索します。

## 3. 乗り遅れ時の候補確認

スマホNAVIまたはメガネNAVの「登録区間で乗り遅れた」を選ぶか、ナビ中に「乗れなかった」「乗り遅れた」と話します。

現在の登録区間が電車・バスで、乗車前の状態である場合に利用できます。確認すると案内を一時停止し、登録した交通手段・乗降地点・路線を保って、現在地・現在時刻の候補を取り直します。候補と開始を確認するまで別の便へ切り替えません。乗車中・降車後の状態ではこの操作を受け付けません。現在地が登録区間の出発地点から離れている場合は、適切な区間を選び直します。

検索が失敗した場合も、一時停止が自動解除されたとは扱いません。表示を確認して再開してください。残りの各区間は利用時に検索し直します。

## 4. 出口・駐輪場所の写真とメモ

スマホNAVIの「出口・駐輪場所の写真とメモ」から、名前・メモ・任意の地点・任意の写真を登録できます。地点は現在地を明示選択するか、候補を検索して選びます。写真とメモだけでも保存できます。

写真は利用者がファイル選択で指定したものを縮小し、JPEGへ再圧縮して、メモとともに暗号化保存します。8MB以下の入力画像、保存画像は256KB以下、記録は最大12件です。自動撮影・AIへの画像送信は行いません。保存前のキャンセルは記録を残しません。

メガネNAVの「保存した出口・駐輪場所」では名前とメモを呼び出せます。写真はスマホで表示します。保存した情報は利用者のメモであり、現在の開閉・利用可否を保証しません。地図表示・編集・削除はスマホから操作できます。

## 5. 短いナビ確認

ナビ中の「次は？」「あと何駅？」「どこで降りる？」に、現在のナビ情報から短く返します。スマホNAVIとメガネNAVにも同じ確認ボタンがあります。新しいAI問い合わせは行いません。

古い情報、位置未確認、経路更新中、一時停止中を区別します。降車地点は取得済みの予定として回答します。現在のデータには残り駅数を確定する情報がないため、「あと何駅？」には残り駅数が未取得であることと、分かっている降車地点を返します。全区間の停車駅数を残り駅数と取り違えません。古い経路情報では運行状況が未確認であることも伝えます。

## 6. 曲がり角を通過した後の案内

曲がり角へ近づいた記録に加え、精度のよい異なるGPS観測で、角から遠ざかり経路も外れた状態が続くことを確認して再検索します。同じ位置の繰り返し通知や精度の悪い観測だけでは通過扱いにしません。

通過の可能性がある間は古い曲がり角・次の方向を表示せず、経路確認中と表示します。再取得した経路では以前の通過判定を引き継がず、新しい経路で案内を判定し直します。GPSによる推定のため、実移動中の確認が必要です。
