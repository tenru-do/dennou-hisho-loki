# 会話の復旧・文脈保持・共通進行表示（グラス v580／スマホ v225）

## 実装

1. **回答の完結性**：通常会話は Gemini の終了理由 STOP を確認してから、読み上げ・履歴保存・ツール実行へ進む。出力上限、安全性停止、終了理由不明を完了扱いにしない。部分回答を使った予定登録・記憶変更を防ぐ。既存の画像回答専用処理とは分けている。
2. **送信控え**：スマホと Web で送った質問・解析用添付を暗号化し、直近10件・24時間保存する。「送信控え」から入力欄へ戻せる。復元だけで再送しない。再送時は重複の可能性を表示し、同一IDに別内容を載せない。グラスにも前の質問を戻す操作を追加。
3. **共通進行表示**：グラス・スマホ・Web で準備中／回答中／確認中／完了／失敗／未確認を共有。再起動後の実行中は未確認とし、自動で再送しない。進行情報には質問・回答本文を入れない。
4. **明示訂正の継続**：「XではなくY」「XじゃなくY」「訂正」「正しくは」などを直近4件・2時間、暗号化して保持。同じ話題の継続時に引用として渡し、新しい話題・会話リセット時には外す。訂正文だけで外部操作を許可しない。
5. **保存と同時動作の検証**：実録音、KEEP撮影、画面休止、TOPIC画像・音声解析、合成会話を区別して検証する。試験ごとのID、送信前の回数記録、結果とのハッシュ照合を使用。

## 実装上の範囲

- 送信控えの動画は解析に送った抜粋画像であり、元動画全体のバックアップではない。
- スマホの復元では、生成物を編集する親画像指定を安全に戻せない場合、入力を変更せず Web の送信控えを案内する。
- 訂正の保持は明示的な表現を対象にする。すべての曖昧な言い換えの理解を保証するものではない。
- 外部APIの停止や通信断そのものをなくす実装ではない。失敗・不明を完了と混同せず、手動復旧できるようにする。

## ビルド・反映

正本ソースの未コミット変更を保持したまま通常ビルド。グラス v580、スマホ v225 を反映済み。対象機種・パッケージ・署名一致、更新前APKとアプリデータのバックアップ、PCコピーのハッシュ、インストール後APKのハッシュを検証した。装着しての主観的な見え方・聞こえ方はこの自動試験とは別。

## 検証記録

- ローカル回帰640項目、実機グラス304項目、実機スマホ69項目、Web72項目が成功。
- 通常のカスタム設定と合成履歴を用いた実API応答3件が STOP で完了。年額計算・明示訂正・新しい話題への切替を確認し、実会話履歴は変更していない。
- 完結性ガードが履歴保存・予定登録・成功記録より前に実行されることをコードで検査。
- ネイティブの送信控え画面の内容・配置・閉じる操作を確認。OS側はロック状態となり、ソフトウェアキーボードの最終表示試験は未確認。過去の結果を新しい実機確認と混同しない。

### 最初の15分試験に関する訂正

録音90区間のハッシュとKEEP写真30枚の認証・画像デコードは有効。一方、当初のTOPIC集計器が古い結果ファイルを読んでいたため、TOPIC3件の同時成功という報告は撤回した。修正後の3件の実API解析は録音終了後に成功（音声のみ2件、画像＋音声1件）。したがって最初の試験を同時API動作の証拠にはしない。

追加で許可された最終構成の同時試験は、専用試験ID・別検証器・送信回数の永続記録・入力SHA-256照合を用いる。途中でアプリ更新や別の実機検証器を起動しない。最終結果は concurrent-final/summary.json に記録する。

## 追加15分同時試験の確定結果

グラスv580／スマホv225のAPKを試験途中で変更せず、900848ms実行。録音90区間（PCM 28,783,360バイト、約899.48秒）すべてのSHA-256が一致し、KEEP写真30枚（3,563,785バイト）はGCM認証・画像デコードに成功した。開始・終了処理を含む経過時間とPCM実時間には約1.37秒の差がある。

録音中に、画像＋音声のTOPIC解析3件と通常設定＋合成履歴の会話1件が成功。各入力のSHA-256、専用試験ID、送信前の永続カウンターを照合し、再送なし。合成会話は STOP、期待する年額に回答し、実会話履歴は不変。

**画像取得の限界**：1件目はKEEP保存写真を直接取得。2・3件目の観測では新しい画像を得られず、検証側で同じ試験の1件目の保存写真を再利用して解析した。録音と画像＋音声API解析の同時動作は確認できたが、TOPICが毎回新しい写真を取得することは、この試験では確認できていない。API解析の成功を撮影側の完全成功と同一視しない。

61サンプル中KEEP稼働60（最初の1サンプルは起動待ち）、画面休止14。未保存PCMは最大640バイト＝20ms分。観測できたプロセスは両端末それぞれ1つ（最初のグラスPID照会1回は取得不可）。最大PSSはグラス104817KiB、スマホ70975KiB。ホスト監視を途中で再開したため再開後のホスト経過秒にはずれがある。端末内の連続録音サンプルと、録音中に実行された専用検証器の結果で重なりを確認した。

実機証跡とバックアップはローカルで保管し、画像・音声・個人設定を含むデータは公開しない。公開前確認は[v580の検査記録](releases/glass-v580-security.md)を参照。
