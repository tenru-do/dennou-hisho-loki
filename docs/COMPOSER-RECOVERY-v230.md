# 添付と下書きの保護（グラスv585／スマホv230）

スマホとWebの送信完了処理は、送信開始時の本文・添付・編集元が変わっていない場合だけ入力欄を消します。途中で編集し、同じ文章へ戻した場合も変更として扱います。

送信控えの復元では画像とメタ情報を先に検証します。Webで画像を準備している間に入力や編集元が変わると、現在の下書きを残して復元を中止します。スマホの添付下書きは暗号化AtomicFileで保存し、複数画像・動画の種別と件数を画面再生成時にも引き継ぎます。古い画面の送信完了が新しい下書きファイルを消さないようにしました。

## 検証

- Web：実際の送信・復元処理をEdge上で14項目検証。遅延したローカル受付結果と合成JPEGを使用。外部HTTPリクエスト0件。
- スマホ実機：合成JPEGで16項目。添付種別・件数、不正画像で元画像保持、Parcel経由の保存状態再構成、暗号化保存、改ざん拒否。
- ローカル：会話27項目、メモ復元22項目、下書き判定9項目を通過。開発ビルド成功。
- スマホv230：機種・パッケージ・署名確認、PCバックアップとハッシュ検証後に更新。反映APKハッシュ一致。通常画面の入力欄と会話ログ表示を確認。
- グラスはv585を維持。検証用アプリ削除、Wi-Fi・モバイル通信・USB接続時の画面休止設定を元に戻した。

実プロセス終了からの復元、実API送信の完了動作、装着中の音声動作は今回の試験に含めていません。外部送信・音声再生・生成API呼び出しは行っていません。
