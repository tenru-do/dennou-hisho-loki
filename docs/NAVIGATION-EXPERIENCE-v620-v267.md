# ナビ会話・案内調整：メガネv620・スマホv267

2026年10月23日。最終候補の隔離検証と両端末への適用が完了。バックアップ・署名・インストール後APKを照合し、起動前にスマホ146ファイル・メガネ410ファイルの内容が維持されていることを確認した。

## 実装した6項目

1. **重要な案内の優先**：曲がる直前と降車・乗り換え直前の案内を優先し、回答の読み上げへ短く割り込む。徒歩の直前判定は速度に応じた通知距離と同じ基準を使う。利用者が発話中の場合は待つ。到着予想の変化などの補足は回答後へ回し、古くなった案内は破棄する。割り込んだ回答は、世代・装着・発話状態を確認できる場合に区切りから再開し、もともと利用者が止めていた回答を勝手に再開しない。実際の音声終了時刻は既存の推定に基づくため、実音声での確認が必要。
2. **目的地を維持した経路の選び直し**：「この道は通れない」「別の道にしたい」→「はい」→メガネで目的地と経路を確認→開始する。共通経路の候補を取り直し、現在の経路形状が分かる場合は同じ形状を除く。別の候補がなければ、その旨を表示して自動で切り替えない。「通れない」は利用者からの申告であり、通行止め情報として外部へ登録しない。取得できた候補が申告の道を避ける保証はなく、元経路の形状が不明な場合は同じ経路を含むこともある。
3. **案内の詳しさ**：SETの「ナビ案内の詳しさ」またはNAVの「案内の詳しさ」で、簡潔・標準・詳しくを選ぶ。簡潔は短い操作案内、標準は操作と取得済みの目印、詳しくは取得済みの次の案内も加える。重要な降車準備などは簡潔設定でも省略しない。位置未確認時に詳しい方向を付け足さない。
4. **接続トラブルの区別**：スマホからの受信失敗、GPS未更新、経路取得失敗、経路未取得、経路更新中を分け、それぞれに接続・位置情報・地図API設定など確認先を表示する。受信失敗だけで物理的な切断と断定しない。位置が確認できない間は方向を読み上げない。
5. **確定前の言い直し・取消**：変更候補を確認中の「駅じゃなくて市役所」は、古い候補画面を閉じ、新しい候補の確認へ戻す。立ち寄り確認中の「コンビニはやめる」「立ち寄りを取り消して」でも取り消せる。すでに開始要求を送った場合は、画面を閉じただけで取り消せたように表示しない。現在の案内状態を確認する表示にする。確定済みの立ち寄りを、この短い取消で削除する機能ではない。
6. **到着後の片付け**：到着確認後は、ナビ音声・待機中の案内・候補画面・開始確認画面・変更希望を片付け、通常の会話へ戻す。通常の回答本文や会話履歴は消さない。スマホ側の候補セッションも無効化し、到着前の候補で後から開始できないようにする。

## 検証

両APKのコンパイルが成功。メガネの保護対象20区間、スマホの保護対象2区間は維持。

実際の候補APKのクラスを別UID・権限なしのAndroid環境で実行し、1,350件が成功（今回追加58件）。優先順位、詳しさ、言い直しの範囲、取消、トラブル分類、現在経路の除外、候補なし、到着後のセッション無効化、早歩き時の直前判定を確認した。隔離テスト用アプリと入力ファイルは削除済み。

検証では外部AI送信・経路検索・録音・音声再生を行っていない。画面キャプチャが黒く、今回のメニューの見え方は確認できていない。実移動中の音声割り込み・再開、実経路の選び直し、GPSやネットワークを実際に切った場合の挙動は未確認。

ロキの共通経路を選ぶ機能であり、Googleマップ内部の選択経路と完全に一致する保証はない。Googleマップ自身の音声終了は、既存の通知権限・終了操作で確認できる範囲となる。

## 実際に使う際の確認

- 「別の道にしたい」で候補まで進み、まずキャンセルして現在の目的地・経路が維持されるかを見る。変更したい場合だけ内容を確認して開始する。
- 確定前に「駅じゃなくて市役所」「コンビニはやめる」を試し、古い候補が復活しないことを確認する。
- 到着確認後にナビの画面と音声が片付き、通常の会話へ戻れるかを確認する。
