# 返答前の文脈検査（グラスv563）

短い続きの発言について、通常の回答を表示・読み上げる前に、現在の発言・参照中の会話・回答案の対象が一致するか、設定済みGeminiの軽量モデルで検査します。年額への続き、製品名と一般名詞の混同、不要な聞き返し、頼まれていない操作への逸脱を対象とします。

判定モデルは回答中と会話中の原文番号を選びます。アプリが原文を取り出して照合できた場合だけ修正を要求します。引用の創作や要約だけでは修正しません。修正は1回で、再検査でも対象の不一致が認められれば、その回答の読み上げを止めてエラーを表示します。

検査は予定登録・受信箱変更などの操作権限を持ちません。元の会話指示を保持します。ネットワーク障害や壊れた判定では通常の回答経路を維持します。外部の事実の正しさや、すべての会話の自然さを保証する機能ではありません。

接続タイムアウト2秒、読み取りタイムアウト3.5秒です。検査対象は参照会話のある160文字以内の発言で、挨拶等は除きます。API利用量と応答待ち時間が増えます。

検証：ローカル方針テスト18件、実端末から設定済みAPIへの個人情報を含まない合成会話10件で期待判定を確認しました。初回8/10だった原文引用の問題を、原文番号方式へ変更して解消しています。
