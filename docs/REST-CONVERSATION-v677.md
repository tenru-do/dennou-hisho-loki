# 寝姿の会話・操作リアクション v677

寝姿と立膝を保ったまま、既存の会話反応メタデータから喜び・考え中・驚き・気遣いを選ぶ。新しい顔4種を加え計10種。返答分類を確定してから反応へ渡す。

タップ・スワイプにも短い上半身の反応を出す。腰・脚は固定。身体反応は2.2秒、同じ意味の連続入力では8秒以内に身体動作を再起動しない。顔は最新の内容へ更新。既存描画スケジューラと動作強度・静穏設定に従い、追加通信や常時タイマーを作らない。

手動指定の表情を優先。「表情をおまかせにして」で自動へ戻す。「うれしい顔にして」「考える顔にして」「驚いた顔にして」「心配そうな顔にして」は寝姿での端末内表示操作。SET→全身の仕草を確認→寝姿の表情・動作（修正版）にも追加。自動では脚・スカート・姿勢を変更しない。

既存の会話入力・モデル指示は変更せず、既存の反応情報を利用。合成タグと操作イベントでAndroidの実Viewを検証し、実ユーザー会話や外部APIは未使用。新規顔は承認済み原画と補正済み寝姿マスターから生成し、顔のみ利用して元の身体比率を保持。artwork/v677/conversation-faces-prompt.txt に生成指示を保存。

ソース段階の隔離Android検証1783件成功。配布候補での再検証・適用結果は作業出力レポートへ記録。
