# 座位の脚の組み替え・寝姿の背景・KEEP

グラス v733 / スマホ v318（2026-11-04）。

通常の座位に8コマの脚の中間動作を追加する。右の脚組みから脚を上げ、ほどき、両脚をそろえ、左の脚組みへ移る。逆順で反対側へ戻る。全コマで同じ顔の倍率・頭頂・上半身の基準を使い、各画像の足の位置で人物を縮小しない。

自然動作が有効な通常座位では、120秒の連続した待機で動作を開始する。明示的な脚組み替えも同じ描画を使う。読み上げ、固定、ナビ等による表示抑制中は進行を止める。別の姿勢・画像一覧・停止では予約を消し、復帰後に古い指示を再実行しない。8枚を必要時だけ読み込み、画面終了で解放する。

寝姿と休息動作の12素材は、寝具・家具を除去した透過画像へ置き換える。生成元と旧原本は制作履歴へ保持する。読書時の本は残す。新しい画像に合わせて、寝姿の口の位置、読書表情の下段、頬に手を添える表情の右列、休息動作の切り出し位置を補正する。旧立膝素材は読み込まず、通常の寝姿で代用し、メニューと説明にこの制限を示す。

KEEPのWeb写真一覧は1ページ500枚。取得・選択・削除の上限とページ送りをそろえる。取り込み状況は既存のグラスからの進捗を用い、PC・タブレットへスマホ保存確認・対象・残り・削除照合・失敗・別処理待ちを表示する。保存確認には既存ファイルとの照合も含むため、新規転送枚数とは表現しない。

新しいコピー要求が前回の完了状態を引き継がないよう、バッチを識別する。未知の総数は確認待ちとして表示する。通信断では最後に確認できた状態を残す。認証済みのGETは状態参照だけで、コピー・削除を開始しない。写真タブが表示されている間だけ5秒程度で確認し、失敗時は間隔を伸ばす。30分・360回で自動確認を止め、手動更新を残す。

画像の制作記録は `artwork/reviews/v733`、原画・新素材は `artwork/revisions/rest-no-bedding-v733` と `artwork/revisions/seated-leg-v733`。指定基準画像は変更していない。実際の大量写真転送、外部AI・経路APIの利用、録音・撮影、R08設定の変更は今回の検証で行わない。PC・タブレット側はページの再読み込みが必要。
