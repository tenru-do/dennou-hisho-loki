# v676: 立膝・布の追従・表情と小さな身じろぎ

修正済み寝姿の顔・体格を参照した立膝4コマをbuilt-in image_genで追加。膝を少し曲げる→曲げる途中→立膝で保持→下ろす途中を使う。裾は膝に伴う自然なしわ・ずれで、手で持ち上げず、不自然な追加布は付けない。原画には区切り線があるため x=511/512、y=729/730 を除外して実行時に切り出す。元PNGは変更せず保管。

## 操作と組み合わせ

- 「寝たまま立膝にして」で片膝を立て、動作後も保持。
- 「寝たまま脚を伸ばして」で下ろす動作を経て元の寝姿へ。
- 「寝たまま立膝のまま身じろぎして」で照れ・緊張に伴う小さな肩・上体の反応。膝・脚は固定し、短い反応後も立膝を保つ。
- 「身じろぎを止めて」で反応だけ止める。姿勢・表情は保つ。
- 立膝のままキス顔・困り顔・せつない顔・気持ちをこらえる顔・微笑み・通常顔を組み合わせられる。顔変更で膝を下ろしたり、膝を曲げる動作を最初から再生したりしない。
- SET → 全身の仕草を確認 → 寝姿の表情・動作（修正版）へ4操作を追加。表示指示の返答はローカルで行い、既存の履歴・読み上げ・再適用・一段戻しへつなぐ。

カメラの縮尺を固定し、曲げた脚の見かけの高さで頭まで拡大しない。表情差分を同じ身体へ合成し、全身の体格を表情ごとに再生成しない。上体の反応は有限の4.8秒で、既存の描画周期・動作設定に従う。動作オフ時は微動を止め、非表示時の新規タイマーや追加通信はない。

## 検証

新規ソースを含む隔離Android検証1759項目成功。新しい4操作を予算0のMainActivityで返答、実Viewの姿勢保持、6表情の描画と膝・裾の一致、上体の反応と脚固定、動作設定オフでの停止、画像解放を確認。頭身・肩幅・伸ばした側の脚長は手入力目印の比較で閾値内。全角度の解剖学的な一致を保証するものではなく、装着して実マイクから行う試験とも別。
