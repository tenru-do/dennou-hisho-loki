# v672: 姿勢操作とイヤリング動作の比率

「ねそべって」のひらがな表記と「ねそべらないな」という表示不具合の指摘を共通判定する。禁止の「ねそべらないで」と区別する。短い姿勢操作は端末内の定型応答を通常の履歴・通知・読み上げ経路へ渡し、モデルの逆解釈やネットワーク待ちを回避する。明示的な姿勢操作は通常表示時に全身モードへ切り替える。ナビ・録音の表示中は切り替えず、終了後の再指定を案内する。

くつろぐ姿勢と、実際に横たわる姿勢を分離。ねそべる操作にはソファにもたれる絵ではなく、既存の横たわる画像（clip 28）を使用する。発話終了後も保持し、元のモデル返答が座位や禁止を述べても表示指示を覆さない。

イヤリングに触れる専用アトラスをv672へ更新。指定基準画像を参照したbuilt-in image_gen編集、4列×2行の立位・座位を維持。旧v667は保存し、新規v672 PNGを描画と自己プロフィール生成へ登録する。プロンプトはartwork/v672/ear-prompt.txt。

## 検証と限界

新規に許可された合成Gemini 2件は直接指示1件成功、訂正1件失敗。追加許可1件も逆表現が残り失敗。API検証成功として扱わず、再送はしていない。以降は端末内の確定応答方式へ変更し、予算0の実MainActivity呼び出しで外部API不要を確認した。

新規ソースを含む隔離Android実機チェック1218項目成功（個人設定変更・外部API・録音・撮影なし）。実Viewで「くつろいで→ねそべって→ねそべらないな→ねそべらないで」の要求・音声開始相当・音声終了相当を通し、描画画像も確認。これは実マイクや装着時のVOICE通話全体の成功を保証する試験ではない。

イヤリング全8コマで頭幅/シルエット高さの比が減少。立位は約7〜11%、座位は約19〜22%減。小さな実表示でも顔が極端に拡大されず、手と耳がつながることを描画プレビューで確認した。最終APKの検証・適用結果は作業側のoutputsへ別記する。
