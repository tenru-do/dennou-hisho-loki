# 画像質問の入力検査（スマホv233／グラスv585）

画像質問の送信処理で、検査より前に送信控え保存と画像・動画生成への振り分けが行われていました。送信ID、本文のnull・2400文字制限・内部制御文字列、添付の空データ・600000バイト上限・寸法上限・画像デコードを先に検査します。不正入力を保存や振り分けより前に止め、理由を分けて返します。小さなプレビューでデコードして解放し、画像全体の再圧縮はしません。

実機39項目成功。既存の添付保持25項目に加え、正常な合成画像の入力検査2項目、不正なenqueue呼び出し12項目を検証。不正ケースでは保存領域・生成設定へアクセスすると失敗するテスト用Contextを使用し、それ以前のIOExceptionで拒否されることを確認しました。正常な依頼の受付処理や実API送信は呼び出していません。

開発ビルド成功。機種・署名確認、更新前バックアップとハッシュ検証後にv233を反映し、端末APKハッシュ一致と通常起動PIDを確認しました。テストAPK削除、通信・USB画面休止設定を復元。外部API呼び出し・音声再生なし。グラスv585は変更なし。
