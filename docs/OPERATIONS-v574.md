# 共通動作確認・転送検証 v574 / v217

グラスv574・スマホv217をビルドし、両端末へ反映しました。更新前に対象端末・署名を照合し、バックアップの読み取りとSHA-256を検証しました。インストール済みAPKもビルド成果物とのSHA-256一致を確認しています。

## 実装

- スマホの「依頼・転送・動作チェック」とWeb会話画面から、依頼IDごとの受付・処理・確認待ち・完了・失敗を確認できます。古い応答や不明な状態を完了と推測せず、自動再送もしません。状態データの一部が壊れても他の診断を表示します。
- 写真と録音の転送件数・音声区間数を表示します。録音の最終受領はID・区間数・PCMバイト数まで一致を要求します。中断は中断として表示し、グラスの元録音を消しません。過去にスマホで削除した写真を勝手に一覧へ戻しません。双方の更新が必要で、古い受領形式は成功扱いにしません。
- 更新後に端末内の保存往復・既存暗号鍵・同梱ファイル・キュー形式・必要権限を自動検査します。手動再検査もできます。スマホで宣言していないCAMERA権限は不要と表示します。追加の権限はありません。

## 検証結果

- 通常ビルド：グラス・スマホとも成功。会話プロンプトの基準検査も成功。
- ホスト回帰テスト：347項目成功。
- ブラウザ：52項目成功。重なり・表示・認証・非同期状態を確認。画像は合成データです。
- 実機の隔離データ試験：グラス18項目、スマホ32項目成功。保存、受領照合、破損時の読み取り、未認証・別オリジン拒否を確認。
- ロック解除後の実画面：共通動作チェック、会話の参照、録音確認の3画面を表示でき、実際の検査内容も確認しました。
- 実際のグラス→スマホ通信：最新状態とグラスv574の検査結果を受信。スマホv217の起動時検査も成功。

## 検証範囲

今回の追加作業でAI・経路APIへの送信、撮影、録音、カレンダー登録は行っていません。ローカル検査は同梱画像の代表ファイルの確認であり、全画像の品質やAI・ナビの稼働を保証しません。以前のv570での15分連続運転試験を、v574で再実施した扱いにはしていません。装着者による見え方・聞こえ方の確認は別です。
