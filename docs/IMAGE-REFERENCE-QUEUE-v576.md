# 待機キュー・実行前の画像参照照合（グラスv576／スマホv223）

## 変更

参照一覧から書き出した画像質問について、参照キーをID付き依頼の内部形式に追加しました。Web受付からスマホの待機キュー、グラスの保存済み依頼までキーを保持します。キーと内部形式をGeminiの質問本文へ混ぜません。旧形式の通常会話も引き続き読み取れます。

グラスでは、実行権を確認して会話へ渡す直前、意図判定からの非同期再開時、回答用プロンプト準備の前後で参照を照合します。参照が更新・期限切れ・破損・無効化された場合は別の画像へ置き換えず停止し、FAILED／REFERENCE_CHANGEDをスマホへ返します。Webの送信状況にも「画像参照が更新・失効したため未送信」と表示します。元の画像や読み取り結果を複製して永久保持する方式ではありません。

スマホから参照一覧経由で送る質問も、ID付きの受付記録と同じキューを使います。同じID・同じ内容の再受付はキューを増やさず、同じIDで本文や参照キーが変わった場合は拒否します。受付記録と送信状態の保存に失敗した場合は、自動再投入しません。下書きの送信IDも画面保存状態へ引き継ぎます。

## 検証と範囲

- ホスト回帰446項目成功。内部形式でのキー保持、旧形式、最大文字数が既存キュー上限に収まること、不正形式拒否、参照変更の失敗理由を検証。両端末のキー計算・期限判定の合成検査も含みます。
- ブラウザ56項目成功。
- グラス・スマホともビルド成功。会話プロンプト基準16区間／2区間の検査成功。保護済みプロンプトは変更していません。

実機試験は合成データ・隔離保存先で行い、Geminiへ質問を送信しません。予定登録・画像生成・動画生成・録音・撮影は行いません。

この保護は、更新された参照への置き換えを拒否する方式です。古い画像を保存して回答を継続する機能ではありません。キーのない旧クライアントや自由入力の暗黙的な画像参照には適用しません。通常の更新順序では、新しい形式を受け取れるグラスを先に反映してからスマホを更新します。旧グラスは新しい内部形式を処理できないため、両端末の更新が必要です。

既存の未コミット変更を保持し、GitHubへpushしていません。新しい外部送信先、Android権限、画像本体の保存先は追加していません。参照キーは既存の端末内キュー・受付履歴に保持されます。

## 反映後の実機結果

グラスv576・スマホv223へ反映済みです。対象機種・署名を照合し、両端末の更新前APKとアプリデータのバックアップ読み取り・ハッシュ、インストール済みAPKのハッシュ一致を確認しました。

グラス42項目・スマホ57項目が成功。実際のキューへの参照キー保存、同じIDの再受付で件数が増えないこと、内容の変わった同じIDの拒否、旧参照の拒否、グラスで参照変更・破損・期限切れ・参照無効時に停止すること、非同期再開前の再確認を検証しました。実APIへの会話送信や予定登録は行っていません。

両端末の起動時ローカル検査は合格。実際の状態同期後、スマホの暗号化状態ファイルが15秒以内に更新されたことを確認しました（本文は読み出していません）。検証専用アプリとグラスの検証DEXを削除し、ロキ本体を起動しています。新しい実画像を用いたモデル回答の品質試験、装着時の見え方・音声は今回の対象外です。
