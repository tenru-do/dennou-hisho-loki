# 画像を添付してロキに質問する

グラスv522／スマホv176で追加。画像解析と予定登録を別の段階に分けます。

グラスv523では主操作列のCAM隣にREADを追加しました。押すと1枚撮影して内容を読み取り、長押しで直近の解析結果を確認できます。READによる画像もGeminiへ送信します。CAMの拡大カメラ機能は従来通りです。

グラスv524／スマホv177からは、READや「これを読んで」で撮影した元JPEGをグラスの暗号化された記録写真に保護保存し、スマホの通常ギャラリーにも自動でコピーします。保存先は Pictures/Loki/READ。グラスの元写真は自動転送後も残ります。Geminiへの送信には縮小・再圧縮した画像を使います。

撮影後は解析に失敗しても保存済み写真を残します。スマホ未接続・保存失敗時はグラスの転送待ちを保持し、ロキが稼働して接続が戻ると再試行します。スマホ上の暗号化保存とギャラリーへの書き込み・読み戻しを確認してから転送待ちを解除します。同じIDの再送や途中の保存行から復旧し、重複保存を防ぎます。スマホ側で明示的に写真を削除した場合は、その削除を優先して自動再作成しません。元写真をグラスから消す処理は自動コピーにはありません。

保護写真も既存の5GB上限・空き容量制限の対象で、保護済みの写真を自動で捨てて新しいREAD写真を保存しません。容量不足は通知します。転送待ちのREAD写真は通常の一括移動から除外し、ギャラリー保存の確認を優先します。スマホ・Webから選択した画像はこの自動ギャラリーコピーの対象ではありません。

ギャラリーの写真は通常のJPEGであり、他の写真アプリから見え、スマホの写真バックアップ設定の対象にもなります。画像質問の一時データや2時間の会話参照が失効しても、保存写真と会話履歴は消えません。

直近の解析結果は、カレンダー登録だけでなく通常の会話でも最大2時間参照します。「その予約は何時？」「さっきの写真の病院は？」などは画像の参照を優先し、通常の予定検索へ直接振り分けません。新たな画像の解析が成功したら参照を置き換えます。画像そのものを会話のたびに再送・再撮影する機能ではありません。不鮮明な文字や読み取れなかった細部は再撮影・質問が必要です。

## 入力する

- グラス：ロキの画面を開いて「これを読んで」「この予約票を読み取って」「写真を撮って解析して」と発話・入力します。カメラで1枚撮影し、Geminiへ送ります。通常の写真の話題だけでは撮影しません。
- スマホ：「画像をロキに質問（選択・撮影）」を開き、画像を選ぶかカメラで撮ります。画像と質問を確認して「画像と質問を送信（Geminiへ）」を押します。
- PC・タブレット：既存のスマホ共有Web画面の「ロキと会話」で「画像を添付」を選択します。プレビューを確認して送信します。画像だけでも送信できます。画像は1回につき1枚です。

スマホ・Webの画像質問はスマホが一時保持し、接続したグラスのGemini経由で解析します。スマホ単独での解析ではありません。グラスの接続・APIキー・インターネット接続が必要です。返答と失敗通知はグラスと共通会話履歴に表示します。準備中・送信待ち・解析結果は別の状態です。

## 予約票から予定を登録する

1. 予約票を選んで「予約日時を読んで。指定したカレンダーへの登録候補を作って」と送ります。
2. ロキが読み取った病院・診療科・日時等を回答します。不鮮明な文字や記載のない年・時刻は推測しないよう指示しています。OCR精度を保証するものではありません。
3. 「この予約を『登録先のカレンダー名』に登録して」と続けます。既存の会話履歴とスマホの書き込み可能カレンダーを参照し、予定名・開始／終了・登録先を示します。この段階では書き込みません。
4. 内容が正しければ「確定して登録」と入力・発話します。モデルを再介在させず、確認済みの候補を既存のカレンダー保存処理へ渡します。訂正があれば先に訂正内容を伝えます。「登録をキャンセル」で取り消せます。

登録前確認は10分で失効します。別の発言・新しい画像は古い確認候補を無効にします。画像解析後の会話参照期間中は、カレンダーの書き込みに確認段階を設けます。画像内容と無関係な登録でも、この期間中は確認が挟まる場合があります。

保存先の名前が一致しない・同名が複数・権限不足・日時が不正な場合は登録を停止します。同一予定の重複確認と保存後の読み戻しは既存のCalendarWriterを利用します。確認できるのはスマホ上の保存であり、Googleクラウドへの同期完了とは区別します。

## サイズ・負荷

入力は20MB・8000万画素以内。長辺を最大2048pxに抑え、最大600KBのJPEGに再圧縮します。WebはJPEG・PNG・WebP・GIFに対応し、ヘッダーで寸法を確認してから縮小デコードします。スマホの対応形式はAndroidのデコーダーによります。細かい文字は必要部分を切り取ってください。アニメーション画像は静止画として扱います。

グラスの撮影時は既存のカメラ排他と顔描画の一時解放を利用します。画像は解析スレッドにだけ付加し、通常の会話やTOPICに添付しません。画像解析には記憶の保存・削除やカレンダー書き込みのツールを渡しません。画像内の文章を命令として扱わないよう指示します。画像質問で会議録音を終了する処理は追加していませんが、同時動作の実機負荷は別途確認が必要です。

## 保存・外部送信

送信すると画像と質問がGoogle Geminiへ送信され、氏名・診察内容等の個人情報も送信対象になります。選んだだけではGeminiへ送りません。元画像は変更しません。再圧縮画像にはEXIF位置情報等を引き継ぎません。画像内に写った文字や場所は消去されません。

スマホの送信待ち画像・質問はAndroid KeystoreのAES-GCMで暗号化します。有効期限は30分で、期限後は読取りを拒否し、次の利用時に古いファイルを削除します。解析成功後は画像本体を消し、再送防止の小さな記録を期限まで保持します。未完了は最大12件、短期記録は最大256件です。Webの同じ送信IDの再試行は重複投入を抑えます。

スマホで外部カメラアプリを使う間は、アプリ専用キャッシュに一時JPEGを書きます。この撮影中のJPEGは暗号化されていません。戻り後は削除・URI許可の取消しを行い、中断等で残ったものは期限後のカメラ利用時に削除します。選択後の下書きは暗号化し、30分後の利用時に削除します。

読み取ったテキストと返答は従来の共通会話履歴に残ります。画像を破棄しても会話テキストは自動削除しません。グラスには直近1件の画像解析テキストも暗号化して保持し、通常履歴の省略で予約日時が欠けないよう登録候補作成時に参照します。この参照は会話参照期間で失効し、次の参照時に削除します。登録確認候補も暗号化し、両方とも会話の初期化時に削除します。既存の履歴・バックアップ・開発版ADBの取り扱いはPRIVACY.mdに従います。

## READの撮影日時・位置印字（グラスv528／スマホv182）

新しいREAD撮影では、グラス時計による撮影日時をJSTで印字します。位置はスマホから取得できた測位値のみで、撮影時点から90秒以内・精度500m以内の有効な座標を利用します。「スマホ位置」と明示し、精度と測位の古さを添えます。グラスとスマホが同じ場所にある保証はしません。住所名の推定や古い位置の流用はせず、取得できない場合は未取得と表示します。キャッシュがなければ撮影を止めない範囲で最大1.2秒だけ位置更新を待ちます。

グラス内の原本JPEGはそのまま保持し、撮影情報を暗号化メタデータとして関連付けます。Gemini向け画像の下端に黒帯を追加し、白文字で情報を焼き込みます。スマホのギャラリーへ保存するコピーにも同じ情報を焼き込みます。既に保存済みのギャラリー写真は上書きしません。印字した撮影日時は、画像内の予約日時・イベント日時とは区別するよう解析へ伝えます。画像に年がない場合、撮影年を予約年として自動補完しません。会話参照期間中は撮影情報も暗号化した画像参照と一緒に保持します。スマホからの添付画像に、グラスの現在地・現在時刻を後付けすることはしません。

位置座標は写真上にも見えるようになるため、印字版の写真を共有するとその情報も共有対象になります。元画像の画面外に帯を足すため、画像内の文字や予約項目を塗りつぶしません。

ReadCaptureContextTestはグラス・スマホそれぞれ15項目PASS。Android上の実描画・ギャラリー保存・Geminiの読み取りは実機で別途確認します。

## スマホの会話内添付（v181以降）

スマホv181では、会話ログの下・質問入力欄の上に「画像を添付」「撮影して添付」を置きます。添付後は同じ画面でプレビューと「画像を外す」を表示し、共通の送信ボタンが「画像と質問を送信」に変わります。画像だけでも送れます。画像付きの質問は2400文字以内です。送信失敗時は画像と質問を残し、同じ送信IDで再確認できます。準備済み下書きは暗号化して画面再作成時に復元します。専用の質問画面へは移動せず、画像選択・撮影のシステム画面から会話画面へ戻ります。添付時もログを併せて読めるよう、プレビューは縮小し、ログ領域の高さを調整します。画像選択・撮影だけでは解析を開始しません。

## 検証の区別

ホスト上の撮影意図・確認文判定、Webの画像準備・送信・再送・ログアウト競合、既存送信／会議操作の回帰テストとAndroidビルドを用意しています。ビルド成功は、カメラ撮影・実際のGemini解析・カレンダー登録・装着時の実機確認を意味しません。
