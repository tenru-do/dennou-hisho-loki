# 動作の検品画面

グラスv563の本番描画器を使い、全身443種類・顔37種類をオフラインで確認するPC用ページを生成します。新しい画像の生成API、マイク、カメラ、実際の会話履歴は使いません。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/Export-MotionReview.ps1 -Serial <グラスのADBシリアル> -Output <新規の出力フォルダー>
```

インストール済みAPKとローカルのビルド済みAPKのバージョン・SHA256が一致する必要があります。開発用署名とrun-asが使える端末用です。診断用アプリを一時インストールし、終了時に削除してロキを開きます。出力専用キャッシュだけを、場所を検証して削除します。

各全身画像は静止1・待機4・発話6・まばたき7・隣接IDへの遷移5コマ、顔は静止1・待機4・発話6・まばたき7コマです。合計480種類・10,855コマになります。座位の動作画像は本番で使う座位の基準ポーズに合わせて描画します。

出力のindex.htmlを開くと、種類・IDによる絞り込み、一時停止、コマ送り、再生速度、顔と首の拡大、確認記録とJSON保存が使えます。以前の出力フォルダーを読み込むと同じIDを比較できます。記録はブラウザ内にバージョンとAPKハッシュ別で保存します。外部へ送信しません。

これは実際の描画コマの検品です。任意ID同士の並びが会話中に必ず発生するとは限りません。隣接IDの遷移は比較用で、専用遷移データの有無を表示します。全会話経路、連続長時間運転、装着時の見え方は別の試験です。全種類を出力したことと、全画像に美術上の問題がないことは区別してください。

## 本番の反応順を検品する
`-Poses routes`を指定すると、隣接IDの組み合わせの代わりにFullBodyConversationMotionの本番ポリシーが選ぶ座位驚き・座位微笑み・涙・思考2系列を0〜2520ms、90ms刻みで描画します。5系列・145枚のPNGを出力します。前後の会話入力・読み込み待ち・すべての補間を含む運転試験とは区別します。
