# ナビの追加改善：メガネv612・スマホv261

## 6項目の変更

1. **出発方向の確認**
   - 徒歩の移動方向をGPSの進行方向や位置の変化から確認し、経路の近い区間と比較した矢印を表示します。
   - スマホの端末の向きは使いません。方向が未確認なら「出発方向を確認中」と表示し、曲がり角の音声案内を保留します。
   - 長いGPS欠落後は方向を確認し直します。矢印の基準は実際の移動方向で、メガネを向けた方向ではありません。
2. **曲がり損ねへの対応**
   - 同じ曲がり角への接近後、別の位置サンプルでも距離が増え、経路からも離れた場合に通過の可能性を表示します。
   - 旧経路の曲がる音声を止め、新しい位置が確認できれば再探索します。同じ位置の繰り返しでは判定を進めません。
3. **次の案内を聞き直す**
   - メガネのナビメニューに「次の案内をもう一度」を追加しました。ナビの案内文を選択して決定する操作でも聞き直せます。
   - 有効な案内だけを読み上げます。位置が古い・方向未確認・再探索中・メガネを外している場合は読み上げません。
   - 自動のナビ音声をオフにしていても、明示的な聞き直しは利用できます。
4. **経路変更の理由と差**
   - 逸脱、曲がり角の通過の可能性、案内元の更新などの理由と、新経路の残り時間の差を表示します。
   - 比較には直前の残り時間の推定を使い、取得にかかった時間も考慮します。古い経路全体の所要時間との比較はしません。
   - 直近の比較条件がそろう場合のみ距離差も表示します。比較不能の場合は差を作りません。説明は約45秒で消えます。
5. **一か所への立ち寄り**
   - スマホの「添付・その他」→「ナビ」→「立ち寄り・最終目的地」から追加します。
   - 最終目的地を候補から選んで座標を確認した後、立ち寄り先を検索・確認し、「立ち寄りを設定して開始」を選びます。
   - 到着後に「立ち寄り完了」→「最終目的地へ」を選ぶと、保存した元の座標へ経路を切り替えます。接近だけでは自動で切り替えません。
   - 2地点は端末内に暗号化して24時間以内保持します。端末再起動後も読み戻せます。案内先や移動手段が変わった場合は、古い完了操作で上書きしません。
   - 「立ち寄り設定を解除」で保存を解除できます。現在のナビは変更しません。各区間を順番に開始する方式で、全区間を合算した到着時刻は表示しません。
6. **徒歩ナビの位置更新を調整**
   - 徒歩で次の曲がり角まで500mを超え、現在地・移動方向・経路との一致を確認できたときに、GPSの更新要求を8秒間隔にします。
   - 曲がり角付近、位置不明、逸脱・再探索中は精度優先に戻します。画面に「GPS省電力：更新要求8秒間隔」と表示します。
   - スマホの「ナビの位置更新・省電力」で、自動省電力と精度優先を選べます。他アプリや車ナビSDK全体の位置更新を制限する設定ではありません。

## 検証

- Androidの独立したテスト環境で959件成功。今回の追加判定63件を含みます。
- 実際の候補APKのクラスを使い、方向未確認・GPS欠落・同じ位置の繰り返し・通過判定・古い案内の聞き直し拒否・比較元の一致・立ち寄りの暗号化保存と完了時の照合・省電力の条件を検証しました。
- 既存の経路候補選択、乗車判定、複数交通機関、HUD、会話処理の回帰検証も成功しました。
- 外部AIへの合成質問や実際の経路検索は検証で行っていません。
- スマホ実機で立ち寄り管理・省電力・入口選択・ナビ状態の画面を確認しました。検索・案内開始・目的地や設定の変更はしていません。

## 未確認の範囲

屋外を実際に歩いた際の方向・曲がり損ね判定、実際の立ち寄りと最終目的地への切り替え、聞き直しの音声、電池の削減量は未実測です。通知や時間・距離はいずれも位置精度と経路データに依存します。

立ち寄り保存用の新しい記録は、手動バックアップの対象には追加していません。今回の更新前バックアップはアプリ全体を対象とします。
