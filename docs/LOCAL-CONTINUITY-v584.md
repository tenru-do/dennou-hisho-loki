# ローカルでの継続性と更新管理（グラスv584／スマホv228）

## 操作

- グラスのSETに「端末内メモ・通信待ち」「容量・更新バックアップ確認」を追加。
- スマホの「添付・その他」に「端末内メモ・通信待ち」を追加。入力欄とログの配置は維持。
- スマホ／Webの「会話の参照・予約候補・認識文」で、短い続きの発言の参照候補を表示する。

## 8項目の実装範囲

1. **容量管理**：更新用ZIPの件数と合計、データ領域の空きを端末内で確認。`Archive-GlassUpdateBackups.py` は、指定モデルを確認し、PCコピー・SHA-256・ZIP CRCの検証後に一致した端末側ファイルだけを削除する。任意ファイル・写真・録音・設定は対象外。PCコピーがない場合は先にコピーする。
2. **会話の経路**：通常送信から天気・データ・雑談の直接応答ショートカットを外し、通常の文脈付きモデル経路へ進める。既存の受信箱・記憶・画像・予定などの専用処理は残す。引用・否定・条件や操作方法の質問はローカル操作として実行しない。オンライン時の端末状態即答は明確な時刻・電池・接続状況の照会に限定する。
3. **名前の訂正**：利用者が明示する名前・地名・読み方・聞き取りの訂正を、既存の暗号化した会話内訂正へ渡す。最大4件・2時間の会話内参照。元の認識文は書き換えず、固有名詞を自動で推測しない。クラウド音声認識の精度改善を検証したという意味ではない。
4. **併用時の音声**：既存の、自分の読み上げが有効なときだけSTOPを出す所有権制御を維持。長時間検証はローカル録音・KEEP・TOPIC素材取得とメディア状態の観測で実施する。クラウドのTOPIC生成・VOICE認識・ベンダーTTSを呼ばない。実際のBluetooth再生がない場合は、音の途切れを確認したとは扱わない。
5. **TOPICの写真**：KEEPの取得開始時刻を基準とする保守的な経過時間を使用。読み出し・縮小後にも15秒以内を再確認する。次の保存を待つ場合は最大2秒、100ms間隔で中止確認し、カメラを追加起動しない。鮮度・負荷などで取得できない場合は理由を残す。音声が取れれば音声のみ、両方なければ既存の待機処理へ進む。待機のために鮮度上限を広げない。
6. **参照候補**：「それ」「この前」「年間では」などの続きの発言について、2時間以内の直近の利用者発言を最大2候補、各100文字で表示。時系列による候補であり、AIが対象を確定した表示ではない。複数なら未確定と明記し、利用者は対象名を添えて訂正できる。予定登録などの実行権限には使わない。WebはtextContentで表示する。
7. **再現ケース**：`tools/local-conversation-fixtures/routing.json` と `Test-LocalConversation.ps1` に個人情報を含まないケースを保存。振り分け、訂正、参照候補、画像の鮮度、メディアSTOP所有権を確認する。モデルの理解精度とローカル状態テストを区別する。
8. **端末内メモ**：グラスとスマホそれぞれの私有領域へAndroid Keystore/AES-GCMとAtomicFileで保存。最大100件・1件2800文字。自動送信・自動登録・生成の自動再送はしない。手動で入力欄へ戻す操作と送信を分離する。添付は保存しない。既存下書きの置換と削除は確認する。破損時は既存ファイルを上書きせずエラーを表示する。アプリのデータ削除まで保持し、個別の手動削除も可能。

## 更新時の再発防止

`tools/Install-LokiVerified.py` を使用する。端末シリアルは呼び出し側で明示し、アプリ種別に対応するモデルとAPKパッケージも検査する。公開ソースには個人の端末シリアルを埋め込まない。

1. ユーザーの録音・KEEPが稼働中なら更新を止める。
2. 明示した新APKのSHA-256、更新前APKのPCコピーと端末ハッシュ、双方の署名証明書を検査する。
3. 私有files/shared_prefsのみを一意なcacheのtarへ保存し、PCへコピーする。外部領域へバックアップZIPを作らず、過去の外部バックアップを取り込まない。
4. コピーのSHA-256、正しいアプリの設定ファイル、全通常ファイルの読み取りを検証する。
5. PCコピーを保持したまま、この処理で作った端末の一時tarのみを削除する。検証失敗時には削除しない。
6. インストール後も端末APKのSHA-256とversionCodeを検査する。既定ではActivityを自動起動しない。

```powershell
python tools/Install-LokiVerified.py --app glass --serial GLASS_USB_SERIAL --adb PATH_TO_ADB --sdk PATH_TO_ANDROID_SDK --java PATH_TO_JAVA --apk PATH_TO_APK --expected-sha256 EXPECTED_SHA256 --output PRIVATE_NEW_BACKUP_DIRECTORY
```

バックアップは個人情報を含むため、Git管理外またはignoreされた私有ディレクトリへ保存する。バックアップのtar/ZIPは検査するだけで展開しない。検証記録を残し、削除範囲を厳格に限定する。

## 今回の検証境界

利用者の指定により外部送信なし。保護対象プロンプトは変更しておらず、既存ベースライン検査を通す。実機ではネットを一時停止して検証し、終了後に元へ戻す。

- 既存の会話・受信箱回帰680項目。
- 新しいローカルシナリオ27アサーション。これとは別に18,120回のメディア状態遷移を模擬。模擬回数を会話品質の検証件数として数えない。
- 誤端末・録音中・ハッシュ不一致・危険なファイル名の更新安全性テスト。
- Android上の暗号化保存、復号、改ざん、上限、下書き維持とキーボード配置。
- 15分の録音・KEEP・TOPIC素材取得を対象に、保存内容・取得時刻・画面休止・プロセス・メモリを確認。実際のモデルの応答品質、クラウド認識、Bluetooth音声の聴感を代替するものではない。

実際の端末シリアル、バックアップ位置とハッシュ、測定結果の詳細は私有の作業出力へ保存する。公開用文書へ会話履歴・画像・音声・APIキーを含めない。
