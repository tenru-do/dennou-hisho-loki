## 実装した内容

| 項目 | 今回の実装・使い方 |
|---|---|
| 1. 回答診断 | 認識文、参照設定、回答処理の段階・失敗理由をまとめて表示。通常回答試行のプロバイダー応答から検索の記録・検索語数と出典数を観測し、依頼IDとの対応も区別。検索語・会話本文を新たな観測記録へ保存しない。記録がない場合は未確認と表示。 |
| 2. 切断・再接続時の状態 | 受信の鮮度、送信待ち、転送、処理状態を既存の操作一覧へ接続。再接続だけで成功扱いや自動再送をしない。 |
| 3. 読み取り訂正の利用 | 訂正履歴画面に「訂正を含めて会話入力へ」を追加。原文と訂正を分けた本文を、版を確認して入力欄へ戻す。送信と予定登録は別の明示操作。原文を上書きしない。 |
| 4. 会議しおりのメモ | 既存のしおり名に加え、1件800文字の暗号化メモと版による競合拒否を追加。受信しおりと別保存のため再転送で上書きしない。録音・要約・保留候補への導線も追加。 |
| 5. 横断検索の絞り込み | 種類、開始・終了日、保留中だけ、をスマホとWebに追加。結果50件への制限より先に絞り込む。メモと会話の続きカードも検索対象。 |
| 6. 負荷調整 | 既存の電池・熱による調整へ空き容量を追加。300MB未満で任意撮影を抑制、100MB未満で待機を優先。録音原本の削除はしない。最終判定日時と未計測を表示。 |
| 7. 保留案件の整理 | 30日以上経過した案件、表記を正規化した同名候補を表示。手動完了・不要として取消・継続保持を選べる。手動完了を予定登録成功とは表示しない。 |
| 8. キャラクター表示 | 顔が未判定だった237・247・425・430の元画像を確認し、顔座標を登録。髪で隠れた目や閉じた目を維持し、口は元の下唇を動かす方式を使用。元画像は変更していない。 |
| 9. 会話の続きカード | 話題・決定事項・未解決の点を確認して保存。直近4件の原文抜粋を編集用の下書きとして使う。自動要約とは表示しない。会話入力への復元だけでは送信しない。 |
| 10. 外出中の簡易メモ | 端末内の暗号化メモを追加。入力、会話への復元、保留保存、個別削除。音声入力には使用者が明示操作するスマホのキーボード機能を使う。新しい常時録音は追加していない。 |
| 11. ロキの状態一覧 | 認識、接続、VOICE/TOPIC、録音・KEEPサービス、画像・動画生成待ち、転送、最後の負荷判定をまとめて確認。サービス稼働と保存の完全性、結果待ちと外部処理の成功を区別。 |

スマホの折り畳み機能内、Webの会話タブに「ロキの状態・回答診断・メモ・会話の続き」を追加しました。新しい画面は候補APKをインストールした後に利用できます。
