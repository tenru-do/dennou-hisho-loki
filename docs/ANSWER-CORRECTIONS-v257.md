# ロキ スマホv257：回答への訂正

スマホの「記録」→「保存済みメモ・回答（通信不要）」で回答を開き、「この情報は違う・訂正を追加」を選びます。記録の横断検索からも開けます。PC・タブレットでは会話履歴の回答にある「この情報は違う・訂正を見る」から操作します。

元の回答と訂正を一つの画面で表示します。元の本文は上書きせず、利用者の訂正文と日時を追記します。訂正をさらに直す場合も追記する方式です。訂正はAIが正しさを確認した情報ではないことを表示します。元の履歴を消しても保存時点の原文コピーは残ります。更新前の回答が抜粋なら、その旨を表示します。

保存したものはスマホの「記録」→「訂正付き回答」、Webの送信状況内の「訂正付き回答を開く」から読み返せます。今回の対象は保存済みの会話回答・直接回答・トピック要約です。画像読み取り履歴には従来の専用訂正機能があります。

スマホ内にAndroidKeyStore/AES-GCM/AtomicFileで保存し、スマホでは通信不要で利用できます。Webからはスマホへの接続が必要です。閲覧専用Web接続は表示のみで、保存には操作権限が必要です。モデルへの問い合わせ・学習・再質問・メガネへの指示は行いません。既存の手動バックアップには、この新しい保存領域はまだ含まれません。

上限は100回答、1回答20訂正、1訂正2400文字、保存領域8MBです。元の回答が初回保存前に削除・更新されていれば拒否します。回答の種類・日時・本文・依頼IDで対応付け、別の回答と取り違えません。同じ訂正IDの重複保存は1件として扱います。同じIDで異なる本文を送った場合と、別画面との保存競合は拒否し、入力中の訂正文を残します。最新の訂正を別画面で確認できます。

候補APKの実クラスを別UID・権限なしのAndroid環境で720項目、ブラウザを332項目検証しました。追加26項目は原文保持、暗号化、日時、重複保存、同時保存の競合、回答識別、保存済み原文コピー、上限を確認しています。Webでは安全な文字列表示、入力保持、原文と訂正の同時表示、一覧、ログアウト時の除去、AIへの質問が発生しないことを確認しました。合成データのみで、AI呼び出し・録音・再生はありません。

既存の途中回答ポーリング検証はビルド中の初回に時間閾値で失敗し、処理完了後の単独再実行ではコード変更なしで37項目が通りました。初回失敗記録も保存しています。

スマホv257は既存データを保持して上書き更新済みです。更新前バックアップ、署名一致、インストール後APKハッシュ、初回起動前の既存158ファイル不変を確認しました。メガネはv608のままです。ロック解除後、実機で訂正付き回答の一覧・保存済み回答・元の回答と訂正の表示領域・訂正入力画面・保存と最新確認ボタンを確認しました。訂正は入力・保存せずに戻り、ロキのメイン画面へ戻しました。元の回答や既存の訂正は変更していません。GitHub公開はまだ行っていません。
