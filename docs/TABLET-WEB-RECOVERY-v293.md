# タブレットWeb操作停止の調査・対策 v293

## 実機で確認した原因

2026-10-28。タブレットChromeのロキ画面は、古い接続先192.168.0.25:8766の静的な保存ページだった。見た目のDOMは約525KBあり、script要素0、self.origin=null、api未定義、保存領域アクセスはSecurityError。元のオンラインHTMLは約19KBであり、この静的コピーではボタン・送信の処理を実行できない。古いIPの8766番は応答せず、現在のスマホは192.168.0.10:8766で応答した。

未送信入力が空であることを確認して、同じタブを現在の接続先へ移動。HTTPSの自己署名証明書について、グラスとの既存共有鍵による署名と証明書SHA256を照合し、タブレットの証明書エラー画面の公開PEMとも一致した。明示承認後、その接続だけの続行を実施。Chrome全体の証明書検証は無効化していない。

旧サイトの有効な保存済み登録情報は見つからず、認証トークンの移行は実行していない。現在のオンラインページではJavaScriptと保存領域が正常。新規登録は通常のスマホ側の許可手順を使う。復旧の最終状態は作業領域outputs/tablet-v293へ記録する。

## 再発時の見分け方と追加の修正

- 静的HTMLにも「Chromeの保存ページは操作できません」を残す。オンラインでは既存API取得の最終接続時刻も表示し、保存ページの見た目だけを接続中と誤認しにくくする。独立したポーリングや自動再送は追加しない。
- 保存領域が拒否・容量制限・削除不可でも、例外で画面全体の初期化・登録・ログアウトを止めない。利用可能なセッション保存、最後は現在のページのメモリだけで操作を継続する。永続登録できない可能性を表示する。
- 認証切れでは履歴・添付・接続情報を消去する既存の処理を維持し、未送信の本文だけをページ内に保つ。送信中の結果が未確認なら既存の確認を要求し、自動再送しない。明示ログアウトでは本文も従来どおり消去する。
- 古い接続の401・結果が新しい接続を解除したり上書きしたりしないよう、要求開始時と取得後のセッションを比較する。
- 初期化の異常を画面上へ表示する。生の例外・認証情報・入力本文は表示やログ送信に使わない。

保存領域ガード不足・認証競合・下書き消失は合成環境でも再現した追加不具合である。今回の静的保存ページをJavaScriptだけで操作可能に戻す修正ではなく、オンラインの共有リンクから開き直す必要がある。

## 検証

最終APK内の13個のWebファイルを抽出してソース一致を確認。保存領域・認証復帰の6条件40項目と、全JavaScriptを読み込んだ通常の写真・会話・縦横レイアウト等34項目が成功。外部要求0。実会話・写真・現在地・有料AIを使ったテストは行わず、新しいAI質問も送信していない。スマホv293の実機適用結果は別記録とし、未接続を適用済みと扱わない。

## 追加で実機確認した再発原因とWi-Fiテザリング対応

スマホUSB接続後、共有画面が携帯回線rmnet_data0の100.79.53.91を案内していたことを確認。従来getWifiIpは列挙の最初のIPv4を返し、携帯回線とWi-Fiを区別していなかった。Wi-Fi wlan0の192.168.0.10を優先する処理に修正。VPN・携帯回線・リンクローカルを共有先にしない。

テザリングのAP/swlanインターフェースが存在する場合はその接続先を優先し、通常Wi-Fiと同時に存在する場合は共有画面で別の接続先も選べる。スマホのWi-Fiテザリングにタブレットを接続した後に共有画面を開く。回線変更後は「接続先を更新」で新しいQRとリンクを作る。アドレスや招待を固定しない。サーバーは既存どおり全ローカルインターフェースで待ち受ける。

アドレス選択30項目と、スマホ実ネットワークを使った隔離Android3項目が成功。Wi-Fi＋携帯回線がある状態で192.168.0.10を選び、実Activityメソッドと招待リンクの一致を確認。テザリング実回線への切替は別の検証段階とし、未実施を成功扱いしない。

v293適用後に1,588ファイルの起動前内容保持、署名・APKハッシュ一致を確認。タブレットの登録は維持され、更新後の実画面で認証付きGET・会話／写真タブ・送信ボタンの有効状態を確認。新しいAI質問や録音は開始していない。

## 2026-10-28 実テザリング試験完了

スマホの通常Wi-FiをOFFにした携帯回線＋テザリングだけの状態で、タブレットから認証済み取得・会話／写真タブ・送信ボタン有効・再読込後の登録保持を確認しました。新規AI質問は送っていません。共有QRはテザリングのローカルIPを提示し、携帯回線IPを提示しませんでした。tether-cellular-only-operations.json と tether-cellular-only-share-ui.json に記録。

試験後は両端末の元のWi-Fi復帰とテザリングOFFを確認済みです。タブレットUSBが外れたため、ブラウザー画面を通常Wi-FiのURLへ戻す最終操作だけ未確認です。通常Wi-Fiでは https://192.168.0.10:8766/web/ を開いてください。
