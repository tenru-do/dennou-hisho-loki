# 座位の足元・表示倍率の補正（グラスv731）

承認済み脚組み座位と元ソファ座位の4種類について、画像全体のサイズで倍率が変わる処理を修正した。従来の512×768表示では眼間距離が33.08、33.56、29.21、30.22pxとなり、同じ人物が切り替えで小さく見えていた。

基準の考え中座位の大きさを保ち、各画像の既存の顔ランドマークを用いて倍率を統一。足元の位置は倍率ではなく平行移動だけに用いる。頭頂が画面外へ出る場合は頭を残し、収まらない足先を表示枠で切る。透明な余白や縮小デコードで人物の倍率が変わらないよう、元画像座標で配置する。画像原本・顔・体格・衣装は変更していない。

座位ジェスチャーの別描画経路も点検し、現在の画像に大幅縮小の原因となる外れ点は確認できなかったため、今回は承認座位の描画経路だけを変更した。

`tools/SeatedDisplayScaleChecks.java`の236項目と既存のキャラクター回帰検証が成功。新しい検証は今後のグラスビルドにも組み込んだ。グラスv731のビルド成功。PC比較画像はJavaの実配置計算による合成であり、実機画面キャプチャではない。

グラスv731を上書き適用し、既存397ファイル・設定ファイル・保護設定の保持を確認。接続グラス上の隔離されたAndroid Canvasで座位0/1/2/7と寝姿3を描画し、60項目成功。頭頂の非接触、可視画素、静止再描画の安定、PNG出力を確認した。これは装着者による実際の見え方の確認とは区別する。R08専用機能は再導入していない。GitHub・公開APKは更新していない。
