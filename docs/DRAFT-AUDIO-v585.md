# メモ復元と音声状態の点検（グラスv585／スマホv229）

## メモ復元の競合防止

保存時はメモ画面を開いた時の本文と現在の本文を、復元時は置換確認を開いた時の本文と現在の本文を再比較する。変わっていれば上書きせず、選び直しを案内する。添付・添付処理の状態も直前に取得し直すため、画面を開いた後に追加された画像や動画をメモ本文と混在させない。

グラスでは会話の応答待ちやVOICEの録音処理中も保存・復元を待機する。読み取り・メモ一覧表示は可能。メモ選択や復元で会話を自動送信せず、元のメモを削除しない。

## 読み取り専用の音声状態

スマホの「添付・その他」→「音声・Bluetoothの状態」に、A2DP・通話用Bluetooth・LE音声の出力機器検出、メディア再生検出、現在の音声モードを表示する。「更新」で再取得する。機器名・アドレス・再生内容は表示・保存しない。

この画面はフォーカスを要求せず、再生・停止・音量・接続先を変更しない。出力機器の検出と実際の再生先は区別する。タブレットなど別の機器の再生状態をスマホだけで確認したことにはならない。

## 検証と限界

- 本文変更・添付追加・処理中の拒否についてローカル22チェック。
- 前版の会話・参照・鮮度・メディア所有権テストを継続し、保護対象プロンプトは変更しない。
- 隔離領域でAndroidの暗号化保存と実際の復元ガード、ダイアログの動的取得用インターフェースを確認する。
- 外部送信なし。クラウド認識・実モデル回答・ベンダーTTSを呼ばない。

音を出す検証では、スマホから30秒の低音量PCMをBluetooth A2DPへ出力した。スマホのストリーム上では再生停止・外部メディア命令・バッファ枯渇は検出しなかったが、利用者からタブレットの音声が止まったとの報告があった。これは試験中のスマホ音声出力を伴った測定として記録し、タブレットとの併用や元の問題の解消を確認済みとは扱わない。音声に影響する試験は開始・終了を明示し、再生中の機器を確認する。

詳細なハッシュ・端末情報・生の測定結果は私有の作業出力へ保存する。

続く無音試験ではスマホから音を出さず、グラスのローカルマイク取得と40回のアイドルSTOPチェックを実施した。利用者からタブレットの再生が続いていたと確認を得た。この条件での結果として扱い、ベンダーTTS・クラウド認識を含む全モードの併用保証へ広げない。終了後に通常起動とネット設定の復元を確認した。
