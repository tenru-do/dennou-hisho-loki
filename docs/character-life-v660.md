# ロキの動作・会話連動 v660

顔・全身の既存素材を使い、端末内の動作制御を拡張しました。新規の画像枚数を増やす変更ではありません。

|提案|実装|
|---|---|
|動作のつながり|開始・落ち着きのイージング、段階的な既存ジェスチャー、画像切替時の短い導入|
|顔モード|首の傾き・視線の往復・うなずき・肩の動きを会話イベントへ連動|
|聞く仕草|ユーザー入力時の聞く・うなずく動作|
|内容に合う仕草|考える・説明・方向・喜び・訂正を分類し、既存表情と全身クリップを選択|
|触れ方|タップ、450ms以上のゆっくりしたスワイプ、850ms以内の連続操作で反応を変更|
|接触中の変化|保持中に24秒周期の短い小さな動き。接触状態や会話入力は変更しない|
|自発的な働きかけ|待機中の控えめな招き。オフ・少なめ・ときどき・多め。実際の接触成立は自動で起こさない|
|全身の重心|顔・足元を固定した肩と上半身の動き。耳たぶ・挨拶・招きの既存素材を会話へ割当|
|場面ごとの強さ|聞く65%、話す38%。ナビ・会議録音・否定表情・個別プレビューの優先を維持|
|好みと反復|動き3段階・自発的な仕草4段階を別々に保存。連続する喜びは落ち着く動作へ切替|

## 操作

グラスの SET → 動きの豊かさ → 控えめ／自然／豊か。
同じ画面の「親密な仕草の頻度」で自発的な招きの頻度を設定できます。「会話の仕草を確認」には8種類の端末内プレビューがあります。プレビューからAI・録音・撮影・経路検索は開始しません。

## 負荷と適用範囲

新規ネットワーク呼出し・センサー監視・常駐タイマーを追加せず、既存の描画周期を使用。仕草のイベントは4.4秒で収束し、非表示・バックグラウンドでは既存の停止処理に従います。素材の追加デコードは既存キャッシュを再使用します。ただし動きの追加による電力差そのものは、長時間の実測を行っていません。

会話の意味やAIへ渡すプロンプトは今回変更していません。仕草の分類は限定された語句・既存の意味分類に基づき、自由文すべてを理解する機能ではありません。自発的な招きは表示のみで、保持状態を勝手に変更しません。
