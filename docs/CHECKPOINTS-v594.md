# 会話訂正・通信・ナビ・保存先・診断報告（グラスv594／スマホv238）

2026-10-20。既存の未コミット変更を保持。今回の検証は外部API送信なし。検索・生成・実予定登録・撮影・録音は行っていない。

## 1. 入力を訂正

スマホの直近送信状況をタップ→「直近の入力を訂正」。会話の参照・予約候補・認識文画面にも同じ入口を追加。15分以内の確定VOICE認識文とID付き送信本文から新しいものを示し、内容を確認してから入力欄へ戻す。TOPIC/AMBの周囲の発言を自分の入力として自動選択しない。確認中に本文・添付が変われば置き換えない。添付付きの依頼は既存の送信控えから復元する。復元だけで送信しない。過去の回答や予定登録を取り消す機能ではない。

グラスの認識文タップによる訂正にも既存入力の置換確認を追加。Webの認識文復元は期限・確定状態・添付を確認し、古い画像参照を外してから修正する。発話「今の違う」を自動で取り消し命令にする変更ではない。

## 2. 通信の経路ごとの状態

「依頼・転送・動作チェック」とWebの操作状態に、スマホ↔グラスの直近状態受信と、グラスから報告されたGemini処理を別表示。古い状態は現在の成功と見なさない。接続エラー・タイムアウト・認証・制限などは固定語彙で表示。物理的な障害箇所を特定できないときは未確認とし、結果不明の依頼は再送しない。既存のID重複防止を維持。

## 3. ナビの鮮度

グラスのナビ時計に現在地と経路取得の経過時間を表示。経路データの取得時刻と位置情報の時刻は別。未取得・未来時刻・古い位置は明示。スマホからの受信が15秒以上途絶えた場合、グラスの案内欄を通信更新待ちへ置き換え、残った経路が前回のものと分かるようにする。受信の鮮度判定は単調時計。新しい受信で通常の案内更新へ戻る。実地の経路API呼び出しや装着歩行での確認は今回行っていない。

## 4. 保存先の区別

スマホ/Webの操作状態に、ロキ内の写真在庫、READ枚数、READのギャラリー保存時確認記録を区別して表示。最大30秒の集計キャッシュとメタデータ2000件の上限を設け、一部を確認できない場合は範囲を明示する。ギャラリーから後日削除された写真の現在の存在や、KEEP写真・PC保存の完了をこの記録から推定しない。グラスの対象・未転送分・録音保存区間は既存のID付き転送記録で別確認する。過去に削除した写真は復旧しない。

## 5. 個人情報を除いた報告

スマホの「依頼・転送・動作チェック」またはWebの操作状態から「個人情報を除いた不具合報告」。報告を表示し、明示的なコピー操作だけでクリップボードへ入れる。自動送信なし。許可したキーのみ取り出し、アプリ版、受信状態、依頼状態の件数、固定分類のエラー原因、転送件数、ローカル検査結果を含む。会話本文・認識文・予定名・場所・依頼ID・URL・認証情報・生のエラーは含めない。
