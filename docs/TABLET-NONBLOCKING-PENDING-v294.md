# タブレット：未完了確認を毎回出さない v294

原因：conversation-ui.jsの送信前処理が、未完了の依頼が1件でもあれば毎回window.confirmを呼んでいた。

修正：未完了の件数・待ち状態・一覧を残し、追加の質問は画面内の案内だけで送る。送信前の接続確認、セッション切替の検出、入力が途中で変わった場合の中止は維持。未完了の依頼の削除・完了扱いへの変更・自動再送はしない。古い依頼が止まった原因自体を一律に修復したという変更ではない。

操作画面v294へ更新し、conversation-ui.jsのURLもv294に変更。更新後、タブレットのページを一度再読み込みすると反映される。
