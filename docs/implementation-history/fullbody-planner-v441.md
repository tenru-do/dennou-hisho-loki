# 全身モード・システム手帳 v441候補

グラス着用の元画像とAndroid描画は全身でした。v440の確認ページだけが顔の拡大表示になっていました。確認ページを修正し、立位・座位とも頭から靴先まで収まるブラウザ描画を目視しました。身体を切り詰める変更は行っていません。

imagegenの組み込み生成で立位6枚・座位6枚のシステム手帳画像を作成し、原本を変更せず追加しました。タブレットではなく紙ページ・リング・ペンのある手帳です。生成条件はprompt-standing.txtとprompt-seated.txt、素材はplanner-standing.pngとplanner-seated.pngです。

待機開始から60〜90秒の区間に、そのときの姿勢に合う手帳動作を表示します。5分周期です。閉じた手帳→開く→書く→考える→閉じるの6種類を組み合わせ、各フレームに既存の呼吸・口・瞬き描画を適用します。元から閉じた目は保持します。会話・音声取得・実演が始まれば既存の優先処理に従って中断します。

既存の立位・座位のタイミングは変更していません。新しい立位は既存の立位、座位は既存の座位の全身高に合わせ、床位置を保ちます。ペン拾いは指示に応じる既存機能を使用し、立った状態・座った状態を維持します。自動でペンを落とす処理は再有効化していません。

## 確認済み

- 12フレームすべてに顔座標があり、全身の外周がセル境界に触れていないことを画像分析と目視で確認。
- ビルド：72ソース、エラー0、警告0。APK署名が既存と同じであることを検証。
- 元の素材84ファイルをv440 APKとSHA256比較。新規2ファイルだけを追加。
- 既存264フレームの領域・縮尺・左右位置の値を保存元と照合。
- FullBodyPlannerTest：6種類ずつすべて再生されること、姿勢、既存姿勢との全身高、頭・足・左右の描画範囲、既存のタブレット・コーヒー・ペン拾いを確認。
- AmbientDisplayPolicyTest、既存の立位・座位切り替え回帰テストも成功。
- ブラウザの全身プレビュー6枚にJavaScriptエラーがなく、グラス着用の立位・座位を目視。キャプチャはglasses-standing-fullbody.png、glasses-seated-fullbody.png、preview-fullbody.png。
