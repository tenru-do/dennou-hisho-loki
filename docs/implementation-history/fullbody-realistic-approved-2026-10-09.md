# ロキ全身画像：リアル・細面版の採用基準

2026-10-09、ユーザーの「この方向でお願いします！」により第3案の方向性を採用。

基準画像：approved-reference-three-poses.png

- 細面で縦長の自然な輪郭。頬の丸みを抑え、顎を極端に尖らせない。
- 目・鼻・口は成人のリアルな比率。落ち着いたクールな目元。
- 非対称のショートヘア、耳飾り、長身の印象を維持。
- 胸のボリュームは控えめ、腰とヒップはスリムで自然な体型。
- 黒い長袖ブラウス（第二ボタンまで開ける）、深いサイドスリットのタイトスカート、パンプス。
- 黒背景と白を中心とする単色グラス向け表現。露出した肌・脚を明るく表示する。
- 正面立ち、説明する立ち姿、正面座りで顔と体型を統一。

採用範囲は見た目の方向性と基準稿。全表情画像への展開・瞬きと口の位置調整・グラス向け表示調整・実機への置き換えは未実施。現在のアプリと画像セットは保持している。

生成画像には肌の薄い陰影もあるため、グラス向け素材を制作する際は肌の点灯を十分に確保する。立ち／座りの身長、足元、頭部の余白と、各ポーズの同一人物性を確認する。
