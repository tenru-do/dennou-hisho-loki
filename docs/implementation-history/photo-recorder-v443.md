# ロキ連続撮影 v443

- 保存上限 **5,000,000,000 bytes (5GB)**。実際のJPEG容量で管理。
- 5秒間隔が標準。10秒間隔も選択可能。カメラ利用の競合・撮影時間により実際の間隔は変動する。
- SET → REC、またはCAM長押しで開始・停止。
- 撮影中は既存のCAMボタンが **KEEP** になる。クリックで前2分＋後1分を保護。停止するとCAMに戻る。
- 音声：`連続撮影を開始して` / `ドラレコを止めて` / `今の場面を残して` / `さっきの場面を保存して`。
- 保護済みJPEGは自動削除しない。上限超過時は通常写真の古い順で削除。保護写真だけで満杯、空き容量1GB未満、連続した撮影エラーの場合は撮影停止。
- 写真はグラスのアプリ専用外部領域 `Android/data/com.example.rokidkeyboardbridge/files/Pictures/loki-recorder` に保存。保護は `.keep` マーカー、未来の保護期限は `keep-until.txt` に記録。
- 撮影はカメラ用foreground serviceで実行。サービスは再起動後に自動開始しない。マイクやGeminiへの送信は行わない。既存AMBは別機能。
- 記録用画像は機器が対応する1920×1080以下のJPEG。ハードウェアJPEGと回転情報をそのまま保存し、全解像度での再圧縮を避ける。1MBは保存期間を計算する目安であり固定サイズではない。
- スマホでの一覧・保護解除・写真転送は今回未実装。保護画像はグラス内に残る。

## 検証

`host-tests.txt`: 5GB定数、古い写真からの削除、他ファイルの保持、前後の保護、再起動での維持、保護写真で満杯の場合の停止、音声指示の否定・引用除外。

`device-test/result.txt`: 実際のサービスでJPEG保存、保護、停止を確認。device-test/buttons-result.txt でKEEPボタンの保護操作と停止後のCAM復帰も確認済み。

APKの署名・パッケージ・表示名と更新後のAPKハッシュを照合。更新前のAPK・アプリデータ・既存の記録写真は `device-backups` に保存。スマホは変更していない。

v442の最初の実機テストではメモリ不足によるプロセス終了を検出し、v443で高解像度の再圧縮を削除、既存の顔描画カメラ休止処理を連携した。短時間の機能試験であり、長時間の発熱・電池持ち、歩行中の撮影品質、装着した表示のなめらかさは未検証。
