# 全身モード 中間画像 v414

生成画像は別ファイルで保存、既存決定稿は変更なし。シートの罫線/余白を避けた12矩形を定義。最初の腕候補は後半の横幅による縮小があったため不採用、縦長版へ作り直してグラスCanvasで確認。
