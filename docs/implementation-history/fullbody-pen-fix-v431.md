# v431 全身リアクション・口・ペン拾いの修正

実際の端末履歴「ペンが落ちた」に動作の条件が一致しなかった。落ちたという報告にも同じ拾う動作を接続。否定・仮定・引用は除外。

Rokid直接TTSの経路で全身へ全文・各読み上げチャンクを渡していなかったため接続。実際の耳への返答「少々動揺してしまいます」を弱い驚きとして判定。閉じ口素材の発話時開口を0.105倍から0.18倍へ拡大。

264素材はv430から変更なし。顔モードの描画変更なし。Androidで指示判定・48枚の拾う描画・発話と表情の実描画・264コマの瞬きと口の3168チェックを実施。全身以外の経路に関わる制御はそのまま。

インストール状況とバックアップ先はverification.json。装着時の反応・見やすさはユーザー確認が必要。
