# 全身モード v426

通常の立ち姿（004）を縮尺基準に固定。最小画像を全体の基準にして座り姿まで縮小していたv424の問題を修正しました。正面座りと待機座りの頭部サイズを通常の立ち姿に合わせています。グラス表示領域240×598の場合、基準の目の外側間の立体寸法は32.10pxで一致します。足元は共通の下端に固定します。

scale-comparison.png はAndroid Canvasで実際に描いた通常立ち・正面座り・腕組み座りの比較です。スマホにはアプリをインストールせず、候補APKを読み取り専用で描画しました。実機装着時の見え方は別途確認が必要です。

ポーズ変更は360msの滑らかな補間。立ち座りは既存6枚の前後を630msでつなぎます。顔・口・瞬きも体と一緒に合成し、加算合成で黒背景による減光を抑えます。細かな待機・歩行・足組みフレームは70msで補間します。呼吸は5.2秒周期、胸元のみの微小変形で頭と足元を固定します。

通常の立ち座り・待機切り替えタイミング、会話の感情選択、顔モードは変更していません。全72画像・音声等アセットもv422と同一です。画面をはみ出す一部の極端なポーズは、その画像だけ全身が収まる上限で縮尺を制限します。手や顔を隠した5枚は同じ元画像シートの頭部測定値中央値で補正しています。

ビルド成功。11種のAndroid検証が通過しました。合成の明るさ4,139,520画素、198枚の瞬き・口、姿勢区分781,920回、全181ポーズの到達性、遷移、会話反応、呼吸の変形範囲、通常立ちと待機座りの頭部寸法一致を検証しています。詳細はdevice-tests.txt。

グラスへのインストール状況はverification.jsonのinstalledOnGlassesが正です。install-glasses.pyは対象グラスの識別、現在APK・アプリデータのバックアップとハッシュ確認後にのみ更新します。
