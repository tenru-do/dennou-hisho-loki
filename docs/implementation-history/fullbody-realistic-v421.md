# ロキ 全身モード v421

対象は全身モードのみ。採用したリアル寄り・細面・控えめな胸・スリムな腰の基準画像を使い、全33シート／198フレームを作成し直しました。立ち姿・座り姿・歩行・足の組み替え・立ち座りとジェスチャーの中間画像を含みます。白〜黒の原画を単色緑LEDで表示する構成です。

各フレームの目・口の位置を取得し、顔の向き、目の開閉、手やアクセサリーによる遮蔽を画像一覧で確認しました。自動取得できなかった84番は手動で調整しています。位置取得用のMediaPipeモデルはPCの制作作業で使用し、Androidアプリには追加していません。

瞬きは開いた目の101フレームに適用し、閉じた目・隠れた目の97フレームは原画のまま維持します。発話時の口は198フレームすべてに対応。通常の口は唇の端を残して小さく開閉し、大きく口を開いた表情は元の画像の形を保ちながら変形させます。待機中は口を動かしません。足の組み替えと中間画像にも、それぞれの顔位置で適用しています。顔の描画は画像の座標に追従し、半解像度の座り・中間画像にも対応します。

立つ・座るタイミング、足の組み替え周期、会話の感情とポーズの対応、同じ姿勢内でのポーズ切り替えは維持しています。`MainActivity.java`を含む8制御ファイルは作業前のバックアップとSHA256で照合済み。既存APKに含まれる全身以外の画像・アセット39ファイルも内容一致を確認しています。スマホアプリは変更・インストールしていません。
