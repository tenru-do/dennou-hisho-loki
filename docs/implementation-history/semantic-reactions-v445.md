# 全身モードの意味判定と自動監査 v445

全身モードの通常Gemini会話に、感情・強さ(0〜3)・動作の内部メタデータを追加。返信の意味から生成され、本文・会話履歴・音声へ渡す前に除去する。追加の推論API呼び出しは通常運用では不要。

- 画像選択は意味情報を利用。姿勢を維持し、対応する動作がある場合はその画像を優先。
- 拒否・怒りを示す本文や既存の場面判定は、モデルが誤って喜びなどを返しても優先して補正。
- メタデータがない・不正・途切れた場合は既存のローカル判定へ戻る。メタデータは読み上げない。
- 今回の実際の会話は、修正前の判定なしから、修正後はREFUSE、座位画像130へ変化。既存会話を変更したり再送信せずホストで再現した。
- 発話全体の開始時に、不一致・判定不能・補正を `files/fullbody-reaction-audit.jsonl` に記録。各ファイル約256KiBで一世代だけローテーション。本文・APIキーを記録せず、既存履歴と照合するためのSHA256を保存。
- 実行中にソースを書き換えたり画像タグを自動変更する機能ではない。意味判定による新しい言い回しへの対応と、既知の矛盾の自動補正を実施する。未解決の監査記録は追加の回帰テストに利用できる。
