## 変更

- CTRLはSettings.System.SCREEN_BRIGHTNESSを読み書きし、ウィンドウの輝度を本体へ委ねます。旧loki_manual_brightnessは使用せず、CTRLを開いたときに削除します。本体側の変更はContentObserverでパネル表示へ反映します。操作時には本体を手動明るさへ切り替えます。設定書き込みが拒否された場合は権限画面へ案内し、変更に成功したふりをしません。Rokid独自のLED制御が同じ設定を使用するかは接続後に確認が必要です。
- TOPIC内のAMBに環境音・カメラ・両方を追加。既存0..2のマイク／Bluetooth／両方の保存値は変更せず、新モードは3..5です。マイクは最大4秒、カメラは既存の小サイズ静止画取得経路を利用します。取得後に約15秒待ち、既存のAPI間隔・熱・電池・ナビ・VOICE・会話優先の休止条件を使います。生の音声・写真はファイルに保存せず、既存のGemini APIへ送信します。マイク・カメラのAndroid権限が必要です。
- 新AMBの反応は短文と感情。NONE、同じ短文、発話中の重複を抑え、喜びなどを全身のポーズ選択と口の動きに渡します。既存の音声再生を利用します。実際のライブ会場での認識・場面選択・タイミングは未確認です。
- 264フレームの顔座標を監査。繋ぎ36を除く228のうち、119は開いた目に瞬き、109は元から閉じている／隠れている目を保持します。ポーズごとの時計リセットをなくし、繋ぎフレームの追加瞬きを抑えます。発話口の設定も尊重します。
- 全身像だけにRokid Glassesのフレーム重ね描画を追加。8分周期の最後90秒に着用し、待機中かつポーズのブレンド完了後に切り替えます。透明レンズ、太めの角を丸めた台形のフレーム、ブリッジ、外側の小型カメラを単色で表現します。Windows閲覧ツールのkernel assetsパスエラーを、専用一時プロファイルの非表示ブラウザで回避しました。Rokid公式の商品写真を目視し、フレーム形状・透明レンズ・外側カメラ位置を照合して修正しました。単色の簡略描画であり、実機での見え方は未確認です。形状プレビューはindex.htmlです。
