# 正面座り・脚の組み替え v415

新規6コマ: 正面で普通に座る(膝を閉じ両足を床につける)、右脚を持ち上げる、右脚を組む、脚をほどく、左脚を持ち上げる、左脚を組む。元の決定稿と既存画像は変更していません。
通常の待機表情000/014は新しい内部ポーズ168(正面座り)へ対応。聞き取りは従来の立ち姿004、返答時は既存の姿勢選択へ戻ります。168も座り姿と判定するため、v414の立ち座り中間画像が動きます。
待機中だけ24秒周期で0→1→2→1→0→4→5→4→0と再生。通常姿勢、組んだ姿勢を数秒保持し、持ち上げ/ほどきコマは150ms。会話中は脚の待機サイクルを使いません。新正面座りにも瞬きを追加。
6コマ共通の横方向切り出し、縦位置を調整してシート罫線を除外。描画高は立ち姿基準0.76、床位置共通。生成画像の細部は完全同一ではないため、必要なら差分をさらに揃えられます。
画像は2分の1解像度でキャッシュ、計1004784bytes(約0.96MiB)。既存の立ち座り/腕キャッシュと合わせ約2.43MiBの追加コマBitmap。APK全体・シート読込み時の一時メモリとは別。
検証: 43ソースビルドエラー0、署名検証成功。RG_glasses上で6フレーム読み込み、表示高維持、瞬き位置、左右の脚サイクル時間、正面座り→立ち姿の対応テスト成功。全168表情の純粋ポリシーテストも成功。実機待機画面と24秒録画を保存。録画/Canvas画像は装着時の光学表示ではありません。
