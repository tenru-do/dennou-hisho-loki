# 全身反応・待機・生活コメント修正 v418

- 原因: 通常会話の発話区間判定が既定0（案内）へ戻り、拒否・不快感を拾っていなかった。全身専用にロキの返答を解析する FullBodySpeechStance を接続。拒否がある返答では腕組み等2/20/29を維持し、次の返答で解除。顔モード判定は変更していない。
- 画像反応だけの修正。Geminiの応答文を強制的に拒否文へ書き換える機能ではない。一般的なセクハラの話題だけを拒否と見なさず、返答に現れる拒否・不快の言い回しを使用。引用や一部否定例を除外。未登録の言い回しは今後追加できる。
- 足: 24秒周期から180秒周期へ変更。最初の60秒は正面、左足組み30秒、正面45秒、右足組み30秒、正面へ戻る。中間フレーム維持。
- 待機: 5分周期で正面座り3分→思案座り1分→腕組み座り1分。会話時は反応を優先。悲しみ・消耗の座り画像は通常待機に混ぜない。
- 自動コメント: 30秒無言で寂しがる旧指示を削除。1時間の無言を目安に、07:00〜22:00 JSTのみ。実際の発話から1時間の間隔と前回コメントを永続保存。SKIP/寂しさ・返事催促/同文を抑制。
- 時刻と2時間以内の天気情報を使用し、生活行動や未確認の予定を決め付けないよう指示。新しい情報や話す理由がなければSKIP。16:30の既存生活コメントも帰宅・夕食の決め付けを除去。
