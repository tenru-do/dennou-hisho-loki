# 全身モード：待機ポーズ固定の修正（v422）

待機中に微笑みなどの感情ポーズが残ると、通常・傾聴用の巡回条件から外れ、同じ立ち姿のまま固定されていました。

会話の反応を15秒保持したあと、同じ立ち／座り区分の待機ポーズに巡回するよう修正しました。立ち待機は既存6種類を使用します。座りは既存の通常／思案の各巡回と足組み中の保護を維持します。立つ・座るタイミング、会話中の感情別ポーズ選択、顔モード、画像、瞬き・口の描画処理は変更していません。

ビルド成功。10種類のAndroidテストが通過。立ち／座り区分の781,920チェック、全181ポーズ到達性、198枚の顔描画、会話反応、足組み、遷移を確認しました。微笑み・怒り・涙などが待機中に固定されない回帰テストを追加しました。APK内の全72アセットはv421と同一です。

修正差分は changes.patch、テスト結果は device-tests.txt。source-before-v421.zip は変更前ソースです。

グラスへの更新状況は verification.json の installedOnGlasses を参照してください。接続確認、現在APKとアプリデータのバックアップ・ハッシュ検証が完了した場合のみ install-glasses.py が更新します。
