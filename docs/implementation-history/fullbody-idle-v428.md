# 全身モード v428

待機中の似た姿勢の往復を増やす。通常姿勢は4秒後、会話の感情姿勢は15秒後から、5.6〜7.4秒間隔で静かな同じ立位・座位のポーズを切り替える。元の姿勢へ戻る区間を挟み、既存の中間動作を使う。

瞬き、呼吸、発話表現、立つ／座る時刻、足の組み替え時刻、全身縮尺、ボタン・状態表示配置、顔モードは変更しない。234フレームの素材をそのまま使うため画像データ追加はない。足の組み替え中は安全な完了区間を待ち、タブレット・コーヒー中は専用動作を優先する。

検証状態・インストール状態はverification.json参照。更新前に対象グラスのAPKとアプリデータをバックアップして検証する。
