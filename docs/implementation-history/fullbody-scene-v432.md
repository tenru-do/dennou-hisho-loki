# 全身モード v432：会話場面の反応選択

返答のみの分類に、ユーザー入力と全文返答による場面ガードを追加。身体への接触・強引さ・婉曲な拒否を合わせて判定。拒否場面で説明・案内・笑顔へ戻らない。読み上げの区切りと次のやりとりをまたいで保持し、謝罪や明示的な話題変更で解除。

引用・仮定・被害相談・医学的質問は接触場面と分ける。ロキの返答が明確に照れ・吐息などを示す場面は、その反応を使用。264素材はv431とバイト一致。顔モード変更なし。

今回の実装は文脈を入力に加えた規則ベースの第一段階。Geminiから構造化した状況・感情・動作を受ける方式ではなく、未登録の婉曲表現には限界がある。場面テスト、実Viewの発話・反応、48拾う描画、全画像への到達性、立ち座り不変性をAndroidで検証。装着時の見え方は別途確認が必要。
