# v435：メイン画面で音楽を直接オン・オフ

ロキ画面の下部、SETとCTRLの間に専用の音楽ボタンを追加しました。パネルを開かず1回で操作できます。

- 再生中は PAUSE：押すと一時停止。
- 停止中は PLAY：押すと再開。
- 操作中は …：連打による重複操作を防止。
- 未接続時は MUSIC：接続を確認し、押すと再接続を試みます。

Bluetooth再生元の実際の状態を監視して表示を切り替えます。ローカルの仮のON/OFF状態だけで判断しません。現在の再生元を対象とし、スマホとタブレットを勝手に切り替えません。音楽操作からナビ・会話・VOICEの停止やTTSは呼びません。明るさ調整はCTRLに残っています。

実グラスのロキアプリUIDからメイン画面の実ボタンをクリックし、停止・再開の実際の状態、PLAY/PAUSE表示、画面内にボタンが収まることを確認しました。明るさ・パネル内のボタンとスワイプの回帰テストも通りました。装着時の操作性と音の確認は別途必要です。

264画像・84素材はv434とバイト一致。更新前のAPK・アプリデータをバックアップし、更新後のAPK・証明書・ハッシュ一致、起動と全身モード設定の保持を確認しています。スマホのアプリは更新していません。
