# ロキ 全身画像の感情・リアクション連動 v419

実装・署名済みAPKの作成と、再接続したグラスへのv419インストールを完了しました。Android上の画像読み込み・実Viewの反応選択・座りフレームの新テストも通過しています。

## 画像の登録と選択

- 元の表情168枚、待機6枚、歩行6枚の計180枚をすべて分類し、選択可能にしました。追加の正面座りを含め、181姿勢の選択一覧があります。
- 追加済みの正面座り6フレーム、立ち座り6フレーム、手振り6フレームも使用します。登録180枚＋追加18枚＝198フレームが描画経路に入ります。正面座りの6枚目などとは別に、これまで使われていなかった中立の座りフレーム3も待機へ接続しました。
- 各画像に反応の種類、強さ0〜3、立ち／座り、身振りを設定。原画像の白黒描画は変更していません。
- 喜び、自信、怒り、悲しみ、涙、驚き、照れ、心配、拒否、疲労、吐息、息切れ・喘ぎ、安堵、緊張、思案、説明、傾聴、通常、歩行を分類。
- `FullBodyPoseCatalog.java` が実行時の分類元です。`catalog.csv` はそこからJavaで書き出した一覧です。画像番号が同じでも顔モードと全身の感情は一致しないため、カタログで選んだ全身番号を顔用番号へ再変換しません。
- 同じ反応の候補を会話をまたいで順番に使用します。画像確認用にSETへ「全身画像の確認」を追加しました。各画像を選ぶと全身モードで表示し、「会話に合わせて表示」で戻れます。新しい発話でも確認用固定表示を解除します。

## 会話との連動

- 現在の発話区間を判断し、後の文の感情を先取りしません。
- 「確認します」「いいですね」「その行為は適切ではありません」などの会話文と、括弧内の「息を切らしている」「涙を流す」などの動作記述を扱います。
- 説明・引用・第三者の反応・否定文を区別するルールを追加しました。全文がロキ自身の台詞として引用符で囲まれている場合は反応を拾います。
- 中立のつなぎ文だけで前の感情を消しません。拒否後も怒り・涙・不安などは表現し、「落ち着きました」などの明示的な回復や新しい返答で解除します。
- 250msの安定待ち、最低900msの保持、進行中の中間画像の完了待ちを維持。専用の立ち座り／手振り中間画像がない組み合わせは200msのクロスフェードです。
- 座った反応がある種類では座り画像も候補にします。画像集合にすべての感情×強さ×立ち座りが揃っているわけではないため、必要に応じて立った反応を選びます。
- 立ち待機は6枚の瞬き列、歩行の発話・動作記述は6枚の歩行列へ接続。座り待機は長い周期で正面／思案／腕組みを選び、足は180秒周期です。
- 既存の顔モードの感情選択や音声・会話処理は維持し、全身表示側で反応を選びます。寂しさの自動発話抑制などv418の生活コメント修正も維持しています。

## 残る限界

静止画の口の開き・胸や頭の身振りから呼吸系の候補を分類していますが、画像だけでは驚き・泣き・息切れなどの内面や原因を断定できません。会話の言い回しと強さで候補を選びます。未登録の言い回しや微妙な画像解釈は実会話で調整が必要です。全画像に口パク・瞬きのオーバーレイや専用の中間画像があるわけではなく、音素単位の口同期も未対応です。
