# v434 ロキの画面で音楽・明るさを操作

画面のCTRL、またはSET → 音楽・明るさから操作パネルを開きます。ナビ・会話の停止処理は呼びません。黒背景の小さいパネルを下に開き、背面を暗くしません。

- 一時停止／再開：現在のBluetooth再生元へ送信。スマホ・タブレットのどちらを再生元にするかは端末側の接続状態に従います。
- 暗く／明るく、スライダー：ロキのウィンドウの明るさを5〜100%で調整。値を保存し、自動暗転からも保護します。端末全体の明るさ設定は書き換えません。
- スワイプ領域：左で一時停止、右で再開、上で明るく、下で暗く。接触座標とDPADへ変換されるグラスのスワイプに対応。領域を選んだ状態のタップでボタンの選択へ移れます。
- 「端末の明るさに戻す」でロキ専用の調整を解除。「閉じる」でパネルを閉じます。

グラス上の実アプリUIDからBluetoothサービスへ接続し、一時停止・再開後の再生状態を確認しました。ボタン・タッチのスワイプ・DPAD、明るさの保存・ウィンドウ反映・自動暗転の抑止・リセット・ナビとVOICEのフラグ保持もAndroidで検証。実際の装着時のスワイプ入力形式・LEDの見え方・ナビ中の使い勝手は別途確認が必要です。

スマホのアプリは変更・更新していません。264枚の画像と84素材はv433とバイト一致。30秒移動は今回の対象外です。v434の更新前にはAPKとアプリデータをバックアップし、更新後のAPK・証明書・ハッシュ一致を確認しています。
