# 全身の会話反応 v417 / スマホ入力欄 v151

## 実装
- 168表情の切り出し画像を contact-0～3 で目視確認。image-reaction-audit.csv は画像から読める表情・姿勢の手動分類。内面の感情を確定するものではない。
- 顔側の既存コメント・発話区間の感情選択は変更せず、全身専用 FullBodyExpressionMap で画像内容の不一致を修正。例: 悲しみ10→3、怒り15→49、通信エラー6→36、検索2→10。
- 微妙な表情の解釈は今後の実機確認で調整可能。原画像は保持。現時点の分類はJava対応表で使用し、CSVはレビュー記録。
- 250ms安定待ち、最低900ms保持、待機座りへ1800ms猶予。進行中のつなぎを完了してから最新の反応へ変更。
- 対応する姿勢変更は既存6フレーム、その他は200msのクロスフェード。全ポーズ間の専用中間画像を生成したわけではない。
- 瞬き・口のオーバーレイは対応済み7姿勢。全168姿勢の口パクや音声の音素同期は未対応。
- スマホ: IMEとシステムバーの大きい方をScrollView下余白へ反映。入力欄を表示範囲へスクロールしadjustResizeを設定。
