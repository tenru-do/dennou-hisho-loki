# 参照の選び直し時に質問本文を保持（スマホv224）

スマホv224を反映しました。グラスはv576です。既存の未コミット変更を保持し、GitHubへpushしていません。

## 動作

参照一覧から作った質問の書き出しに追記している場合、別の添付や新しい参照を選び直すと「書いた質問を残して参照先を変更する」確認を出します。承認すると添付番号・種類に対応する書き出しだけを差し替え、その後に書いた質問をそのまま残します。改行・絵文字も保持します。取り消した場合は本文と選択を変更しません。自動送信しません。

スマホでは確認を出している間に下書きが変わった場合も、古い内容で上書きしません。書き出しの差し替えで上限を超える場合は切り詰めず、本文を残して止めます。Web側でも同じ文字数保護を行います。

参照一覧由来であることを識別できない通常の下書きは、従来どおり置き換えの確認を出します。無関係な文章を勝手に画像質問へ付け足しません。参照の選び直しは別の送信IDを持つ新しい下書きとなり、以前の送信済み依頼を変更・取消する操作ではありません。前の結果が未確認なら、送信状況も確認してください。

## 検証

- ホスト回帰456項目成功。うち10項目で本文保持、同じ参照書き出し、無関係な下書き、空値、繰り返し切替、文字数超過拒否などを確認。
- ブラウザ61項目成功。取消時の全文保持、複数行の質問保持、添付番号・動画種別の更新、切替時にPOSTしないこと、文字数超過時の拒否を追加。
- スマホv224実機60項目成功。本文保持・改行・絵文字・同じ書き出し・上限拒否を本番ポリシーで検査。キュー・参照キー・保存等の既存検査も継続。スマホの確認ダイアログを人が実際に操作する試験とは区別します。
- ビルド成功、会話プロンプト基準2区間の検査成功。プロンプト変更や追加のモデル送信はありません。
- 更新対象の機種と署名を照合。旧APKとアプリデータのバックアップ全メンバー読み取り・SHA-256照合、インストール済みAPKと成果物のSHA-256一致を確認。

実機試験は合成データ・隔離保存先で実施しました。実際の予定登録、Gemini送信、画像・動画生成、撮影、録音は行っていません。新しい権限・外部送信先・保存先はありません。送信時とグラス実行前の参照照合は維持しています。
