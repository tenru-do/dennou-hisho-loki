# Reliability: glass v593 / phone v237

2026-10-20。既存の未コミット変更を保持。公開・GitHub送信はしていない。

## Changes

- 入力欄の近くに直近3件の共通送信状況を表示。2行表示をタップすると全文を確認。IDで追跡できない旧記録は結果未確認とし、本文一致で完了を推定しない。
- 会話・ナビのため延期したCodex通知を端末暗号化領域に最大20件保存。質問を先に表示。元の5分の有効期限を延長しない。質問は明示的確認まで送信元にも残る。通常通知の要約は無音。保留通知の確認は操作確認画面から。これはCodex通知向けであり、全通知一般の統合ではない。
- カレンダー候補を登録先・日時・場所で表示し、訂正前後の差分を確認。スマホ/Webから保存済み候補の同一・時間帯重複を読み取り専用で確認可能。編集途中の値でなく保存済み候補が対象。繰り返し各回・未同期の予定は確認範囲外。明示的な登録操作と登録直前の重複再確認は維持。
- 画像読み取り文に明記された不鮮明・未確認などを確認事項として表示。記述がないことは読み取りの正しさの保証ではない。新しいOCR/API送信は追加していない。
- tools/Test-ReleaseReliability.ps1 を追加。既存の会話・受信箱回帰に、通知・送信記録・候補差分・読み取り確認事項と実ブラウザの検証を統合。
- 「それはいくら？」「ほかには？」「その条件では？」の省略質問を直前の関連文脈へ接続。
