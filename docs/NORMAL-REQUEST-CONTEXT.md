# 通常依頼の文脈分離（グラス539）

通常の質問に、保存カスタム指示内の性的な演技指示を添付しない。設定の原文・会話ログは削除せず、依頼作成時の参照だけを分離する。地域・施設などの情報収集の好みは保持する。

直近の画像の読み取り結果は、写真についての後続質問に限って添付する。無関係な独立したイベント検索には添付しない。

PROHIBITED_CONTENT / SAFETY / BLOCKLIST等を受けた依頼は、別モデルへの切り替えや履歴除去による自動再送を行わず停止する。エラー説明も実際の動作に合わせる。HTTPの一時的な障害と安全判定を区別する。

検証では実機上で送信前のプロンプトを構成し、該当指示・無関係な写真と会話履歴が含まれず、地域の検索設定と現在の質問が残ることを確認する。停止済みの依頼は再送しない。
