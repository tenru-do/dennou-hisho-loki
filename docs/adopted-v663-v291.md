# 採用済み改善の実装：グラスv663／スマホv291

採用した27項目を実装し、グラスv663・スマホv291へ適用しました。公開リリースは別です。
当初はグラスを外したまま実装・検証を進め、その後いただいた接続の連絡を受けて両端末へ適用しました。

## 操作・安定性

- 使えない理由と接続・権限設定を、スマホ／PCの「使える機能・復旧・続きを開く」に集約。グラスのSETにも状態・復旧・続きを追加。
- BT30は選択画面を挟まず30秒送り。直近の操作端末とアプリを表示。
- メディア・ナビ・転送の通信失敗を別々に扱い、3連続失敗後は15秒待機。通知の取得・確認応答は止めない。自動再送で二重操作しない。
- 短時間に続いた完了通知を保留通知の一覧に集約。確認質問は承認扱いにしない。
- 直前の対応設定を競合確認付きで取り消す。目的地入力の取り消しは入力欄だけが対象で、案内中の経路やAPI検索を開始しない。
- 同期済み回答・写真の参照内容と縮小画像・保存済み経路情報を開き、同じ内容の続きの位置を暗号化して保存。新しい内容に変わった場合は古い位置を上書きしない。
- APKを版番号とSHA256で固定。既存の検証結果は、APK・全対象ソース・検証範囲と証跡ファイルのハッシュが合う場合だけ再利用。写真関連の変更がなければメタデータ確認、変更時は内容ハッシュ確認を計画する。インストール自体は既存の署名・バックアップ必須のツールを使う。

## キャラクター

顔の16コマと、立ち姿4／座り姿4の手帳動作を追加。従来の表情・仕草も残しています。

- 聞く→視線を向ける→うなずく→正面に戻る。
- 手を差し出す→指を曲げて受け止める→手を緩める→余韻。
- 手帳・ペンを持つ→開く→書く→閉じる。
- 呼吸、本文の句読点を目安にした口の休止、発話後の納得・同意・問い返しのうなずき。
- 押したボタンの上下左右に目線を向け、目→顔→肩の順に反応。
- 手足の比率を伸ばさない接近と、足元を基準にした表示。
- 新しい会話で前の余韻を中断。拒否・終了時に親密な仕草を継続しない。
- 目・顔・体・接近の強さを個別に設定。振動は初期オフで選択可能。
- PC画面で従来画像と新画像を比較し、小表示の各コマを確認可能。

## 使う場所

スマホ：設定 → 更新・バックアップ・動作確認 →「使える機能・復旧・続きを開く」。
PC／タブレット：接続済みWeb画面の「使える機能・復旧・続きを開く」。開いた時と手動更新時だけ取得し、追加の定期ポーリングはしません。
グラス：SET →「顔の表情・仕草を確認」「全身の仕草を確認」「動きの豊かさ」「回答・写真・経路の続きを開く」。

## 検証と適用

最終結果は同じフォルダのJSON一覧と検証レポートを参照。自動テストは合成データ・隔離アプリを使用し、普段のロキを上書きしません。外部APIへの送信、撮影・録音、実際の案内開始は行いません。
実機では消灯→通知だけで点灯・表示→会話状態の終了→自動消灯の2サイクルに成功しました。試験中の手動点灯・アプリ再起動は0回です。USB接続・充電中の結果で、未接続時や実移動中を含む全条件の保証ではありません。全表情の装着確認と実移動は未実施です。

新しい画像は組み込みimagegenで生成。仕様はリポジトリ docs/character-v663/image-prompts.md に保存。
