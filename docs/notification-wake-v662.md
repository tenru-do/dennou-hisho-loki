# Codex通知でグラスを自動点灯 v662

## 要件の訂正

通知時にグラスが消灯していても、通知をきっかけに点灯して知らせることが必要です。点灯中にだけ届くこと、休止中は保留されることをもって完了とは扱いません。v661での点灯中の連続2件の表示・終了・受領確認は成功しましたが、自動点灯の確認ではありませんでした。

## 実装

- バックグラウンドであるという理由だけではCodex通知を保留しない。
- 認証済みの新しい通知を受けたら、既存の短時間の点灯処理とロキの画面復帰処理を使う。画面が点灯し、ロキが前面に戻るまで待ってから表示・受領確認する。
- 会話・録音・読み上げ・ナビ等の実作業への割り込み抑制は維持する。
- 通知のために起こした画面は、通知終了後に保持を解除して元のバックグラウンド／消灯へ戻す。途中で実際にキー・タッチ操作をした場合や別の作業を始めた場合には勝手に戻さない。
- 点灯を待つ時間は最大2.5秒。復帰できない場合は表示済みIDを保存せず、スマホ側の再試行に残す。
- 通知待ちのための点灯維持や追加の定期ポーリングは作らない。既存の通知受信経路を使用し、古い通知は期限に従って扱う。

## 検証

- 自動点灯・復帰の条件256項目、通知終了条件19,332項目成功。
- 本物のMainActivity終了処理、バックグラウンドでの通知受付、録音中の保護を含む隔離Android890項目成功。
- 消灯からの実機テストは、Sleepキーで消灯した後、手動のWakeキーやアプリ起動を一切送らず、合成通知だけで点灯することを2回確認する。通知終了後の会話中フラグ解除、再消灯、元の質問・操作の保持も確認する。
