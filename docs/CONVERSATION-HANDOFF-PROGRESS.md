# 会話の引き継ぎと進捗表示（グラス564／スマホ207）

## 引き継ぎカード
回答生成の前に、既に選択された会話参照を、現在の発言・直近6往復の引用・訂正時の元依頼候補に整理します。現在の発言320文字、過去ユーザー発言320文字、過去回答抜粋220文字を上限とします。元依頼候補も原文引用で、モデルの要約による新しい事実は作りません。話題変更の境界を越えて元依頼を持ち込みません。

カードは一時的な回答用参照です。未完了案件や操作許可として保存しません。日常の状態報告を保留案件へ変換せず、カレンダーや記憶の既存確認手順を省略しません。永続的な保留案件は既存の暗号化受信箱が管理します。新しい意図判定API呼び出しは増えません。

## 段階表示とエラー
通常会話で「会話の引き継ぎを整理中」「Geminiの回答待ち」「回答の文脈を確認中」「回答を調整中」を状態欄へ表示します。失敗した段階と、タイムアウト／接続不可の区別を示します。回答欄を進捗表示で繰り返し上書きせず、VOICE中の前回答維持を守ります。

要求世代番号と処理中フラグで古い進捗を排除し、スマホへの状態通知は非同期通信を開始した時刻で順序を照合します。この表示追加による自動再送はありません。元からあるモデル切り替え・HTTP再試行は別の既存処理です。画像生成・動画生成・全音声認識経路の段階表示を統一する変更ではありません。

## 受信箱の表示
スマホは受信箱ボタンを会話入力欄の近くへ移動し、保留と結果要確認の件数を分けて表示します。Webは会話のそばに件数と保留題名を最大2件表示します。ログイン済みの共有端末だけが既存APIを使用して閲覧します。Webは接続解除で表示を消し、題名はHTMLとして解釈しません。案件の再開はIDを入力欄へ入れる段階で止まり、勝手に送信・登録しません。
