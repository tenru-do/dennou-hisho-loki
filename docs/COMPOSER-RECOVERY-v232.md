# 添付準備の画面終了対策（スマホv232／グラスv585）

添付追加の非同期処理が、画面終了時に解放する画像リストを参照していたため、処理開始時に元画像・種別・件数・選択URIをUIスレッド上で固定するよう修正しました。終了時の解放で準備対象が変わらないようにします。

すでに画像が添付されている画面では、保存状態の復元を再実行しません。遅れて届いた古い状態で新しい添付を置き換えることを防ぎます。

## 検証

スマホ実機25項目を通過。合成JPEGで、既存の添付復元・暗号化保存検証に加え、新しい添付への古い復元要求の拒否と、準備開始直後のclose後にも画像データ・種類が保存されることを検証しました。closeはオフスクリーンのテスト用composerに対して行い、利用者の添付や履歴には触れていません。

ビルド成功。機種・署名確認、更新前バックアップとハッシュ検証後にv232を反映し、インストール後APKハッシュも一致。通常起動PIDを確認。検証用APKは削除し、通信とUSB接続時の画面休止設定を復元しました。グラスv585は変更していません。

外部API呼び出し・音声再生なし。実プロセス終了や実APIへの送信完了までの試験は含みません。
