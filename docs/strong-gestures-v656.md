# 顔・全身の強め動作 v656

ディープ・突然・めろめろに「動き強め」を追加。通常4種類も残しています。

- ディープ強め：接近量と往復する揺れを増加。
- 突然強め：接近を速め、短い揺れを追加。
- めろめろ強め：ゆっくり大きく揺れる動作。

顔は傾きと接近、全身は上半身の揺れを変更します。全身の足元・座り姿勢は保持。既存画像を使い、画像資産の追加はありません。全身22クリップ、顔は通常4＋強め3の演出です。

SETの「顔の表情・仕草を確認」「全身の仕草を確認」から選択できます。会話では種類を添えた「強め」、同じ話題で「もっと激しく」に対応。「控えめにして」で通常版へ戻り、中止や無関係な話題で解除します。

顔の強め動作中だけ40ms間隔で更新し、最長4.1秒で通常の描画間隔へ戻します。非表示・ナビ・録音中の抑制を維持しています。実際のバッテリー消費量は今回測定していません。
