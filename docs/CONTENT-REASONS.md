# 対応できない理由の通知（グラス583／スマホ227）

通常会話の内容制限・AIによる拒否と、通信障害・認証・利用上限等を区別して通知する。画像・動画の生成結果にも、APIの制限コードだけを表示する代わりに固定の日本語説明を使用する。

## 通知

- 性的な表現の制限と分かる場合：AI側が性的な表現に関する制限に該当すると判定したと説明。
- 個人の機微情報、著作権、暴力や危険な行為、差別や嫌がらせも、根拠が確認できる場合は対応する区分を表示。
- PROHIBITED_CONTENTなどで詳細区分を確認できない場合：AI側の内容制限で停止したことと、具体的な判定項目は確認できないことを明示。依頼文だけから性的制限と推定しない。
- AIが文章で拒否し理由を示さない場合：具体的な理由が示されていないと明示。
- 通信や権限の問題を内容制限へ置き換えない。拒否文の引用・説明を拒否そのものと誤認しにくくする。

通常会話では理由の固定文を表示・読み上げし、スマホ／認証済みWebのログへ「システム通知」として共有する。通知に元の依頼やAPI応答全文を含めず、会話記憶の対象から外す。拒否されたやり取りを成功したAI会話として保存しない。既存の送信控え・生成ジョブ等の独立した保存は変更しない。

これはAPIから提供された区分、または明確な拒否文を元にした表示処理であり、すべての自由文の拒否・理由を理解できる保証はない。特に通常会話の終了理由に詳細区分が残らない場合、説明は汎用の内容制限になる。安全基準を回避したり、同じ依頼を自動再送・再生成する処理は追加していない。
