# 会話履歴の自然な参照と仕草 v657

## 既存実装と原因
スマホには既に90日を基準とした会話ログ保存と、それ以前の質問・回答を短くして残す圧縮アーカイブがあります。800件の上限で、90日未満でも古い記録が先に圧縮される場合があります。今回この保存機構・保存データは変更しません。

一方、グラスは約8〜9往復の時間制限付き参照であり、質問の判定次第で履歴を添付せず、スマホの過去ログ検索も明示的な過去会話質問が中心でした。空回答で文脈を削除する再試行もありました。保存ログと実際にAIへ渡す情報は別になっていました。

## 修正
通常会話でも最近の文脈を引き継ぎ、関連語が最近の文脈になければスマホに保存した90日間のログと古い圧縮記録を検索します。取得結果は上限付きで引用し、同じ検索の短時間キャッシュを使います。グラスのローカル参照キャッシュは48往復・7日で、スマホ側の90日保存や長期アーカイブを置き換えません。各回答へ渡す最近の引用は最大12往復・10000文字です。空回答の再試行では直前の引用を残し、保存済み文脈を消しません。

『覚えておいて』という指示は通常のログ参照には不要です。明示的な記憶メモとは区別し、過去のユーザー発言・訂正を参照します。過去のAI回答を検証済み事実や現在の操作命令に変えません。明示的な新しい話題では過去ログを自動参照しません。

これは保存記録を回答時に選んで参照する機能で、モデルの重みを再学習するものではありません。全会話の完全な記憶や任意の表現での検索成功は保証しません。現在の関連語検索は日本語の表記ゆれ・言い換えに限界があります。長期圧縮は既存の抜粋・重複削除方式で、AIによる意味要約ではありません。スマホ未接続時は取得できたローカル文脈だけを使います。

## 仕草6項目
予備動作・待機・応答・余韻の段階、明示的に甘える／誘う会話で操作への反応待ち、目・眉・口・肩の同じ位相での連動、左右や間の変化・耳たぶの癖の時刻変化、褒め言葉や確認への小反応、SETの『控えめ・自然・豊か』を追加しました。通常のボタンの意味は変えません。顔の動きが必要な短い間だけ更新を細かくし、読上げ中は小さく、ナビ・録音・強い否定表情を優先します。新しい画像データの追加はありません。
