# 送った写真への追加質問

スマホ v259 に更新済み。メガネは v610 を継続使用します。

## 使い方

### スマホ

1. 「添付・その他」を開き、「送った写真に追加質問」を押す。
2. 日時・元の質問を確認して写真の控えを選ぶ。
3. 添付プレビューを確認し、「右上は？」「この文字を訳して」などを入力して送信する。

### PC・タブレット

会話ログにある送信済み写真の「この写真に追加質問」を押し、質問を入力して送信します。

選択時は現在の質問文を残します。元の質問へ置き換えたり、自動送信したりしません。別の添付があれば置き換える前に確認します。

## 対象と保存期間

- 既存の暗号化された送信控えを使い、新しい写真保存領域は増やしません。
- 控えは送信全体の直近10件・24時間以内です。写真10件専用の枠ではありません。
- 写真を添付して送った質問が対象です。動画や生成画像の編集依頼は対象外です。複数写真をまとめた添付は、その一覧画像を使います。
- 写真の撮り直し・選び直しは不要ですが、追加質問の送信ごとに写真もAIへ再送します。通信量・AIの利用量は発生します。
- 写真の選択だけでは問い合わせません。次の無関係な質問へ写真を自動で付け続ける動作もありません。
- 選択中に本文・添付・接続が変わった場合は準備を止め、現在の入力を保持します。
