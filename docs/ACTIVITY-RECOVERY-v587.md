# 状態表示・復旧・残件再開（グラスv587／スマホv234）

## 実装

- グラスの「依頼・転送・動作チェック」、スマホの同名画面、Web会話の状態確認へVOICE/TOPICの段階を追加。停止、聞き取り、音声認識、解析・回答待ち、読み上げ、次の入力・話題待ち、一時待機を区別します。
- 待機理由はナビ優先、画面非表示、利用者の入力・会話優先、メニュー操作、停止処理の固定語彙です。音声内容・画像・位置・自由記述は追加しません。古い受信状態を現在の成功として表示しません。
- 写真・録音の転送表示に「保存未確認」の残件を追加。失敗と別処理待ちはこの残件に含み、二重計上しません。過去削除によるグラス保持分を残件から除きます。
- グラスの同画面に「未転送写真の取り込みを再開」を追加。確認後に既存の照合付き転送へ進みます。写真を撮影中は既存の制限により拒否し、過去にスマホで削除した写真は一覧へ戻しません。

## 5項目の検証結果と範囲

1. **会話訂正**：実機で完全な送信文の組み立てを7項目確認。合成の直前会話、明示的訂正、現在の質問が含まれ、話題変更で訂正が外れます。試験後は元の履歴・訂正を復元。モデルへは送っていないため、自然な実回答や謝罪で止まらないことまでは確認していません。保護対象の会話プロンプトは変更なしです。
2. **復旧**：実際のMainActivity.onSaveInstanceStateで、オフスクリーンの合成入力・添付を保存（利用者のUIフィールドは同一UI処理内で元に戻す）。暗号化した試験用保存状態を残し、アプリをforce-stopした後、新プロセスで復元して9項目成功。本文、画像・動画の件数・種別、プレビューを確認。結果不明の合成送信記録から再実行権限が出ないことも確認。これは保存処理と復元処理のプロセス越しの検証であり、Androidが実タスク全体を自動再生成する検証とは区別します。試験ファイルは削除済み。
3. **状態表示**：スマホ実機で暗号化した隔離workspaceと表示9項目、実際のネイティブダイアログ4項目、Edgeで実際のWeb描画9項目。未許可の語・自由記述を状態へ保存せず、状態の鮮度を区別します。
4. **Bluetooth併用**：グラスで待機時のTTS停止処理60回と約4秒のローカルマイク取得（約17秒の試験）。音声はメモリ内のみ、保存・外部送信・ロキの音声出力・タブレットの再生操作なし。タブレットの聞こえ方は利用者確認待ち。実際のベンダーTTS発話・クラウド音声認識・外部APIを含むTOPIC/VOICEの全経路は未検証です。
5. **写真再開**：グラス上の隔離した合成写真で9項目。不完全・不一致の保存応答では元写真を保持し、一致した保存応答で対象写真だけを外し、新しいアーカイブインスタンスには残件だけが現れることを確認。利用者の全写真を再転送する試験はしていません。

ローカル108項目＋18,120回のメディア状態遷移シミュレーションを通過。追加の状態・残件・訂正文脈21項目を通常のTest-LocalConversation.ps1へ組み込みました。グラス20・スマホ2の保護対象プロンプト区間はベースライン一致。

## 更新

両端末の機種・パッケージ・署名を照合。更新前のPCバックアップをハッシュ検証した上でインストールし、端末のAPKハッシュがビルド成果物と一致することを確認しました。通常起動PIDを確認し、試験用APK6個を削除、Wi-Fi・モバイル通信・USB画面休止設定を元に戻しています。利用者の写真・録音・設定と既存の未コミット変更は保持しています。GitHubへは今回公開していません。

外部APIへの検証送信、検索、予定登録、画像・動画生成、ロキからの音声再生は行っていません。
