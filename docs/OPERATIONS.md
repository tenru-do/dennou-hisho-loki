# 運用・更新手順（グラスv456／スマホv162）

v447以降はTLSへの移行、双方の同時更新、暗号化写真の書き出しが必要です。[セキュリティ対策と移行手順](SECURITY-v447.md) を先に確認してください。

最新のAMB変更と実入力検証は [v450](releases/v450.md)、コメント・画像連動の基礎変更は [v448](releases/v448.md) を参照してください。

## ビルド

リポジトリのルートで実行します。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File tools/build-integration.ps1 -App glass
# v447への通信移行ではスマホも必ず同時に更新
powershell -NoProfile -ExecutionPolicy Bypass -File tools/build-integration.ps1 -App phone
```

生成APKは `.build-integration` 以下です。署名鍵・APIキーをGitへ登録しないでください。ビルド環境と既存署名を確認してから配布します。

## 実機更新

1. `adb devices -l` で対象を確認し、以降は `adb -s <serial>` で固定する。
2. アプリの表示名、パッケージ、搭載版、署名を確認する。グラスは `com.example.rokidkeyboardbridge`。
3. 更新前APK、アプリデータ、保存写真をバックアップし、コピーのハッシュを検証する。データ取得には端末・アプリの権限が必要。
4. 新APKのパッケージ・版・署名を確認し、既存と互換であることを確認する。
5. `adb -s <serial> install -r <apk>` でデータを保持して更新する。署名不一致をアンインストールで回避しない。
6. 起動、設定保持、搭載版、インストールAPKのハッシュを確認する。検証用アプリは終了・削除する。
7. 実装テストと、装着した視覚・音声・動作の評価を別々に記録する。

## 画面と撮影

SETで顔／全身を選択。PLAYは音楽制御、SET内CTRLは本体設定と連携する明るさ調整。TOPIC内AMBは音声・カメラ・両方を選択する。

SET→RECから連続撮影を開始（5秒／10秒）・停止する。KEEPは過去2分・未来1分を保護する。CAM長押しは使わない。保存上限は実JPEG合計5GB、未保護の古い記録から削除する。保護済みで容量を使い切る場合は撮影を停止する。撮影間隔はカメラの処理状況によって変動する。

## 反応・画像の強化

`tools/FULLBODY_SCENES.md` と履歴資料 `fullbody-rules-v433.md` を参照。規則は `tools/fullbody-scene-rules.json`、生成・検証スクリプトは `tools/generate-fullbody-scenes.ps1` と `tools/test-fullbody-scenes.ps1`。通常ビルドでも規則を検証する。

全身・顔の監査JSONLは本文ではなくハッシュと反応情報を記録する。未知の反応を確認し、匿名化した回帰例を追加する。画像と感情、立位／座位、縮尺を照合し、ラベルの変更だけで不一致を隠さない。瞬き・口・移行フレームは装着評価も行う。


## 記録写真の取り込み・整理（グラスv456／スマホv162）

スマホの「記録写真（KEEP・連続撮影）」→「グラスから一括取り込み」→「撮影を停止して取り込む」で、KEEP保護の有無にかかわらずグラス内の全記録写真を移動する。両端末のロキを起動し、同じネットワークで連携する。グラスのSET→REC→「記録写真をすべてスマホへ移動」からも開始できる。HiRokidの画像読み込みとは独立した機能。

スマホで暗号化保存し、再読込とSHA256一致を確認できた写真だけ、グラスの元写真・撮影情報・KEEP保護印を削除する。未転送、保存失敗、曖昧な受信応答では元写真を残す。中断後は再実行できる。スマホ内取り込み容量は500MBで、空き容量不足では移動できない写真をグラスに残す。

一覧は大きな2列の写真、1ページ60枚。転送中は5秒ごとに枚数の変化を確認して自動更新する。「表示中を選択」は現在のページだけが対象。ページ移動・手動更新では選択を解除する。「選択して保存」「選択して削除」はチェックした写真だけを処理する。「全写真を削除（全ページ）」は独立したボタンで、確認画面に全件数と対象範囲を表示する。

写真をタップして1枚表示し、ピンチ拡大、ドラッグ移動、ダブルタップで拡大・全体表示する。削除後も同じ1枚表示で次の写真へ進む。最後の1枚を削除した場合は一覧へ戻る。

「ギャラリーに保存」は通常JPEGをMediaStoreのPictures/Lokiへ保存する。撮影日時と取得済みGPSを保持し、同じ書き出し先が残っていれば重複保存しない。ロキ内の写真を削除してもギャラリー保存済みのJPEGは残る。Android 9以前の保存権限経路は実機未検証。

スマホで削除した写真は削除記録を残し、再取り込みを拒否する。グラスにその元写真が残る場合は、認証済みの削除済み応答と元データのハッシュを照合して整理する。削除後の復元を前提にせず、残したい写真は先にギャラリーへ保存する。

撮影時刻を表示し、取得できた新しいスマホ位置だけを撮影情報に記録する。過去の写真の場所は推定せず「位置情報なし」とする。実際の外出時GPS記録の品質は未検証。

検証記録：[全写真移動](releases/v456.md)、[60枚表示とページ内選択](releases/phone-v162.md)、[撮影露出の調査と制約](releases/v454.md)。撮影の暗さと体感停止は解消したと主張しない。
