# 座って手を差し出す全身画像の補正 v658

ユーザーの指摘対象は座ってこちらへ手を差し出す仕草。従来の標準ロキを基準として、頭・胴・肩幅・腰まわり・脚の比率と輪郭を揃えた座り画像へ差し替えます。比率指定は生成時の目標で、身体寸法の測定値ではありません。

内蔵 image_gen ツールで2案を生成し、2案目を選択。編集基準は loki_fullbody_000_005.png、対象は最初の補正案。最終プロンプトは prompt.txt／artwork/seated-proportions-v658-prompt.txt に保存しています。採用画像は glass-app/assets/loki_body_affection_seated_v658.png。元の立ち画像・座り画像を上書きせず残します。

生成画像の下段は座り4コマ、上段は立ち3コマです。上段は縮尺参照だけとして3列で読み、下段4列を切り出します。通常の立ち姿は元画像を使うため、この新しい上段は表示しません。座って手を差し出すキャッシュと、それを使う通常／強めの接近動作だけが新画像へ切り替わります。既存のループは最初の3コマを往復しており、同じ方法を維持します。

v657の仕草6案・動き設定・90日ログ／圧縮記録の自然な参照は維持。会話入力はv657から変更しておらず、Geminiの追加テスト送信は行いません。GitHubと公開APKは今回更新しません。
