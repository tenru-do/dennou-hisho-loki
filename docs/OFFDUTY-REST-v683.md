# 縦長の寝姿・身じろぎ・予定登録の導線 v683

## 最終の寝姿

ユーザー指定に従い、縦長で頭が上・足が下、真上から見る構図に統一。靴を脱ぎ、短い髪と服に自然なくつろぎ感を加えた。元の成熟した顔・細身で脚の長い体格を参照し、表情変更では同じ中立の体を保持する。

1. 抱き枕を体に載せる仰向け。
2. 両手を頭の後ろに置く仰向け。
3. 仰向けで頬に手を添える姿。
4. 眉を寄せて目を閉じる悪夢の寝顔。

各姿勢に4表情。穏やか・微笑み・考え顔（悪夢の姿は心配顔）・眠そうな顔を用意。顔パッチのアルファ属性が失われて黒い境界となる問題も修正した。

身じろぎは肩・手・上体の小さな非性的な動きに限定し、体格・服・下半身の形を変えない。通常は約2.8秒、悪夢の反応は約5.2秒で収まり、「身じろぎを止めて」で姿勢を保持して停止する。悪夢は自動のくつろぎ姿勢ローテーションには含めない。

新しい寝姿は全身の仕草→寝姿の表情・動作メニューから選べる。会話では「枕を抱えて横になって」「両手を頭の後ろに置いて休んで」「寝たまま頬に手を添えて」「悪夢でうなされている感じにして」。選択後に「寝たまま身じろぎして」「眠そうな顔にして」を使える。

横長・斜めの試作は不採用。脚の間の抱き枕と横向き追加分は画像生成ツールの出力安全判定で止まったため、今回のアプリには含めていない。画像がない動作を実行したと返答しないようにし、対象の操作には未追加であることを表示する。

## カレンダーの誤判定修正

新しい「添付の予定表をカレンダーに登録して」が受信箱分類器でFOLLOWUPに誤分類され、対象案件がないという直接回答で止まっていた。

明確な即時カレンダー登録を受信箱分類より先に通常の予定登録処理へ渡す。添付を指定した新規依頼では古い受信箱カード／提案を解除。単なる報告・否定・後回し・保留案件の再開・提案の補足は従来の確認経路を維持する。画像参照と登録前確認、確認後の登録処理は従来通り。

ローカルの姿勢変更も受信箱分類より前に判定し、表示だけの指示に不要な分類APIを挟まない。

ユーザーの実際の通院票をAPIへ送信しておらず、予定の登録は実行していない。氏名・患者番号・通院先・予定をソースや公開素材には保存していない。検証は架空の予定文と隔離Activityによる導線テスト。実サービスでのOCR読み取り・実カレンダーへの登録まで成功したという検証ではない。
