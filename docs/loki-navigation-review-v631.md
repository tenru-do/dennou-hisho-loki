# メガネからの公共交通経路選択の修正（v631）

## 原因

通常の案内更新が行う表示リセットが、取得中・選択中の経路候補まで取り消していました。通信の一時的な失敗や復帰でも同様に候補を閉じていました。また、登録地点からの公共交通検索は独立したスレッドで実装され、共通の取り消し・世代管理・読み込み画面から外れていました。候補画面が閉じた後も「スマホと共通の経路候補を取得中」の状態表示が残る経路がありました。

## 変更

- 表示のリセットは案内表示だけを対象にし、候補取得・選択・開始確認を取り消しません。表示のリセットで開始中フラグを解除しないようにしました。
- 通信の一時失敗・復帰で選択画面を閉じません。候補取得自身の結果・失敗・明示キャンセルで状態を管理します。
- 登録地点からの公共交通候補を共通のジョブ・世代・キャンセル管理へ移しました。取り消し済みの結果は表示しません。
- 取得中はキャンセル可能な待機画面を表示。取得後は「経路を選んでください」へ変更し、候補を閉じた場合は未開始であることを表示します。
- 候補取得に75秒の上限を設け、遅れて届く結果を無視します。タイムアウトで選び直しを案内します。
- 開始確認画面を管理対象にし、開始要求を1回だけ送ります。開始結果が不明な場合は自動再送せず、現在の案内の確認を促します。

## 検証方針

実APKのメガネActivityで表示リセットを100回呼び、候補の世代・選択中・取得中・開始中・実行ジョブを保持することを検証します。明示キャンセルでは世代と実行ジョブが無効になり、選択中・取得中が解除されることを確認します。別UIDの隔離環境を使用し、勤務先や現在地を送らず、実案内を開始しません。

今回、登録済みの勤務先への実検索は実行していません。個人地点をソース・APK・この報告へ記載していません。

最終APKの検証は合計4,018項目成功。うち今回の候補維持・明示キャンセル・開始処理中の保護は507項目成功しました。メガネv631へ適用済み。署名・バックアップ・適用済みAPKのハッシュを照合し、既存411ファイルの内容を起動前に保持確認しています。スマホはv276のままです。

勤務先への実検索・実際の候補表示から開始までの最終確認は未実施です。利用者が同じ操作を再度行った際に確認します。
