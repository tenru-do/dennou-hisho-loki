# 添付復元の連続性（スマホv231／グラスv585）

添付復元の読み込みが終わる前に画面が再生成されると、画像がまだメモリにないため保存状態が「添付なし」になる問題を修正しました。復元中も添付ありとして保存します。

復元の重複要求と終了済み画面からの開始を拒否し、読み込み対象ファイルを開始時に固定しました。画像デコードと元画像数の整合を確認してからUIを更新します。非表示になった画面用のプレビューは解放します。

## 確認

- 開発ビルド成功。保護対象の会話プロンプト2区間は不変。
- 合成画像による実機19項目を通過。復元中の保存状態、別IDの復元要求拒否、Parcelでの状態再構成、画像種別・件数、壊れた画像の保持、暗号化保存と改ざん検出。
- ローカル会話27項目、メモ復元22項目、送信中の編集9項目を通過。
- スマホv231を機種・署名確認、更新前バックアップ・ハッシュ検証後にインストール。反映APKハッシュ一致。通常起動PID確認。
- テストアプリを削除し、通信・USB画面休止設定を元に戻しました。グラスv585は変更なし。

外部API送信・音声再生なし。実際のプロセス終了からの復旧は今回の検証範囲に含みません。
