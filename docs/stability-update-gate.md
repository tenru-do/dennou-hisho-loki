# 安定稼働の更新前ゲート

候補APKのビルド後、tools/Verify-LokiStability.py --output <新しいフォルダ> を実行します。処理の順序は、実ダイアログ操作→Android実クラスの回帰と安定性→観測ツールの欠測判定→ブラウザ24スイートです。すべて同じAPKハッシュであることを確認します。外部AI・経路API・カメラ・録音は使用しません。

実会話、VOICEのマイクと音、撮影と回答、保存済み記録、実端末同期、ナビの開始/取消/復帰は、別のmanualChecksに記録します。自動テスト成功だけではallChecksPassedはtrueになりません。結果はautomatic_pass_manual_pendingです。公開前には --require-manual を付け、手動証跡が足りなければ終了コード2で止めます。

--manual-evidence は同じapkSha256と、各checksのstate=passed/evidence=実在する証跡ファイルへのパスを持つJSONです。撮影・音声・課金を伴う実送信はユーザーの許可範囲内で実施します。全条件の正常を保証するものではありません。

長時間の観測には tools/Run-StabilitySoak.py を使用します。通常利用のプロセス・メモリ・CPU観測窓・温度・充電状態・実装済み通信カウンターを記録します。独自負荷や経路開始は行いません。USB切断・ホスト休止・アプリ停止・カウンター未取得を成功扱いにしません。12時間経過と、12時間連続して観測できたことは区別します。
