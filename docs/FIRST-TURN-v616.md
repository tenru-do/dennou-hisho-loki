# メガネv616：第一声の停止経路と古い失敗表示

2026年10月22日、メガネv616へ更新済み。スマホ版はv264のまま。署名・バックアップ・インストール済みAPKを照合し、更新前410ファイルの一致を確認。

## 確認できたこと

直近の実機ログには、回答後の修正段階で `phase=REPAIR reason=PROCESSING` により停止した記録がある。今回の記録は音声認識エラーでも、前回修正した口調判定エラーでもない。「毎回の第一声で必ず同じ原因が発生する」とまではログから確認できていない。

旧実装では、過去の参照情報があれば挨拶の一部を除くほぼすべての短い発言を追加の文脈確認に掛けていた。独立した質問も古い対象と照合され、再修正後にも不一致判定になると、一般的な「回答を完了できませんでした」に落ちる経路があった。失敗表示を新しいVOICE開始時に消す処理もなかった。

## 修正

- 「ピュアブレッドはどこにある？」「今日の天気を教えて」など独立した質問や「ロキ、こんにちは」などの挨拶を、追加の文脈確認から外す。
- 「それは？」「年間では？」「元の話を引き継いで」などの続きは文脈確認を維持する。会話履歴を一括削除する変更ではない。
- 新しいVOICE開始時、画面が前回の失敗文と一致し、回答処理が走っていない場合だけその古い表示を消す。新しい回答や処理中の表示は消さない。失敗の診断記録は保持する。
- 本当に文脈不一致で停止した場合には専用の停止理由と対処を表示し、汎用エラーだけにならないようにする。ログに例外の種類を残し、本文・URL・認証情報は追加しない。

## 検証と限界

- 最終候補APKの隔離テスト1,090件成功。会話の保護対象20区間は変更なし。
- 第一声・独立質問・挨拶・会話の続き・失敗表示の保持条件・専用エラー分類を18件追加。
- 外部APIへの追加送信は行っていない。前回許可された合成2件は消費済みであり、再使用していない。
- 実際のVOICEの第一声で正しく返答するかの確認は更新後に必要。今回の修正だけで全種類の回答失敗が解消したとはしていない。
- v615の口調判定・認識準備・コメント消去は維持する。
