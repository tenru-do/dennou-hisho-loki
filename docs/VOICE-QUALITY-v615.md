# メガネv615・スマホv264：VOICEと回答表示

2026年10月22日、メガネv615・スマホv264へ更新済み。更新前データはスマホ159ファイル・メガネ410ファイルが一致し、バックアップ・署名・インストール済みAPKを照合済み。

## 修正内容

1. **「回答の口調を整える必要がございます」の頻発**
   アプリ側の口調判定が、出典URL・住所・箇条書き・丁寧な挨拶を文末の不備として扱っていた。固定の人格・安全性・生成指示は変えず、構造化された情報と通常の丁寧な挨拶を区別する。口調不備時の定型文から内部処理の説明を除く。回答の検索出典チェックや安全停止は維持する。
2. **固有名詞の場所検索**
   「ピュアブレッドはどこにある？」「施設名の所在地」「施設名へのアクセス」も検索が必要な質問として判定する。問題の原因やアプリの入力欄の場所など、施設検索とは異なる質問は除外する。特定の住所をアプリに固定する変更ではない。
3. **最初の発話の文字化待ち**
   VOICE開始時にスマホの音声認識サービスへの接続・日本語対応確認を並行して準備し、最初の認識で再利用する。準備自体では録音や音声の送信を開始しない。30秒で破棄し、利用できない場合は従来の認識方法へ戻る。認識開始から準備完了・全文確定までの時間を、本文を含めずログに残す。実際に何秒短くなったかは未実測。
4. **読み上げ後のコメント消去**
   読み上げ終了判定から約3秒で、同じ回答のコメントとキャラクターの発話文字を消す。認識中の入力欄・回答履歴は消さない。質問や読み上げの世代が変わったとき、新しい回答に差し替わったとき、一時停止中などには古いタイマーで消さない。連続VOICEで待ち受けているだけなら古いコメントは消す。

Rokid音声サービスには発話完了コールバックがないため、終了時点は既存の発話時間見積もりに基づく。実際の読み上げ終了から厳密に3秒になる保証はない。

## 検証

- 最終候補APKの隔離テスト1,072件成功（新規32件）。実会話・音声・写真を使わず、外部リクエストなし。
- 出典付き回答、箇条書き、住所、挨拶、くだけた口調の拒否、施設の場所検索、アプリ内位置質問の除外、表示消去の世代・本文・一時停止条件、準備の有効期限を確認。
- 明示許可を得たGoogle Geminiへの合成リクエストは合計2件。1件はHTTP200・STOPで完了し、最終口調判定でも受理を確認。もう1件はHTTP200だったが、完了した非空回答を取得できなかった。追加送信・自動再試行はしていない。実会話・写真は送信していない。APIキーを保存・表示していない。
- 実応答と候補クラスの検証後、口調の出力判定に限って変更保護基準を更新。固定の人格・生成指示は変更前と一致。残りのメガネ19保護区間、スマホ2保護区間は一致。
- 追加の別UID検証で、実際のAndroidハンドラーによる約3秒の合成コメント消去、新しい本文の保持、新しい質問世代の保持の3件が成功。音声・実会話は使っていない。
- 実際のVOICEによる初回遅延の短縮量、Geminiでの施設検索成功、耳で聞いた発話終了からコメント消去までの時間は未確認。
