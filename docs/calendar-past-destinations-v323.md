# 予定の時刻を過ぎた場所も目的地候補に含める

2026-11-21、スマホv323へ反映。グラス側はv761のまま、スマホの共通候補APIを参照して同じ候補とラベルを表示する。

「予定から目的地」の今日・明日の一覧で、選んだ日に属する予定は開始・終了時刻を過ぎても候補に含める。開始時刻だけを過ぎていれば「開始時刻経過」、終了時刻も過ぎていれば「終了時刻経過」を付ける。予定を実際に済ませたかどうかは判断しない。経路検索は従来どおり、利用者が選択してから今からの出発条件で行う。

日付範囲、終日のUTC日付処理、削除・キャンセル・辞退の除外、オンライン会議や場所未登録の扱い、候補60件の上限、5分の確認期限、選択時の場所・日時再確認は維持する。単に時計が進んで予定の終了時刻を過ぎただけなら、予定内容が同じである限り無効にはしない。

実際のカレンダー権限も通信権限もない隔離UIDで、候補APKの実クラスと合成Cursorによる60項目を検証。終了済み、開始時刻経過、終了時刻ぴったり、日付境界、終日、夏時間、場所なし、変更検出、件数上限、確認期限を含む。実際の予定を作成・変更せず、経路APIも呼んでいない。

検証コマンド: `tools/review-device/run.py --only-calendar --output <新しい記録先>`。更新は `tools/Install-LokiVerified.py` で旧APK・データのPCバックアップ、署名一致、新APKとインストール済みAPKのSHA-256一致を確認した。非公開バックアップは `.build-private-install-calendar-v323/` に保持。実カレンダーを表示する端末内操作と、実際の経路検索は未実施。
