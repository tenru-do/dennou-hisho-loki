# グラスv571・スマホv214：会話参照・確認・録音の改善

## 実装と入口

- 会話の参照先：自動／直近の画像／画像を使わない、を明示選択。画像を使わなくしても元の読み取り情報は保持。保留案件を選んだ会話には画像の文脈を混ぜない。案件の選択は既存の「秘書の受信箱」から行う。
- 画像の予定候補：登録先・予定名・開始・終了・終日・場所を項目別に訂正し、グラスの登録前確認へ戻す。訂正だけでは予定登録しない。候補更新・10分経過・別の保留案件参照中は訂正を止める。保留案件に紐づく候補の訂正は従来の会話欄を使う。
- TOPIC／AMB：取得中・処理中・認識した言葉を別々に保持。認識文を会話欄で直してから送信できる。自動送信しない。実際に聞き取れない場合は認識文なしと表示する。リアクション本文を認識結果に転用しない。
- ナビ：現在地・経路の経過時間、未取得、取得エラー、目的地不一致を表示。利用者が確認した上で目的地を維持して再取得できる。再取得では候補が変わり得る。Googleマップ内部の選択経路との同一性は保証しない。
- 録音：取得／書込／ファイル確定区間を分けて表示。保存記録は区間ごとに復号・ハッシュ・長さ・WAVヘッダーを確認し、欠損と取得量との差を表示する。古い録音で取得量の記録がない場合は、検証結果の比較可否フラグがfalseになる。
- 並行稼働：録音とKEEPの実機15分保存試験、TOPICの実通信3件、経路API1件を実施。

グラスは **TOPIC → 認識した内容を見る・直す／会話の参照先**。スマホは **会話の参照先・予約候補・認識文** と **録音の進捗・保存確認**。PC・タブレットは「ロキと会話」の折りたたみパネル、「会議・録音」の保存区間検証から開く。

## 検証結果

- 正本の回帰試験303項目、実ブラウザ41項目、スマホの隔離データによる実機13項目、グラスの参照分離7項目が成功。
- スマホの確認用ダイアログ2種類を実画面で確認。グラスの実際の状態送信処理からスマホへの保存・新鮮な状態の表示も確認。
- 実録音：計測900.816秒、保存音声899.780秒、90区間、28,792,960 PCMバイト。90区間すべてハッシュ一致。終了操作で停止。開始・終了処理の時間を音声長として水増ししていない。
- 61回の計測で取得量と書込量の差は最大20ミリ秒。KEEPは30枚を保存。会議録音優先の30秒間隔で撮影され、古い画像はTOPICから除外されることも確認。
- TOPICは承認どおり合計3リクエストが成功（うち1件は保存画像＋短い音声）。今回の環境音では認識文は空で、認識語の精度比較は行っていない。
- 経路APIは新しい現在地で1リクエスト成功、1経路を取得。実利用の保存経路は変更していない。
- 15分のハードウェア並行試験は更新前v570の録音・撮影処理で実施し、その後v571へ更新。v571で追加した進捗計算は回帰試験、保存検証はスマホ実機で破損・欠損データも使って確認した。v571で追加の15分録音は行っていない。
- ビルド・インストール・装着中の目視を区別する。両端末の対象、署名一致、更新前バックアップ、バックアップ内容とハッシュ、反映後APKのハッシュを確認。装着時の視覚・聴覚による確認は利用者確認とは別であり、今回の実機確認を装着確認と呼ばない。

## 保持と取扱い

写真と録音は承認どおり保持。一時解析用の観測データと計測用アプリは検証後に削除。更新前バックアップはローカルの検証出力に保持し、公開しない。既存の未コミット変更は保持。今回GitHub公開や追加の画像・動画生成、予定の書き込みは行っていない。

グラス非装着の休止時は共有状態が古くなることがある。確認画面は「古い可能性」を表示し、常時接続中と誤表示しない。新しい同期を受信すると状態を更新する。

最終再起動後、両アプリのプロセス稼働を確認。計測用APKと一時観測データは削除済み。
