# ロキの表情・動作改善 v686

## 採用6案の実装

1. **動作中の体格固定**：立ち動作6系統の頭の中心を明示し、上げた手が頭の検出に混ざって横へずれる処理を補正。頭部を身体の変形メッシュから保護し、首付近で徐々に身体の動きへつなぐ。全身を均等に拡縮し、頭だけを拡大しない。
2. **顔の同一性**：通常顔モードの24表情を、ユーザー指定の成熟した顔の基準から一つの画像集として生成。通常表情・会話表情で画像集を共有し、一度だけデコードする。顔の幅・顎・鼻・髪型を全コマで目視比較した。
3. **姿勢変更**：座位から立位への6コマと逆再生を追加。約1.85秒で終了し、ナビ・録音などの優先表示では停止する。人物の倍率と床の基準をシーケンス内で固定。読み込みはキャッシュし、失敗時の再試行は60秒以上空ける。表示終了・破棄時に解放する。
4. **接触位置**：キャラクター上のタップ・スワイプ位置、または会話の頬・肩・手という語から反応部位を選ぶ。座位では下がった顔・膝付近の手の位置を考慮。視線と反応の回転基準を部位で変え、接触時の全身の縦方向つぶれを除いた。ボタン本来の操作と仮想接触の状態管理は既存の処理を維持する。
5. **繰り返しの軽減**：会話から自動選択する同じ仕草を18秒以内に連続再生しない。許可された同じ種類の動作内で速度に小さな差を付ける。明示的な動作指定・プレビュー・手帳への指示は繰り返せる。従来の自動仕草の履歴管理も維持する。
6. **画像の採用前検査**：v686以降のアトラスは、画像・基準のハッシュ、全コマの確認記録、切り出し矩形、頭の目印、比較画像をビルドで照合。新画像をハッシュ登録するだけでは通さない。不正・欠落した記録5パターンの拒否を検証した。さらにAndroidの実描画で全24表情と姿勢変更の往復を確認する。
