# 座位の右手挨拶・体格と脚の比率補正（グラスv732）

座ってこちらを見ながら右手を上げる動作は、脚組み静止画とは別のclip1だった。旧共有画像先頭行は頭が大きく、胴・脚が短く見えていた。さらに動作時だけ独立した0.76身長の倍率へ切り替わっていた。

指定基準画像を参照し、built-in image_genで成人の成熟した顔、自然な頭と手、細身の長脚体格に合わせた専用4コマを生成。初回候補は脚が短いとのユーザー指摘により不採用にし、太もも・膝下の比率を調整した2回目を採用した。生成された本来の透明alphaを保持し、局所的な引き伸ばしや体形の後加工はしていない。

新素材はglass-app/assets/loki_seated_greeting_v732.png。clip1だけ専用2×2の画像へ切り替え、他の座位5種類の素材と切り出しは維持した。4コマに共通の元画像座標を使い、静止画と同じ眼間距離で倍率を校正。頭頂を残し、足元を収めるために全身を縮めない。

ビルドおよび既存のキャラクター回帰検証、座位の倍率236・画像経路161・挨拶と静止画の倍率132項目が成功。グラスの隔離Android Canvasで10時点・4コマの挨拶動作を描画し119項目成功。各コマの顔・脚・上端を目視比較した。これは装着者による光学的な見え方の確認とは区別する。
