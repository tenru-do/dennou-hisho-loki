# ロキのナビ改善：メガネv611・スマホv260

両端末へ上書き更新済み。既存データをバックアップし、同じ署名で更新しました。初回起動前にスマホ158ファイル・メガネ410ファイルの内容保持を確認しました。

## 追加・改善した内容

| 項目 | 変更 |
| --- | --- |
| 徒歩の曲がり角 | 約120m以内・35m以内・12m以内の段階で通知します。同じ曲がり角の同段階を連呼せず、経路内の曲がり角IDを使って連続する右折も区別します。 |
| 道からの逸脱 | 同じGPS値の繰り返しでは確定しません。異なる位置サンプルが3件以上、8秒以上にわたり基準距離を超えた場合に再探索します。許容距離は位置精度と移動手段に合わせて調整します。 |
| 再探索中の表示 | 更新中・位置のずれの確認中・取得失敗を表示します。旧経路が残る間も、再探索中の曲がる音声案内は保留します。 |
| 駅の出口・施設の入口 | スマホの「添付・その他」→「ナビ」→「駅の出口・施設の入口を選ぶ」を追加しました。名前で検索し、候補の住所・座標を確認して目的地に設定します。設定だけで案内は開始しません。 |
| 降車・乗り換え | 選択経路の降車地点の座標、確認済みの乗車区間、新しい位置サンプルを使い、約800m・250m以内で接近を知らせます。次の乗り換え路線が経路データにあれば併記します。 |
| 音声の優先 | 通常のナビ通知は読み上げの終了見込みを最大6秒待ち、直近の曲がり角は優先します。対応する回答は区切り単位で再開できる状態に残します。ナビ音声終了後に決定タップで再開します。 |
| ナビ音声の切り替え | メガネのナビメニューに「ナビ音声をオフ／オン」を追加しました。表示は継続します。 |

## 位置・データが不足する場合

- 徒歩の曲がり角は30秒以内・精度40m以内の位置を使います。位置が古い、欠落している、再探索中の場合は音声通知しません。
- 降車通知には30秒以内・精度100m以内の位置と、経路内の乗車区間の確認、APIが返した降車地点の座標が必要です。乗車待ちの状態では通知しません。
- 「次はこの駅」とGPSだけで断定したり、位置が取れない地下で時刻だけを使って降車を通知したりしません。
- 入口候補が施設の中心を指す場合もあります。検索結果が入口であることを保証する自動判定ではありません。候補を利用者が確認する方式です。建物内の通路・改札内の誘導は追加していません。
- 新しい段階通知は徒歩が対象です。車の車線案内は既存のSDK機能を継続します。
- メガネを外している間は読み上げません。回答の再開は区切り単位のため、一部を繰り返す場合があります。
- 音声終了は端末側の実完了通知ではなく時間見込みを使うため、屋外での聞こえ方と通知タイミングの確認が必要です。

## 更新後の歩行確認

1. よく知っている道で、右左折が2か所ほどある短い徒歩経路を選びます。
2. スマホとメガネで選択した目的地・経路が一致するか確認します。
3. 曲がり角の手前での表示と音声、同じ通知が続かないかを確認します。
4. 別の道へ進んだ場合に、位置確認中→再探索中→新しい経路へ切り替わるかを確認します。
5. 入口・出口を指定した場合は、実際の入口の位置と候補が合っているかを確認します。
