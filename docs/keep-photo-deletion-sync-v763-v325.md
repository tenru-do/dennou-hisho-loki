# KEEP写真のグラス原本削除：修正・実機確認

2026年11月26日12:40（日本時間）。グラスv763、スマホv325へ既存データと署名を保持して更新。

## 原因

KEEP一覧での削除はスマホ内写真・メタデータと再取り込み防止履歴だけを更新していた。グラス原本を消す処理は再取り込み時の照合に依存し、通常の一覧削除だけでは原本が残った。そのためスマホ一覧0枚とグラス保存写真560枚は両立していた。今回、表示だけの誤差ではなく原本残留の不具合と確認。

## 修正

- Web・スマホ写真一覧の削除で、選んだ写真IDだけを永続的なグラス削除待ちへ登録。
- 認証付き既存TLS経路でグラスへ渡し、原本と関連メタデータの削除が成功したIDだけを確認応答。接続断・アプリ終了・失敗時は未確認のIDを保持して再試行。
- 原本を残す明示的なスマホ側重複整理とは区別。過去の全削除履歴を一律に削除指示として扱わない。
- Web画面にグラス削除反映待ち件数を表示。削除確認文も両端末への反映と未接続時の待機を明示。

## 今回の残留分の処置

グラスの現在の560枚をスマホの既存削除履歴とIDで照合。該当559枚だけを修正版の待ち行列へ登録した。削除履歴にない1枚は保持した。対象はユーザー申告の557枚だけに限らず、以前の削除済み残留分を含む。

原本は暗号化状態のまま非公開.build作業領域に退避し、ファイルハッシュ確認済み。削除待ち登録時にも「スマホ削除履歴あり・スマホ写真本体なし」を再検証。画像の復号・内容閲覧は行っていない。

## 検証

- ローカルTLS・証明書・暗号化保存・ペアリングの既存安全性試験に合格。
- 原本削除試験：対象原本とsidecarのみ削除、未選択写真の保持、不正IDの拒否、失われた応答後の再試行の冪等性に合格。
- 実ブラウザの写真一覧・削除・進捗・削除待ち表示36項目に合格。外部リクエスト0。
- 両APKビルドと既存回帰検査に合格。更新前と署名一致確認、アンインストールなし。
- 実機で559枚を新しい認証付き同期処理に通し、グラスの物理ファイル数1、待ち0、スマホのWeb表示用受信状態も1と一致確認。

この修正で解放した写真領域は約137MiB。初期化後の総減少約2.1GiB全体の説明にはならず、残る未説明領域は引き続き別の問題。Webページを開き直すと新版の削除待ち表示を利用できる。
