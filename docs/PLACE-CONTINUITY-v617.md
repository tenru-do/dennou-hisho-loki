# メガネv617：場所の追加質問と訂正の継続

2026年10月22日。メガネv617の実機適用が完了。スマホはv264。更新前バックアップの読み取り、署名、インストール後APKのハッシュを照合し、起動前に既存410ファイルの内容が変わっていないことを確認した。

## 問題

提示された会話では、茂林寺を話題にしていたのに「近くに沼ある？」を現在地側の地域へ読み替え、その後の「違うよ茂林寺の話」でも未回答の沼の質問へ戻れなかった。

従来は、履歴を添付する処理はあっても、省略された「近く」の対象や訂正後に答えるべき質問を明確に結び直していなかった。文脈確認の対象語にもこれらの発言が含まれていなかった。履歴が存在することだけでは、この誤りを防げていなかった。

## 修正

- 履歴から一意に確認できる直前の場所を使い、「近くに沼ある？」を内部で「茂林寺の近くに沼ある？」という質問へ補う。
- 「違うよ茂林寺の話」は、直前の場所についての情報質問へ戻す。提示された例では、茂林寺の説明を始め直すのではなく、茂林寺周辺の沼を尋ねる質問へ戻る。
- 「栃木じゃなかったっけ？」のような地域の再確認は、直前の同じ対象について公式情報を検索して確認する質問として扱う。確認結果から簡潔に答えるようにし、「以前お伝えした通り」「ご確認くださいませ」と突き放す表現を使わないよう依頼する。
- 実際にユーザーが入力・発話した文章は、表示・ログ・再送控えにそのまま残す。内部で質問を補っても、新しい質問IDを作ったり重複送信したりしない。
- 現在地や別の地域・施設を明示した場合は、その発言を維持する。対象が複数ある場合、履歴が期限切れ・未来時刻の場合、画像や画面内の位置を指す場合には、場所を自動で補わない。
- 履歴の参照は直近8組・2時間以内に限定し、出典一覧やURLを場所候補の抽出に使わない。
- 情報質問の継続が対象。訂正発言を理由に、以前の予約・保存・削除・送信などの操作を繰り返さない。

施設の名称や住所をアプリへ固定した変更ではない。履歴に根拠がなければ、施設名や地域を作らない。

## 確認する会話

1. 「ぶんぶく茶釜の舞台って？」→茂林寺についての回答。
2. 「栃木じゃなかったっけ？」→同じ茂林寺の所在地を再確認する質問。
3. 「近くに沼ある？」→内部の回答対象は「茂林寺の近くに沼ある？」。
4. 誤答を挟んだ「違うよ茂林寺の話」→同じ沼の質問へ戻る。
