# NAVIの移動中の安定性改善 — メガネv625・スマホv272

## 変更内容

1. **GPSの揺れで案内が戻るのを抑制**：鮮度30秒以内・精度25m以内の新しい位置情報で経路進捗を保持します。古い・重複・精度不足の位置では進捗を更新しません。30秒を超える観測間隔や経路の再取得・再開始では取り直します。GPSによる誤判定を完全に防ぐ機能ではありません。
2. **通過した曲がり案内の再表示を抑制**：同じ経路では保持済み進捗より前の曲がり案内へ戻しません。既存の通過疑い判定・再検索は継続します。
3. **音声・検索と画面処理の競合を軽減**：同じ経路のJSON解析と区間距離の合計を再利用。距離は累積値の差で求めます。既存の検索用ワーカー分離・最新結果優先も保持します。検索待機中に画面スレッドの処理が実行できるテストを追加しました。VOICE録音・読み上げを同時に使う実移動での計測は未実施です。
4. **画面復帰を改善**：スマホは保持している乗車方向表示を復帰時に反映。メガネは案内中の表示を戻し、通常の周期を待たずにスマホへ最新状態を問い合わせます。案内の開始・一時停止解除は自動で行いません。
5. **再検索中の参考経路**：Google経路の再計算中、目的地・移動手段・区間が一致し、有効期限内の直前の経路を参考表示します。新経路として扱わず、曲がり読み上げは保留します。目的地・区間の変更時は破棄し、取得できた新経路と混ぜません。初回取得前や期限切れには表示しません。
6. **区間切り替えの安定化**：GPSで推定する移動区間は隣接する次区間までとし、順序の古いサンプルで切り替えを進めません。15秒を超える観測間隔では切り替え候補の証拠を取り直します。既存の明示的な乗車・降車の確認と一方向の進行は保持します。

## 検証範囲

実APKのクラスを別UIDの通信・録音・再生権限のない環境で実行しています。テストは合成情報のみ。個人の自宅・勤務先・通勤経路の初期登録はしていません。

実際の道路・駅での移動、経路サービスへの検索、VOICEとNAVIの同時利用中の遅延、実際の音が出る時刻は未検証です。前版のメニュー測定値を今回の改善効果として流用していません。
