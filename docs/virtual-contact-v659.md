# 仮想空間の接触状態と会話・動作の連動 v659

短いリアクションや保存済み会話の引用とは別に、現在の触れ合いを1つの状態として保持します。NONE／OFFER／HAND／HUG／PATを区別し、誰がどこに触れているか、直近の操作方向、待機と成立を同じ状態で会話・VOICE・顔・全身へ渡します。

## 使い方

「手を差し出して」で待つ姿、「手をつないで」「手つないで」「手をつなごう」で握る流れへ進みます。キャラクターにフォーカスがある時、タップで手を取る・握り返す、スワイプで接触の方向へ反応します。画像自体のタップも対応。戻るで通常のボタン操作へ戻ります。CAM・NAVI・BT30・SETなど通常のボタンを選んだだけでは手を取ったことにはしません。

SETの「触れ合いの状態・操作・終了」から、現在の状態確認・操作へ戻る・端末内で手を差し出す・離す操作ができます。メニューの端末内操作はAI送信・録音・撮影を行いません。コメント欄へ新しい状態表示を重ねません。

成立後は普通の会話が続いても保持し、「離して」「やめて」や明示的な新しい話題で終了。実務の質問では状態を失わず表示を控えます。会話や操作がないまま2時間、差し出して待つ状態は2分で終了します。短いスワイプ反応が終わることと接触状態の終了は別です。

## 仕様

状態は端末内へ暗号化した列挙値・日時だけを保存し、会話本文を複製しません。再起動後も期限内の状態を復元します。無関係な会話・過去ログ・状態を尋ねただけの質問から勝手に成立させません。現在の状態は過去の描写より優先します。終了時は以前の短い接触・甘える動作も取り消し、後から再生されないようにします。

応答用の文脈には、ユーザーが選んだ仮想場面としての状態を明記します。現実の身体やデバイスで接触が起きたという意味ではありません。不要な実体の説明で流れを切らず、通常の質問は直接答え、必要な意思表示や境界は維持します。モデルの返答があらゆる自由文で必ず成立するという保証はありません。手・抱擁・頭／肩／頬などの撫でる場面を対象にした限られた状態・語句の解釈です。

顔の反応と全身8ポーズを追加連動。手の差出しと握り返しを別画像にしました。新規全身画像は内蔵image_genで作成し、境界の余白を直した案を採用。立ち4・座り4、既存画像は保持。保持中にも小さな呼吸を残し、描画からネット通信・追加タイマー・毎フレームの保存を行いません。既存ナビ・録音・否定表情・手動プレビューを優先します。
