# 記録検索・会議しおり・読み取り訂正・静かな時間・出発前チェック

2026-10-20 / グラス v596・スマホ v240。両端末へ反映済み。更新前バックアップのPCコピーと読み出し、同一署名、ソースAPKとインストール済みAPKのSHA-256一致を確認。

## 開き方と動作

- **記録の横断検索**：スマホの折り畳み機能内「記録の横断検索・読み取り訂正」。PC・タブレットは会話タブの「記録の横断検索」。端末にある会話・長期記憶、会議要約、受信箱、画像読み取りを検索し、元の記録を開く。空白区切りはAND検索。全角半角・英字大小を正規化する。意味検索ではない。
- **会議しおり**：グラスのMTGメニューの「ここ重要」、スマホの「録音の進捗・保存確認」、Webの会議・録音画面から追加。グラス自身の通常入力で「ここ重要」「ここ大事」「しおりをつけて」などの一致表現も扱う。PCからの通常会話文は依頼IDの処理を維持し、専用ボタンを使う。1会議100件まで。PCM取得済みバイト数から位置を決め、音声とは別の暗号化ファイルへ保存する。保存完了後に成功通知する。しおり保存の失敗だけで録音を停止しない。
- **しおりから再生**：スマホで保存会議の「元の録音・しおり・文字起こし」を開く。Webでも会議記録のしおりボタンから再生できる。再生は明示ボタンのみ。10秒の音声区間を取得し、その中の保存位置までシークする。スマホはアプリ専用キャッシュへ区間ごとの一時WAVを作り、停止・ダイアログ終了で削除する。異常終了時のキャッシュはOSの管理対象として残る場合がある。
- **読み取り訂正履歴**：検索または「読み取り・訂正履歴」から元の読み取りと訂正を並べて確認する。項目、元の文字列、訂正後を保存。変更前に指定した文字列が原文にない場合、古いリビジョン、同じIDで異なる内容は拒否する。元の読み取りを上書きしない。訂正は記録用で、AIへの参照・予定登録へ自動適用しない。
- **静かな時間**：グラスSETの「静かな時間（表示のみ）」、スマホ・Webの同名操作から設定。初期値OFF。毎日2時間帯、日付をまたぐ設定も可能。開始と終了が同じなら終日。通知・TOPIC・AMBを表示のみにし、エラー/権限、予定、Codex通知の読み上げ例外を選べる。直接の会話は対象外。現在の発話を途中で切らず、次の通知・TOPIC・AMBの出力開始で判定する。スマホ/Webからの設定は送信待ちと表示し、グラスの適用結果を再度開いて確認する。変更競合はリビジョンで拒否する。
- **出発前チェック**：グラスSET、スマホの折り畳み機能、Web検索欄そばから開く。電池、空き容量、受信状態、最後の位置情報の経過時間、経路取得データ、案内状態を表示。電池30%と空き300MBは注意の目安。端末内の記録だけを読み、新たな位置取得・経路API・削除・設定変更を行わない。値がなければ未確認、通信が古ければ前回値と明示する。経路データありは現在も有効な経路の保証ではない。

## 記録の範囲・保存

検索はスマホが保持する直近会話（既存の90日・最大800件）と圧縮された長期記憶、直近100件の会議要約、受信箱、今回以降に保存した読み取り履歴が対象。最大50件を新しい順に返し、取得できなかった情報源を表示する。全写真のOCR・全会議の全文検索・クラウド検索ではない。削除済み・期限切れの過去画像読み取りは復元しない。

画像読み取り履歴は縮小プレビューがあればそれも含めて暗号化保存（最大100件・90日、1件20訂正）。原寸画像そのものではない。期限超過分は一覧から除外し、新しい読み取り保存時に整理する。履歴を削除しても元写真・共通会話・予定は削除しない。同じ現在参照が再取り込みされないよう、削除済みIDと元日時のみを暗号化して上記上限内で保持する。100件の枠から削除IDが押し出された場合、現在参照がまだ有効なら再度履歴へ入る余地がある。

録音のしおりはグラス・スマホの会議フォルダー内の暗号化 sidecar。転送時に既存の認証経路を使ってしおりも渡し、スマホでは平文の会議メタデータから除いて暗号化保存する。録音の原本や過去の音声は書き換えない。検索・訂正・静かな時間・出発チェックで新たな外部AI送信は行わない。通常のTOPIC処理を使用者が起動した場合の既存API送信は従来どおり。

## 検証結果と限界

- 両アプリの開発ビルド成功。保護された会話プロンプトのベースライン検査成功。会話プロンプトは変更していない。
- 既存のリリース回帰一式成功。今回追加した時間帯/検索ポリシー24項目、Edge上の実際の新UIと模擬ローカルAPIによる14項目成功。ブラウザの外部リクエスト0件。
- 更新後の端末内隔離テスト：グラス19項目、スマホ32項目成功。実際のAndroid暗号化保存、重複/競合拒否、削除の再登録防止、元読み取り保持、合成音声区間としおりの受信・検証、検索元の区別、静かなTOPICが音声出力を呼ばないことを確認。
- テストは専用の一時フォルダー・一時設定で実行し、終了時に削除。検証APKは両端末から削除。両アプリの通常起動とプロセス生存を確認。
- 今回は外部APIへの送信、実マイク/カメラ取得、実音声再生、実予定登録、装着しての長時間試験はしていない。しおりの本番録音中の操作感・実スピーカーのシーク音・静かな時間の実生活での使い勝手は、この隔離検証だけでは保証しない。

ローカル検証：`tools/Test-ReleaseReliability.ps1 -JsonJar <local-json.jar>`。端末内検証の実行結果とバックアップ確認は作業用 records-v596 出力へ保存しており、私的バックアップを公開物へ同梱しない。
