# v673: 会話と動作のつながり

1. 明示的に選んだ座位・寝姿・くつろぐ姿勢を通常の質問、意味の質問、読み上げ終了、会話の待機時間切れで解除しない。立つ・座る・終了など明示操作を優先する。寝姿の微笑みは既存顔の局所変形、手振りは既存の寝姿の手振りコマを使用し、立ち姿へ差し替えない。
2. 同じ仕草のコマ間を240msで接続。新しいBitmapをフレームごとに作らず、既存のデコード済み画像を共通アンカーで合成する。イヤリングは手を下ろす→耳へ→触れる→襟元へ戻す→手を下ろす。3コマの別動作へ4コマ目を適用しない。
3. 顔モードは考え始めからの短い視線外し・首傾げ、返答開始時の視線戻し・うなずきを追加。通常の既存微動と組み合わせ、ナビ等の静かな表示では追加反応を止める。カメラや追加の常時タイマーは使用しない。
4. 自動の仕草は同じ種類を120秒以内に再開しない。同じ動作の描画継続は遮断せず、明示プレビューややり直しは除外する。履歴はView内の小さな固定配列で保持する。
5. 「動いてない」「その姿勢じゃない」「動作をやり直して」で直前の表示を再適用。「戻って」「一つ前の姿勢に戻して」で直前の姿勢へ戻す。短い完全一致の表示操作だけを対象とし、駅への案内や説明・引用は横取りしない。履歴なしはその旨を返す。端末内の返答を既存の履歴・受信・読み上げ経路へ渡し、外部AIへ送らない。読み上げ開始時の重複入力でundoを二重適用しない。
6. tools/Review-CharacterArtwork.py は指定基準と候補を実表示サイズで並べ、手入力で確認した頭・肩・腰・足首の目印から頭幅/身長、頭幅/肩幅、肩幅/身長、脚長/身長を比較する。座位は座位基準を使用。顔の同一性・リアルさ・手・衣装・遠近感は目視確認が必要で、自動承認はしない。artwork/character-artwork-review.json は既存17アトラスを固定し、追加・変更した未確認画像をビルド時に拒否する。既存ファイルの固定は全旧画像の解剖学的な正しさの保証ではない。

## 画像確認手順

PillowがあるPythonで tools/Review-CharacterArtwork.py --candidate 画像 --landmarks 目印JSON --output 出力フォルダ を実行する。artwork/ear-v672-standing-landmarks.json は書式例。新しい動作用シートは全コマの目印を用意する。比較画像・metrics.json・review.html を確認し、問題を修正した後にのみ登録ハッシュを更新する。閾値を通っても成人顔や骨格の同一性は別途確認する。基準画像そのものは加工しない。

## 検証

ビルドに純粋Javaの姿勢保持・再適用・undo重複防止・頻度制限・顔反応の回帰チェックを追加。隔離Androidの描画テストと、最終APKのハッシュを結びつけた適用結果は作業outputsへ保存する。外部API、実会話、録音、撮影を使うテストは今回行わない。
