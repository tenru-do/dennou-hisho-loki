# ロキ本人情報と登録画像

2026-10-16: グラスv536／スマホv193。

ロキの役割・標準の髪型／顔／服装・登録画像の位置づけを、両アプリの会話ペルソナに追加。外見の正本は既存登録画像とし、年齢の数値や身長、現在表示中のフレーム等の未提供情報を創作しない。

`tools/generate-loki-self-profile.ps1` はビルド前に実画像の登録表から全身443フレームの画像ファイル／領域とソースSHA256、顔37表情の正本画像を `assets/loki-self-profile.json` へ記録する。台帳は両アプリ共通。本人参照は通常立ち姿ID4と採用済み顔ID0。スマホへ同梱する元アトラスはグラスの正本をそのままコピーする。

本人の外見／画像に関する会話と画像生成では、2枚の実登録画像を領域デコードして添付する。普通の会話や周囲解析には添付しない。全画像を毎回送信せず、登録台帳と本人の代表画像を参照する構成。すべての画像を一度に視覚入力しているわけではない。

送信画像は登録アトラスからの小さなJPEG領域で、実機では2枚合計37,907バイト。Bitmapは使用後に解放。生成の編集元と本人の外見参照は別の説明を付ける。一般の猫画像や北欧神話／別作品のロキには本人情報を添付しない。

プライバシー: 本人画像はアプリに同梱されたキャラクター画像。自己情報のために連絡先・位置情報・利用者の写真を収集しない。通常会話の既存の共有記憶機能はそのまま。本人参照画像は該当する依頼でGeminiに送られる。安全判定と自動再送停止を維持。

検証: 画像正本のハッシュ一致、参照JPEGのサイズ・復号可能性、通常／神話／編集指示の区別、実機Geminiの本人説明、登録画像を添えた生成・ギャラリー保存、グラスの実送信リクエスト構築を確認。生成ID48a3adab-9bdd-3be4-beb3-7349daa2cb65、gallery media/4179。出力は `outputs/self-profile/generated-registered-loki.jpg`。生成結果は既存画像そのものへの置換ではなく、顔の完全一致を保証するものではない。
