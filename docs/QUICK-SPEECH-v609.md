# メガネv609：読み上げの停止・再開

通常のロキ読み上げ画面で、決定タップ（DPAD_CENTER / BUTTON_SELECT）を押すと一時停止し、もう一度押すと停止した区切りの先頭から再開します。HUDを起こす処理やフォーカス中ボタンの起動より先に処理し、押下・解放や長押しの繰り返しでは二重に切り替えません。

画面には「TAP: 読み上げ停止」「TAP: 続きから再開」を表示し、表示ボタンからも操作できます。通常の会話回答、ローカルの単発読み上げ、従来のロキ・トピックに対応します。別経路のAMBIENT短音声や旧式Rokid音声テストは対象外です。メニューのダイアログにフォーカスがある間は、通常のメニュー操作を維持します。

停止では現在の読み上げ世代を無効にし、ネイティブTTSへ停止命令を送ります。本文や履歴は変更せず、AIへ質問を送り直しません。停止中のVOICE自動再開予約を抑制し、古いコールバックでも次の区切りへ進まないようにします。

再開位置は区切り単位で、止めた区切りの先頭を読み直す場合があります。ネイティブTTSには発話完了通知がなく、再生終了判定は推定です。再開位置はアプリ内の一時状態で、新しい読み上げやアプリ再起動後には引き継ぎません。

候補APKの実クラスを、別UID・権限なしのAndroid環境と合成データで758項目検証しました。追加38項目はキー重複防止、区切り位置、古い世代の無効化、新しい回答との識別、終了済み・空の読み上げを確認しています。

実機では短いローカル音声と決定キー相当の入力で、停止命令の送信、停止中の再送抑制、再開時の音声送信、再度の停止を確認しました。初回は画面が起きておらず音声開始を確認できませんでしたが、画面を起こしロキを表示後の試行で確認できました。実際に音が止まるまでの時間や、装着者による聞こえ方は測定していません。新しいAI質問は送信していません。

メガネv609をデータ保持で上書き更新済みです。更新前バックアップ、署名一致、APKハッシュ、初回起動前の既存410ファイル不変を確認しました。スマホはv257のままです。一時音声は停止後、メガネ版を再起動して片付けました。公開用署名APKの作成・GitHub公開は今回まだ行っていません。
